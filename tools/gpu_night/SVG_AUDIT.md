# SVG 임시 그림(greybox) 점검 — 12편 (2026-10-03)

방법: 12편 코드를 처음부터 끝까지 읽고(그림이 있으면 숨는 대체 그림은 빼고, **그림이 다 있을 때 실제로 보이는 코드 도형**만), 자동 재생 캡처(1280×720, 2초 간격, 12편 전부 끝까지)로 화면에서 확인했다. 표의 큰 항목은 모두 캡처에서 회색 도형으로 보였다(토끼 노을·결승·시상대·악기, 해님달님 해·달·구멍 눈·나무 꼭대기·우물 물·귀 배지, 개구리 삼촌, 순무 잔치 상·컷 흙띠, 사자 비교판·이빨·구멍·그물, 여우 잔치 식탁, 골디 부감 그릇·침대 옆모습·이불·곰 발·치마 컷·식탁, 브레멘 북·나팔, 개미·오리 카드·꽃·먹구름).
작업 목록: `build_svg_jobs.py` → `jobs_svg.json` (**102장, 우선순위 순**). 아래 표의 **애셋 이름**이 그 작업 이름이다.

- 모든 동화의 ART/BG 지도에 적힌 파일은 **전부 디스크에 있다**(빠진 파일 없음). `null` 은 일부러 버린 그림뿐이다: sunmoon `basket`·`cut_eye`, sun_wind `cut_pant`, turnip `cut_pop`, bremen `cut_monster`·`cut_ghost`.
- **개미와 베짱이·미운 아기 오리는 아직 그림 연결 코드가 없다**(ART 지도·이미지 함수 없음) → 지금 화면은 전부 회색 도형. 아래에는 `jobs_ant_grasshopper.json`·`jobs_ugly_duckling.json` 에 **없는 것만** 적었다.
- 표의 **M** = 마젠타 배경(초록·연두 대상, 또는 그물처럼 구멍이 많은 대상 — 마젠타 키잉은 색으로 지워 막힌 구멍도 빠진다).
