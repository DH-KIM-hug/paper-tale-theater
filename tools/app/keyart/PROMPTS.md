# 시작 화면 키아트 판(plate) 프롬프트

## 사용법
1. ChatGPT 이미지 생성에서 프롬프트를 그대로 붙여넣습니다. 세로용은 **2:3 (960x1440)**, 가로용은 **16:9 (1600x900)** 크기를 고릅니다.
2. 마음에 드는 한 장을 고르면 `assets/raw/keyart_gpt/<id>_tall_v1.png`(세로), `assets/raw/keyart_gpt/<id>_wide_v1.png`(가로)로 저장합니다. 다시 뽑으면 v2, v3으로 올립니다.
3. 판에는 인물·동물이 없습니다. 아래쪽 가운데 빈 곳에 게임 스프라이트를 얹어 합성합니다.
4. 각 항목 끝의 "합성 스프라이트"는 장면이 자리를 비워 둘 대상입니다.
5. 팥죽 세로는 승인된 원본입니다. 가로는 새로 뽑아야 합니다.
