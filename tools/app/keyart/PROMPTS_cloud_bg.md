# 퐁! 구름 공장 배경 프롬프트 (가로 풀블리드)

## 사용법
1. ChatGPT 이미지 생성에서 프롬프트를 그대로 붙여넣고 크기는 **16:9 (1600x900)** 로 고릅니다.
2. 마음에 드는 한 장을 `assets/raw/bg_gpt/kkultteok/<장면이름>.png` 로 저장합니다. 파일 저장이 번거로우면 이미지를 채팅으로 그냥 보내 주셔도 됩니다. 다시 뽑으면 `_v2`, `_v3` 로 올립니다.
3. 이 배경은 시작 화면 키아트와 달리 둥근 창, 흰 종이판, 테두리가 없습니다. 화면 끝까지 꽉 채웁니다.
4. 인물·동물·얼굴은 그림에 넣지 않습니다. 등장인물은 게임이 얹습니다. 아래쪽 3분의 1은 비워 두고, 중요한 물건은 가운데 60% 안에 둡니다(세로 화면은 양옆이 잘립니다).
5. 이 동화의 대표 그림은 굴뚝입니다. 하늘로 길게 솟은 연한 민트색 굴뚝에서 두툼한 연기가 옆으로 휘어 나가다가 뭉게구름으로 바뀌어 하늘의 구름과 하나가 되는 모습입니다(연기, 퐁, 구름 세 단계). `door`, `chimney` 판에서 이 모습이 나왔는지 꼭 확인해 주세요.
6. `door`는 굴뚝 장면과 동그란 문 장면이 함께 쓰고, `inside`는 솥·구름·단추 장면에, `corner`는 빨간 단추 장면에 씁니다. `chimney`는 선택 판입니다.
