# 아기돼지 삼형제 배경 프롬프트 (가로 풀블리드, 10장)

## 사용법
1. ChatGPT 이미지 생성에서 프롬프트를 그대로 붙여넣고 크기는 **16:9 (1600x900)** 로 고릅니다.
2. 마음에 드는 한 장을 `assets/raw/bg_gpt/three_pigs/<이름>.png` 로 저장합니다(채팅으로 보내 주셔도 됩니다). 다시 뽑으면 `_v2`, `_v3`.
3. 둥근 창, 흰 종이판, 테두리 없이 화면 끝까지 꽉 채웁니다. 인물·동물·얼굴·글자는 넣지 않습니다. 아래쪽 3분의 1은 비워 두고(등장인물 자리), 중요한 물건은 가운데 60% 안에 둡니다.
4. 기준 화풍은 `assets/raw/bg_gpt/patjuk/scene_a_field.png` 입니다(승인본). 같은 종이 질감·색 층·그림자로 맞춥니다.
