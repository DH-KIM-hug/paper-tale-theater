# 종이 동화극장 (Paper Tale Theater)

3~4세 아이를 위한 **인터랙티브 페이퍼아트 동화** 모음입니다. 겹겹이 오린 종이 그림 속에서, 아이가 화면을 톡 누르고 쓱 밀며 이야기를 함께 만들어 갑니다. 인물마다 다른 목소리로 말하고, 말하는 인물을 카메라가 따라갑니다. 이야기마다 수 세기, 크기 비교, 순서, 분류 같은 놀이 학습이 들어 있습니다.

**바로 해보기:** https://dh-kim-hug.github.io/paper-tale-theater/

아이패드에 맞춰 만들었고, 휴대폰 가로·세로에서도 플레이할 수 있습니다. 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.

## 동화

| 동화 | 종류 | 배우는 것 | 상태 |
|---|---|---|---|
| 팥죽할멈과 호랑이 | 한국 전래 | 순서, 관찰 | 페이퍼아트 그림 |
| 해와 달이 된 오누이 | 한국 전래 | 수 세기, 관찰 | 페이퍼아트 그림 |
| 황소와 개구리 | 이솝 | 크기 비교 | 페이퍼아트 그림 |
| 토끼와 거북이 | 이솝 | 소리 듣기, 마음 | 페이퍼아트 그림 |
| 해와 바람 | 이솝 | 날씨, 마음 | 페이퍼아트 그림 |
| 커다란 순무 | 외국 전래 | 순서, 수 세기 | 페이퍼아트 그림 |
| 사자와 생쥐 | 이솝 | 크기 비교, 수 세기 | 페이퍼아트 그림 |
| 여우와 두루미 | 이솝 | 모양 맞추기, 배려 | 페이퍼아트 그림 |
| 골디락스와 곰 세 마리 | 외국 전래 | 크기 비교, 순서 | 페이퍼아트 그림 |
| 브레멘 음악대 | 외국 전래 | 소리 듣기, 순서 | 페이퍼아트 그림 |

**만드는 중:** 아기 돼지 삼형제, 늑대와 일곱 마리 아기 염소, 콩쥐 팥쥐, 헨젤과 그레텔, 신데렐라, 흥부와 놀부, 빨간 모자, 은혜 갚은 까치, 요술 항아리

## 아이를 위한 원칙

- **게임오버가 없습니다.** 틀리면 짧은 헛수고 장면 뒤에 점점 더 도와줍니다 (1번째: 말로 힌트, 2번째부터: 정답이 반짝이며 이름을 알려 줌).
- **조작은 5가지:** 톡(누르기), 톡톡톡(연타), 골라요(2~3개 중 선택), 쓱(밀기), 꾹(길게 누르기).
- **막히지 않게:** 5초 동안 가만히 있으면 손가락 안내, 12초면 다시 알려 주고, 20초면 자동으로 넘어갑니다.
- **대사 건너뛰기**는 무대를 1초 길게 누를 때만 됩니다 (아이의 톡톡으로 힌트가 끊기지 않게).
- 원작 줄거리는 지키되, 어두운 순간은 화면 밖 소리와 그림자로만 보여 줍니다.
- 홈의 톱니를 3초 누르면 보호자 메뉴가 열립니다.

## 실행 (개발)

```bash
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765 열기
```

빌드와 의존성이 없는 정적 웹입니다. `main` 브랜치에 올리면 GitHub Pages에 자동으로 배포됩니다.

## 구성

| 경로 | 역할 |
|---|---|
| `index.html`, `home.css`, `home.js` | 앱 홈: 종이 한 장에 동화마다 모양이 다른 구멍(썸네일), 이야기 종류·배우는 것 태그(숨기기 가능) |
| `tales/catalog.js` | 동화 목록과 태그 |
| `tales/<이름>/` | 동화 한 편 (`index.html` + 이야기 스크립트) |
| `engine/` | 공용 엔진: 무대·카메라·종이 조리개 장면 전환, 대사 연출(말하는 인물 따라가기·마주 보기), 조작 5가지, 도움 단계, 만화 컷, 조사(이/가) 처리 |
| `audio.js` | 내레이션 재생 (녹음을 미리 받아 두고 재생, 없으면 브라우저 음성), 실제 효과음·동물 소리, 아이폰 무음 모드에서도 소리 |
| `story.js`, `narration_tc.js` | 팥죽할멈 대사와 녹음 파일 목록 (다른 동화는 `tales/<이름>/voice_script.json` → `narration.js`) |
| `audio/tc/` | 배역별 내레이션 녹음 (Typecast) — `tools/typecast/`로 생성, 대사를 고치면 `update_all.sh` |
| `sounds/` | 동물 소리·효과음 — 출처와 라이선스는 [`sounds/CREDITS.md`](sounds/CREDITS.md) |
| `assets/v2`, `assets/v3w`, `assets/thumbs` | 페이퍼아트 그림·썸네일 (웹용 webp) |
| `tools/gpu_night/` | 로컬 GPU(ComfyUI + Qwen-Image) 그림 생성·배경 제거 도구 |
| `legacy.html`, `game.js`, `style.css` | 예전 2.5D 팥죽할멈 (비교용 보관) |
