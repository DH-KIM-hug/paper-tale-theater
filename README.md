# 톡톡 동화극장 (Tok Tok Tale Theater)

3~4세 아이를 위한 **인터랙티브 페이퍼아트 동화** 모음입니다. 겹겹이 오린 종이 그림 속에서 아이가 화면을 톡톡 눌러 이야기를 함께 만들어 갑니다. 인물마다 다른 목소리로 말하고, 말하는 인물을 카메라가 따라갑니다. 이야기마다 수 세기, 크기 비교, 순서, 분류, 위치말 같은 놀이 학습이 들어 있습니다.

**바로 해보기:** https://dh-kim-hug.github.io/paper-tale-theater/

아이패드에 맞춰 만들었고, 아이폰·안드로이드 휴대폰의 가로·세로 화면에서도 플레이할 수 있습니다. 웹에서는 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.

## 이렇게 놀아요

- **톡톡 동화 놀이:** 아이가 누르고 고르면서 이야기를 끝까지 이끌어 갑니다.
- **읽어 주기(잠자리):** 누르지 않아도 책장이 저절로 넘어가며 처음부터 끝까지 읽어 줍니다. 화면을 꺼도 소리는 끝까지 이어지고, 여러 편을 이어 듣는 재생목록도 만들 수 있습니다.
- **영어로 듣기:** 보호자 메뉴에서 English를 고르면 글과 목소리가 영어로 바뀝니다(같은 배역 목소리, 영어 녹음이 없는 동화는 한국어로).
- **스티커북:** 동화를 놀이로 끝까지 하면 그 동화의 캐릭터 스티커가 한 장씩 모이고, 갈래별 퍼즐판이 한 조각씩 채워집니다.
- **책을 펼치듯:** 홈에서 동화를 고르면 극장 커튼이 열리고, 시작 화면(책 표지)을 넘기면 장면 그림 책장이 넘어간 뒤 이야기가 시작됩니다.

## 아이를 위한 원칙

- **광고가 없습니다.** 외부 분석 도구도 쓰지 않습니다.
- **게임오버가 없습니다.** 틀리면 짧은 헛수고 장면 뒤에 점점 더 도와줍니다(1번째: 말로 힌트, 2번째부터: 정답이 반짝이며 이름을 알려 줌).
- **안내와 동시에 누를 수 있습니다.** "○○를 톡 눌러 봐요"가 들리는 순간 이미 누를 수 있고, 같은 동작을 여러 번 눌러야 할 때는 한 번 누르면 나머지는 저절로 진행됩니다.
- **막히지 않게:** 5초 동안 가만히 있으면 손가락 안내, 12초면 다시 알려 줍니다.
- **대사 건너뛰기**는 무대를 1초 길게 누를 때만 됩니다(아이의 톡톡으로 힌트가 끊기지 않게).
- 원작 줄거리는 지키되, 어두운 순간은 화면 밖 소리와 그림자로만 보여 줍니다.
- 녹음되지 않은 말은 기계 음성으로 읽지 않습니다.
- 홈의 톱니를 1초 누르면 보호자 메뉴(언어, 자동 재생, 하루 놀이 시간, 기기 연결 등)가 열립니다.

## 실행 (개발)

```bash
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765 열기
```

빌드 없는 정적 웹입니다. `main` 브랜치에 올리면 GitHub Pages에 자동으로 배포됩니다. iOS·안드로이드 앱은 같은 웹을 [Capacitor](https://capacitorjs.com)로 감쌉니다(`tools/app/build_www.sh` → `tools/app/cap_sync.sh`, 안드로이드는 [`docs/ANDROID_SETUP.md`](docs/ANDROID_SETUP.md)).

| `index.html`, `home.css`, `home.js` | 앱 홈: 스플래시, 동화·잠자리·스티커북 탭, 이야기 종류·배우는 것 태그, 보호자 메뉴 |
| `engine/splash/` | 스플래시(three.js): 로고 안 무대로 들어갔다 나와 홈 로고 자리로 |

| `tales/<이름>/` | 동화 한 편(`index.html` + 이야기 스크립트 + 녹음 목록 + 읽어 주기 대본) |
| `tales/stickers.js` | 동화별 캐릭터 스티커 세트 |

| `entitlements.js` | 앱 모드의 무료·잠금·종이별·스티커 기록(웹 공개판은 잠그지 않음) |
| `audio.js` | 내레이션·효과음 재생(녹음을 미리 받아 두기, 화면이 꺼져도 이어지는 읽어 주기, 아이폰 무음 모드에서도 소리) |
| `audio/el/`, `audio/tc/` | 배역별 내레이션 녹음(한국어·영어) |

| `assets/v3w`, `assets/thumbs`, `assets/ui` | 페이퍼아트 그림·썸네일·화면 단추(웹용 webp) |
