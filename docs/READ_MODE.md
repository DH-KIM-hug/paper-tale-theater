# 읽어 주기 모드 (READ MODE) 설계서

> **보류: 대본만 준비, 구현·녹음 미정 (2026-10-22)**
> 사용자가 도입 여부를 아직 고민 중이다. 엔진 코드와 녹음은 손대지 않고, 설계서와 동화별 대본(`tales/<id>/read_script_el.json`, `read_script_en.json`)만 먼저 만들어 둔다. 시범 대본은 팥죽할멈과 호랑이 한 편.

## 0. 한 줄 정의

**읽어 주기** = 같은 장면 그림 위에서, 톡·고르기·세기 같은 조작과 배움 놀이 없이, 처음부터 끝까지 그림책처럼 읽어 주는 모드.

기존 **자동 재생**(보호자 메뉴 `auto_play`)과 다르다. 자동 재생은 놀이판의 대사를 그대로 쓰고 엔진이 톡을 대신 눌러 준다. 읽어 주기는 조작 안내·퀴즈 대사를 아예 빼고, 그 자리에 장면을 잇는 묘사·감정 문장을 보탠다.

### 사용자 결정 (2026-10-22)
1. **기존 대사를 글자 그대로 최대한 재사용**한다. 이미 녹음된 클립을 그대로 쓸 수 있게 문장을 바꾸지 않는다.
2. "톡 눌러 봐요", "골라 봐요", "세어 봐요", "누가 먼저일까요?" 같은 **조작 안내·배움 놀이 대사는 모두 뺀다**. 이야기 내용과 퀴즈 꼬리가 한 줄에 섞여 있으면 꼬리만 잘라 쓴다(`trim_line.py`, CLAUDE.md §3).
3. 그 위에 장면 연결·묘사 문장을 더해 **전체 분량을 지금 대사의 1.5~2배**로 만든다. 글밥을 크게 늘리지 않는다.
4. 새로 쓴 문장만 녹음이 필요하므로 크레딧은 **신규 문장 글자 수**만 센다.

## 1. 사용자 흐름 (권장안: 시작 화면 버튼)

- 동화 **시작 화면**의 알약 버튼 줄에 `이야기 시작` 옆으로 **`읽어 주기`** 버튼(책 모양 아이콘)을 하나 더 둔다. `tales/<id>/read_script_el.json` 이 있는 동화에서만 보인다.
- 누르면 같은 무대에서 읽어 주기가 시작된다. 끝 화면의 리본(한 번 더)은 같은 모드로 다시 읽는다. 홈으로 가면 모드는 남지 않는다(동화마다 그때그때 고른다).
- 주소 `?read=1` 로도 들어갈 수 있다(홈 타일 길게 누르기, 검증 도구용).
- 보호자 메뉴 토글은 두지 않는다. 이유: 이미 `자동 재생` 토글이 있어 두 가지 "혼자 흘러가기"가 메뉴에 나란히 있으면 보호자가 구분하기 어렵고, 읽어 주기는 잠자리에서 그날그날 고르는 선택이라 숨은 메뉴보다 시작 화면이 맞다.
- 자동 재생이 켜져 있어도 읽어 주기 버튼은 그대로 보인다. 읽어 주기 안에서는 `auto_play` 를 보지 않는다(누를 것이 없다).
- 쉬는 화면(놀이 시간 알림)·자막 끄기(`captions_off`)·언어(`lang`)는 그대로 적용된다.

## 2. 엔진 구조

### 2-1. 파일
```
tales/<id>/read_script_el.json      한국어 대본 (장면 목록 + 문장 + 연출 지시)
tales/<id>/read_script_en.json      영어 대본 (같은 장면·같은 줄 순서, en 문장)
tales/<id>/narration_read_el.js     (생성) 신규 문장의 녹음 경로 — Object.assign(NARRATION_CLIPS, {...})
tales/<id>/narration_read_el_en.js  (생성) 영어
audio/el/<id>/                      녹음 mp3 — 놀이판과 같은 폴더 (같은 문장은 같은 해시라 파일을 공유한다)
```

### 2-2. 공통 플레이어 — 엔진 함수 하나
`engine/tale.js` 에 `T.readPlay(acts)` 를 더한다. 동화 js 는 `run(T)` 첫머리에서 한 줄만 분기한다.

```js
async function run(T) {
  …배우·장면 함수 만들기 (지금 코드 그대로)…
  if (T.reading()) return T.readPlay(READ_ACTS);   // 읽어 주기: 아래 놀이 흐름은 돌지 않는다
  …놀이 흐름 (지금 코드 그대로)…
}
```

`T.readPlay(acts)` 가 하는 일:
1. `read_script_<el|en>.json` 을 fetch 한다(영어 모드이고 en 파일이 있으면 en, 아니면 el).
2. `narration_read_el.js`(영어는 `_en`) 를 fetch 해 `new Function` 으로 실행해 `NARRATION_CLIPS` 에 합친다(시작 화면의 `home_narration_el.js` 로더와 같은 방식). `src: reuse` 줄은 놀이판 클립을 그대로 찾고, `trim` 줄은 잘라 낸 클립(`trim_line.py` 가 같은 규칙으로 경로를 만든다), `new` 줄은 새 클립을 쓴다. 없으면 브라우저 TTS 로 떨어진다(지금 `Narrator.speak` 규칙 그대로).
3. 장면마다 `T.sceneCard(card, () => { acts.set(scene.set); scene.enter.forEach(run) })` → 줄마다 `before` 동사 → `T.say(text)` → `after` 동사 → `GAP`(700ms). 장면 끝 `SCENE_END`(1500ms). 첫 장면은 `T.curtain(true)` 로 연다.
4. 끝나면 `moral` 을 돌려주고, 엔진이 평소처럼 끝 화면(뒷표지)을 보여 준다.
5. 동사 실행: `"granny:cry"` → `acts.granny('cry')`, `"cam:300,400,1.3"` → `acts.cam('300,400,1.3')`, `"friend:bam:enter"` → `acts.friend('bam', 'enter')`. 콜론으로 자르고 첫 토큰이 함수 이름, 나머지가 인자다. 모르는 동사는 `console.warn` 만 하고 넘어간다(대본이 코드보다 먼저 나와도 깨지지 않게). 동사가 Promise 를 돌려주면 기다린다.
6. 조작 함수(`tap/mash/choose/…`)와 손가락 힌트는 호출되지 않는다. 무대 1초 꾹 누르면 대사 건너뛰기(보호자용)는 그대로 된다.

### 2-3. 장면 그림 재사용 (권장안: 동화 js 가 동사 맵을 내보낸다)
두 가지를 비교했다.

| | (가) 동화 js 가 `READ_ACTS` 동사 맵을 내보냄 **(권장)** | (나) 플레이어가 그림 이름 목록으로 직접 그림 |
|---|---|---|
| 동화 js 변경 | `run()` 안에 분기 1줄 + 동사 맵 1개(기존 `setScene`·`grannyMood`·`pose`·`walk` 를 감싼 얇은 함수) | 없음 |
| 그림 일치 | 놀이판과 **완전히 같은** 배우 크기·자리·카메라·컷·효과음 | 배우 크기(ASP)·발 위치·카메라를 json 에 다시 적어야 하고, 동화마다 다른 좌표 체계(ACTOR_SCALE, STATION_CAM)를 복제하게 된다 |
| 새 동화 추가 | 동사 맵만 쓰면 됨 (대본은 동사 이름만 안다) | json 이 커지고, 그림을 바꾸면 json 도 함께 고쳐야 함 |

(가)로 확정. 각 동화는 `run()` 안에서 이미 쓰는 함수들을 동사 이름으로 묶는다. 팥죽의 동사 목록은 `tales/patjuk/read_script_el.json` 의 `acts` 항목에 적어 두었다(문서용; 플레이어는 읽지 않는다).

## 3. 대본 형식 규칙 (다른 동화 대본을 나눠 쓸 때 이 규칙을 지킨다)

### 3-1. 파일 뼈대
```json
{
 "mode": "read", "tale": "<id>", "lang": "ko",
 "title": "<동화 제목>",
 "voices_from": "voice_script_el.json",
 "moral": "<교훈 한 줄 — 끝 화면 msg 로 넘긴다 (화면에 보이지 않음)>",
 "notes": "<순화한 점, 원작과 다른 점, 재사용 원칙 메모>",
 "acts": { "<동사 꼴>": "<설명>" },
 "scenes": [ { "key", "card", "set", "enter", "lines": [ … ] } ]
}
```

### 3-2. 장면 (`scenes[]`)
- `key`: `R01_field` 꼴. `R` + 두 자리 번호 + `_` + 영어 소문자 짧은 이름. 번호는 읽는 순서, 이름은 장면 내용.
- `card`: 장면 카드에 오려 붙는 글자(한국어 2~6자). 영어 파일은 영어로. `null` 이면 카드 없이 책장만 넘긴다.
- `set`: 동화 js 의 장면 세트 키(팥죽 `A|B1|B2`, 신데렐라는 `bgImage` 키 등). 플레이어가 `acts.set(set)` 으로 먼저 부른다.
- `enter`: 장면이 열리기 전에 실행할 동사 목록(배우 자리·자세·카메라). 책장이 넘어가는 동안 실행되므로 애니메이션 없이 **놓기만** 한다.
- 장면 수는 놀이판과 같거나 ±2. **한 장면은 한 가지 사건**(CLAUDE.md §3). 8~11장.
- 놀이판 장면 중 **배움 놀이 전용 장면**(세기·고르기만 있는 장면)은 뺀다. 그 장면의 그림이 이야기에 필요하면 묘사 문장 한두 줄로 남긴다.

### 3-3. 문장 (`lines[]`)
```json
{ "text": "<말풍선에 보이는 글>", "src": "reuse|trim|new", "from": "<trim 일 때 원래 줄>",
  "segs": [["<배역>", "<읽을 글>", "<감정>", "<연기 지시>"]],
  "before": ["<동사>"], "after": ["<동사>"] }
```
- `src` 는 반드시 적는다.
  - **`reuse`(기존)**: `voice_script_el.json` 의 `text` 와 **글자 하나까지 같다**. `segs` 도 그대로 복사한다. 녹음 없음.
  - **`trim`(기존, 꼬리 자름)**: `from` 에 원래 줄을 적고, `text` 는 원래 줄의 **앞부분을 문장 경계에서 자른 것**이다. 잘라도 되는 꼬리는 퀴즈·조작 안내 문장("누가 먼저 혼내 줄까요?", "다음은 누구?", "톡 눌러 봐요!")뿐이다. 세그먼트 단위로 떼는 것(`"얘들아, 도와줘!"` 만 남기고 내레이터 안내 세그먼트를 버림)도 `trim` 이다. 녹음은 `trim_line.py` 로 자른다(크레딧 없음).
  - **`new`(신규)**: 새 문장. 녹음 필요. 신규는 **내레이터 위주**로 쓰고, 배역 새 대사는 한 편에 3~5줄 안으로.
- 문장 길이: 한 줄 **15~45자**(공백 포함), 한 줄에 문장 최대 2개. 소리 내어 읽기 쉽게, 3~4세가 아는 낱말로. 의성어·의태어는 놀이판 말투를 따른다(데굴데굴~, 쿵!).
- `segs` 의 배역 키는 그 동화 `voice_script_el.json` 의 `voices` 키만 쓴다(영어 소문자). `nar` 가 내레이터. 감정·연기 지시 꼴도 거기 있는 것을 따른다(`smart`, `sad:1.4`, `[calm, warm storytelling]`). `=` 로 시작하는 전체 지시는 놀이판 줄을 복사할 때만 쓴다.
- **voices 값이 `tc`(Typecast)인 배역**(팥죽의 사물 친구 7명 등)에는 신규 대사를 주지 않는다. ElevenLabs 로 만들 수 없고 Typecast 재생성은 별도 결정이다(§9 판단 1).
- `before`/`after`: 동사 목록. 비워도 된다. 걷기·컷처럼 시간이 걸리는 동사는 `before` 에 두면 문장을 읽기 전에 끝나고, `after` 에 두면 읽은 뒤 실행된다. 컷(`cut:*`)은 컷 속 외침(VOICE_LINES)을 그대로 재사용한다.
- 조작 안내 문구("톡", "눌러", "골라", "세어", "꾹", "쓱")는 어떤 줄에도 남기지 않는다. 커밋 전 `grep` 으로 검사한다.

### 3-4. 영어 파일 (`read_script_en.json`)
- 장면·줄 순서는 한국어 파일과 **같다**. 각 줄에 `text`(한국어 키, 그대로)와 `en`(읽는 문장)을 둔다. `segs` 는 영어 글이고 감정은 한국어와 같다. 연기 지시는 적지 않는다(`gen_tale.py --lang en` 규칙대로 한국어 줄의 지시를 가져온다).
- `reuse` 는 `voice_script_en.json` 의 `en` 그대로. `trim` 은 영어 녹음을 같은 문장 경계에서 자른 것(영어 문장 순서가 달라 자를 수 없으면 그 줄은 `new` 로 바꾸고 `notes` 에 적는다).
- 영어 신규는 한국어의 **2.2~2.5배 글자**가 보통이다.

### 3-5. 순화·원작 원칙 (CLAUDE.md §1 그대로)
- 원작 줄거리를 따른다. 갈래·선택 없음. 디즈니식 각색(노래, 요정, 키스) 없음.
- 거친 장면은 원작을 해치지 않는 선에서 줄이고 **`notes` 에 적는다**. 팥죽: 호랑이는 바다에 빠져 헤엄쳐 멀리 달아난다(죽지 않는다). 놀이판이 이미 순화한 처리는 그대로 따른다.
- 교훈 한 줄(`moral`)은 마지막 장면의 마지막 문장으로 한 번 읽어 준다. 설교하지 않고 이야기 말투로.
- 실제 아이·가족 캐릭터는 넣지 않는다(창작편 꿀떡이 제외 규칙은 family-tale 메모를 따른다).

### 3-6. 분량 기준
측정(팥죽 ElevenLabs v4 클립, 공백 포함): **한국어 약 350자/분, 영어 약 750자/분**.

| 항목 | 기준 |
|---|---|
| 한 편 읽기 시간 | 5~8분 (장면 전환·컷 포함) |
| 장면 수 | 8~11 |
| 장면당 문장 | 3~6줄 (한 줄 15~45자) |
| 한국어 전체 | 1,500~2,200자 |
| 재사용 대비 배율 | 기존(reuse+trim) 글자의 **1.5~2배** |
| 신규 문장 | 한 편 15~30줄, 500~1,000자 |

팥죽 시범: 10장면 48줄, 한국어 1,616자(기존 1,072 + 신규 544, **1.51배**), 예상 읽기 약 5.5~6분.

## 4. 녹음

- 목소리: **놀이판과 같은 배역, 같은 voice_id** (`voices_from: voice_script_el.json` 의 `voices`·`models`·`settings` 를 그대로 쓴다). 모델 `eleven_v4`. 내레이터는 한 편 안에서 한 사람.
- 생성기: `tools/elevenlabs/gen_tale.py <tale> --read [--lang en]` 옵션을 더한다(구현 보류). `read_script_*.json` 의 `src: new` 줄만 만들고, `reuse` 줄은 놀이판 클립 경로를 그대로 적고, `trim` 줄은 `trim_line.py` 가 둔 경로를 적는다. 출력은 `narration_read_el.js`(`_en`). 해시 규칙이 같아서 같은 문장은 파일을 공유한다. 정리(안 쓰는 mp3 삭제)는 놀이판·읽기 두 대본의 합집합으로 해야 한다.
- 영어 v4 는 같은 말을 두세 번 반복하는 버릇이 있다 → 새 영어 클립은 `mlx_whisper` 로 받아써서 반복을 검사한다(elevenlabs 메모).
- `--dry` 로 글자 수를 먼저 센 뒤 생성한다. 한도에 걸리면 `--max-chars` 로 나눠 만든다.

## 5. 크레딧 추정 (신규 문장만)

- 기준: 팥죽 시범에서 **신규 한국어 ≈ 기존(재사용+자름) 글자의 0.5배**, 영어 신규 ≈ 한국어 신규의 2.4배. ElevenLabs 에 보내는 글자에는 연기 지시 태그가 붙어 한국어는 약 2.1배, 영어는 약 1.46배로 는다(팥죽 실측: 544자 → 1,147자, 1,308자 → 1,911자).
- 동화별 "기존" 은 `voice_script_el.json` 에서 조작·퀴즈 낱말이 든 줄을 뺀 글자 수. 실제 대본을 쓰면 ±20% 달라진다.

## 7. 판단이 필요한 부분 (최대 2개)

1. **Typecast 목소리 배역의 신규 대사**: 팥죽 사물 친구 7명처럼 voices 가 `tc` 인 배역은 ElevenLabs 로 새 대사를 만들 수 없어 시범에서는 신규 대사를 주지 않았다. 이대로 두면 읽기 모드에서 친구는 기존 등장 대사("팥죽 한 그릇 주면 도와줄게!")만 말한다. 더 말하게 하려면 `tools/typecast/gen_tale.py` 에 `--read` 를 더해 Typecast 로 따로 만든다(Typecast Lite 월 20만 자, 비용 작음). → 사용자 결정.
2. **배율 1.5 vs 2**: 팥죽 시범은 1.51배(신규 544자)다. 2배까지 늘리면 신규가 약 1,100자(한·영 보낼 글자 약 6,000자)로 두 배가 된다. 31편 기준 크레딧도 두 배(약 19만 자). 1.5배로 전편을 먼저 만들고 반응을 보는 것을 권한다. → 사용자 결정.

## 8. 확정 사항
- 모드 이름: 읽어 주기(영어 Read to me). 진입은 시작 화면 버튼, 보호자 메뉴 토글 없음.
- 대본 파일 `read_script_el.json`/`read_script_en.json`, 줄마다 `src: reuse|trim|new`.
- 그림 재사용은 동화 js 의 동사 맵(`READ_ACTS`) 방식, 플레이어는 엔진 함수 `T.readPlay` 하나.
- 목소리는 놀이판과 같은 배역·voice_id, eleven_v4. 신규 문장만 녹음.
- 분량: 기존의 1.5~2배, 한 편 5~8분, 장면 8~11, 장면당 3~6줄.
- 우선순위: 무료 고정 4편 → 창작 3편 → 나머지.
- **구현·녹음은 보류**(2026-10-22). 대본만 쌓는다.
