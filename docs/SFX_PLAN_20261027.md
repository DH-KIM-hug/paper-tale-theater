## 고를 때 주의

- 분위기음(새소리, 귀뚜라미, 파도, 시냇물, 바람, 비)은 길게 깔리므로 내레이션보다 훨씬 작게(0.15~0.3) 넣고, 장면 전환 때 서서히 줄인다. 2분 넘는 파일은 10~20초만 잘라 반복한다.
- 천둥·폭풍·눈보라는 "Gentle", "Distant" 계열을 먼저 듣는다. Heavy/Loud 후보는 넣지 않았다.
- freesound_community 파일은 원 녹음 품질이 고르지 않다. 짧게 잘라 앞뒤 잡음을 확인한다.
- 새로 넣은 파일은 sounds/CREDITS.md 에 출처(픽사베이 주소)를 함께 적는다(의무는 아니지만 기존 방식대로).
