### 1-3. 왜 문제인가

**아이 관점**
- 홈 첫 화면에서 아이가 눌러도 되는 것은 큰 동화·화살표·작은 타일뿐인데, 눌러서는 안 되는 것(EN·태그·톱니)이 같은 줄에 같은 크기로 있다. 실수로 누르면 앱이 낯설어진다.
- 보상(종이별)이 쌓이는 느낌이 없다. 완주해도 화면에 아무 일이 없고, 알약 숫자만 바뀐다.
- 잠긴 동화를 누르면 바로 어른 산수가 뜬다. 아이는 왜 안 열리는지 모른다.
- 동화가 31편(공개 8편)으로 늘었는데 고르는 방법은 '위에서 아래로 긴 격자' 하나뿐이다. 세로에서는 세 줄 아래부터 화면 밖(`sim_now.png`).

**보호자 관점**
- 잠자리에 읽어 줄 때 매번 「홈 → 동화 → 시작 화면 → 읽어 주기」 3단계. 읽기 녹음이 없는 동화는 버튼이 아예 없어 들어가 봐야 안다.
- 설정이 한 시트에 섞여 있어 "언어 바꾸기", "오늘 몇 분까지", "구매 복원"을 찾을 때마다 전부 읽어야 한다. 가로 낮은 화면(844×390)에서는 시트가 화면보다 길다(AUDIT #26).
- 보호자용 글(태그 설명, 한 줄 소개, 10px 딱지)이 아이 화면에 섞여 있고, 정작 보호자가 필요한 정보(이번 주 무료가 언제 바뀌나, 기다무가 언제 열리나, 개인정보 방침, 버전)는 없다.

**규칙 관점**
- §7-5 "화면 전체는 한 종이, 장식 소품 금지": 끝 화면의 리본·박음질·도장, 홈의 '새 그림' 임시 딱지(review.js), 10px 글자 딱지가 어긋난다.
- 어린이 카테고리: 돈·링크·연결은 부모 확인 뒤에 두었지만, 확인이 4지선다 산수라 아무 데나 누르면 평균 4번에 통과한다(AUDIT #7). 통과 직후 가장 큰 버튼이 결제다(AUDIT #8).

결론: **탭이 없어서 '아이 것'과 '보호자 것', '놀이'와 '잠자리'와 '모은 것'이 한 화면에 겹쳐 있다.** 이 셋을 최상위에서 갈라 주고, 보호자 영역은 탭이 아니라 잠긴 문 뒤에 두는 것이 이 기획의 뼈대다.

## 2. 최상위 구조 권장안

### 2-1. 권장: 아이용 탭 3개 + 보호자 문 1개

```
아이가 쓰는 최상위 (탭 막대)          보호자만 (탭이 아님)
┌──────────┬──────────┬──────────┐    ┌───────────────┐
│  동화     │  잠자리   │  종이별 │    │ 톱니 1초 꾹   │
│ (놀이 서가)│(읽어 주기) │ (모은 것) │    │ → 보호자 영역 │
└──────────┴──────────┴──────────┘    └───────────────┘
```

| 탭 | 한 줄 정의 | 아이가 하는 일 | 왜 최상위인가 |
|---|---|---|---|
| **동화** | 놀이판 서가. 지금 홈의 큰 동화 + 목록 | 그림을 보고 고른다, 톡 하면 제목을 듣고, 다시 톡 하면 들어간다 | 앱의 본체. 첫 탭이자 기본 탭 |
| **잠자리** | 읽어 주기 서가. 읽기 대본·녹음이 있는 동화만 | 오늘 들을 이야기를 고른다(보호자와 함께). 들어가면 바로 읽어 주기 시작 화면 | 쓰는 시간대(밤)와 자세(누워서, 화면 꺼짐)가 다르다. 보호자가 한 번에 닿아야 한다. 읽어 주기가 있는 동화만 모아 보여 줘야 "들어가 봐야 아는" 문제가 사라진다 |
| **스티커북** | 퍼즐 스티커 갤러리와 종이별 접시 | 별이 몇 개인지 본다, 5개면 동화를 하나 고른다, 완주 스티커를 구경한다 | 3~4세에게 "내 것"이 쌓이는 자리가 있어야 보상이 작동한다. 교환도 여기서 한다 |

**보호자 영역은 탭이 아니다.** 톱니(오른쪽 위, 1초 꾹)로만 들어간다. 안에서 돈·연결·외부 링크로 가는 길에는 부모 확인(산수)을 한 번 더 둔다. 이유: 탭은 "아이가 눌러도 되는 것"이어야 한다. 보호자 탭을 두면 아이가 반복해서 눌러 부모 확인 쪽지를 계속 띄운다.

### 2-2. iOS 관례 근거

- Apple HIG(탭 막대): 최상위 구역이 2~5개일 때 탭 막대를 쓰고, 탭은 "서로 다른 종류의 내용"이어야 하며, 한 탭 안의 상태 전환(필터·모드)에 쓰지 않는다. 동화/잠자리/종이별은 내용과 쓰임이 다르고, 태그 필터는 탭이 아니다.
- iPhone: 탭 막대는 화면 아래. 아이패드: iPadOS 18부터 시스템 탭 막대가 화면 위로 올라가고 사이드바로 펼쳐지는 것이 기본이다. 그러나 이 앱은 글을 못 읽는 아이가 쓰므로 **위쪽 작은 글자 탭은 맞지 않는다.** 아이패드에서는 사이드바(옆 레일)와 아래 막대 중 고른다(§2-4).
- 어린이 카테고리 지침: 결제·외부 링크·개인정보 입력 앞에 부모 게이트. 설정 자체를 게이트 뒤에 두는 것은 허용이며 널리 쓰인다(어린이 앱들의 "어른용" 모서리 버튼 + 길게 누르기 또는 산수).
- 어린이 앱 관례(PBS Kids·Khan Kids·Sago Mini류): 큰 그림 탭 3~4개, 글자는 보조, 어른 영역은 모서리의 작은 잠긴 버튼.

### 2-3. 탭 막대의 종이 표현 (§7-5 "구멍이나 새김으로만")

- 탭 막대는 따로 붙인 판이 아니라 **같은 크림 종이의 일부**다. 경계선을 긋지 않는다.
- 탭 하나 = 종이에 뚫린 **둥근 구멍**(짧은 변 88px, 아이폰 80px). 구멍 안에 탭 그림(생성 페이퍼아트)이 보인다.
  - 선택한 탭: 구멍이 **열려** 색 그림이 보이고 안쪽 위 가장자리에 음각 그림자(홈 썸네일과 같은 `.thumb::after` 문법).
  - 선택하지 않은 탭: 같은 자리에 **눌린 자국(새김)**만. 그림은 종이와 같은 계열 한 톤 어두운 단색 실루엣(필터 `duoM-l`). 색이 없으니 "지금 아님"이 한눈에 보인다.
- 전환: 누른 구멍이 열리며(아이리스 0.25초) 색이 차고, 이전 구멍은 오므라들어 새김만 남는다. 종이 소리 `paper_tap`, 그리고 탭 이름을 한 번 읽어 준다("잠자리"). 탭은 **한 번 톡으로 바로 바뀐다**(두 번 톡은 카드에만).
- 글자: 구멍 아래 보호자용 작은 이름(13px, `--text-2`, 자간 넓게). 아이는 그림으로 안다.
- 알림: 스티커북 탭 구멍 가장자리에 작은 구리색(`--copper #C98A5B`) 점 하나 — 5개가 모였을 때만. 숫자 배지는 쓰지 않는다.
- 금지: 막대 배경색, 선, 그라데이션, 양각 탭 버튼.

### 2-4. 아이패드에서 탭 위치: 가로 = 왼쪽 레일, 세로·아이폰 = 아래 막대

| | 아이패드 가로 | 아이패드 세로 | 아이폰 세로 | 아이폰 가로 |
|---|---|---|---|---|
| 탭 자리 | **왼쪽 레일** 폭 128px(안전 영역 포함) | **아래 막대** 높이 104px + 홈 인디케이터 | 아래 막대 88px + 안전 영역 | 왼쪽 레일 96px |
| 구멍 크기 | 88px | 88px | 80px | 80px |
| 로고 | 레일 맨 위 작게 | 왼쪽 위 | 왼쪽 위 | 레일 위 |
| 톱니 | 오른쪽 위 고정 | 오른쪽 위 고정 | 오른쪽 위 고정 | 오른쪽 위 고정 |

가로에서 레일을 고른 이유: 가로는 세로 픽셀이 귀하다(1024 중 큰 동화 16:9가 430~480px). 아래 막대 104px을 빼면 선반 한 줄이 사라진다. 가로 폭 1366은 넉넉해서 128px 레일을 떼어도 선반 7칸이 그대로다. 아이패드를 양손으로 들면 왼손 엄지가 왼쪽 가장자리 가운데에 닿는다. HIG의 아이패드 사이드바 관례와도 맞는다. 세로는 폭이 귀하고 아래쪽이 엄지 영역이라 막대가 맞다. **레일과 막대는 같은 구멍 세 개를 세로/가로로 돌린 것**이라 그림과 코드가 하나다.

| 지금처럼 탭 없이 홈 하나 + 모드 전환 | 읽어 주기 입구가 동화마다 묻히고, 보상을 볼 곳이 없고, 보호자 스위치가 아이 손에 남는다 |

| 4탭(동화 / 잠자리 / 스티커북 / 찾기) | '찾기(태그)'는 글자 기반 보호자 기능. 3~4세에게 탭 4개는 많다. 찾기는 보호자 영역의 필터로 |
| 4탭(… / 설정) | 위와 같은 이유로 설정 탭 금지. 어린이 앱 심사에서도 설정은 게이트 뒤가 안전 |
| 잠자리를 보호자 메뉴 토글로 | READ_MODE §1에서 이미 버린 안. 그날그날 고르는 선택이라 숨은 토글이 맞지 않다 |

## 3. 화면 목록

화면 번호는 흐름(§4)과 표(§5)에서 그대로 쓴다. 와이어프레임은 아이패드 가로(1366×1024)와 세로(1024×1366)를 기준으로 그리고, 아이폰(390×844 / 844×390)은 달라지는 점만 적는다. 모든 화면의 바탕은 크림 종이 한 장이며 아래 와이어프레임의 테두리는 화면 가장자리일 뿐 선이 아니다.

공통 요소 약속
- `[⚙]` 톱니: 오른쪽 위 56px, 회색(`--gear`), 1초 꾹 누르면 둘레 링이 차오르며 보호자 영역(S9). 짧게 누르면 "1초 동안 꾹 누르세요" 쪽지 1.8초.
- `(( ))` 둥근 구멍(음각) 안의 그림. `[  ]` 양각 종이 버튼. `~~~` 가로 스크롤 줄.
- 탭 레일/막대는 S1·S2·S3에서만 보인다. 동화 안(S5~S8)과 보호자 영역(S9~S13)에서는 숨긴다.

### S0. 스플래시

- 목적: 앱이 켜질 때 6.4초. 언덕·나무가 내려앉고 토끼와 거북이 → 공주들의 정원 → 앱 이름 순으로 이어진다. 2026-10-27 사용자 피드백(너무 빠름)에 따라 1.4초 압축 재생을 없애고 미리보기와 같은 원래 속도로 재생한다. 안내 글자 없이 저절로 끝나며, 톡하면 바로 건너뛴다. 같은 회차에서는 다시 보이지 않는다.
- 누가: 아이·보호자 모두.
- 첫 실행 한 번: 스플래시가 걷힌 뒤 오른쪽 위에서 쪽지 하나가 4초 머문다 — "보호자님: 오른쪽 위 톱니를 1초 누르면 설정이에요" + 톱니 그림. 톡 하면 바로 사라진다. 그 밖의 온보딩 화면은 두지 않는다.
- 앱 모드 첫 실행 때 서버가 있으면 무작위 계정을 조용히 만든다(실패해도 아무 표시 없이 오프라인 계속).
- 아이폰: 같은 연출을 세로 화면 비율에 맞춰 배치한다.

### S1. 동화 탭 (놀이 서가) — 기본 탭

- 목적: 놀이판 동화를 그림으로 고른다. 공개 동화가 31편 이상으로 늘어도 세 줄 안에서 고를 수 있어야 한다.
- 누가: 아이(고르기), 보호자(옆에서 제목 읽어 주기 소리 듣기).
- 요소
  1. 큰 동화(히어로): 지금 고른 동화 한 편. 가로는 16:9 키아트(`_key_wide`), 세로는 4:3 타일. 밑에 제목(오린 글자)만. 보호자용 한 줄 소개는 뺀다(보호자 영역 S9의 동화 정보로). 좌우 화살표 72px.
  2. 서가 줄(가로 스크롤 줄 여러 개, 세로 스크롤): 줄 머리에 큰 그림 스티커(64px)와 작은 글자. 줄 순서: **이번 주 무료** → **최근 본** → **창작 동화** → **공주** → **동물 이야기(이솝)** → **우리나라 옛이야기** → **세계 옛이야기**. 비는 줄은 숨긴다. 같은 동화가 여러 줄에 나와도 된다.
  3. 타일: 구멍 속 그림 + 제목. 상태는 **그림 딱지**로: 잠김 = 종이 마개 + 자물쇠(28px), 이번 주 무료 = 별, 만드는 중 = 가위와 종이(앱 모드에서는 '만드는 중' 2~3장만 예고로, 나머지 숨김). 글자 딱지(10px)는 모두 뺀다.
  4. 머리줄: 로고(왼쪽), 톱니(오른쪽 위). EN·태그·종이별 알약은 없다.
- 동작: 작은 타일 톡 = 제목 읽기 + 큰 동화로 올라옴. 큰 동화 톡 = 조리개 닫히며 S5로. 잠긴 타일 톡 = S4(잠김 쪽지). 만드는 중 톡 = 마개 들썩 + "곧 열려요". 스크롤해서 큰 동화가 가려지면 머리줄 아래에 얇은 제목 띠만 남고, 타일 톡 때 맨 위로 부드럽게 올라온다.
- 빈 상태: (보호자 영역에서 필터를 걸어 결과가 0) 큰 그림 하나(빈 선반 위 종이 새 한 마리)와 음성 "이 조합의 이야기는 아직 없어요", 큰 버튼 [전체 보기]. 필터는 보호자 영역에서만 걸 수 있으므로 아이 혼자 이 화면에 들어갈 일은 없다.
- 잠긴 상태: 타일 자체는 보이되 마개로 덮인다. 큰 동화로는 올라오지 않는다(올라오면 '시작'할 수 있는 것처럼 보인다). 대신 S4.
- 오프라인: 모든 그림·소리가 번들 안이라 달라지는 것 없음. 서버 동기화만 조용히 멈춤.

### S2. 잠자리 탭 (읽어 주기 서가)

- 목적: 읽어 주기(READ_ACTS + 읽기 녹음)가 준비된 동화만 모아, 보호자가 한 번에 고르고 바로 틀 수 있게 한다.
- 누가: 보호자(주로), 아이(고르기).
- 요소
  1. 머리 그림: 종이 구멍 하나에 초승달·별·베개(생성 그림). 밤 분위기지만 **종이 색은 그대로 크림**(한 종이 원칙, 다크 모드는 나중).
  2. 목록: 큰 타일 한 줄(가로는 3열, 세로는 2열) 격자. 한 화면에 6~8편, 세로 스크롤. 타일에 **읽기 시간**(예: "6분")을 보호자용 작은 글자로.
  3. 줄 머리 두 개만: **최근 들은** / **모든 이야기**(읽기 준비된 것). 잠긴 동화는 여기서도 마개로 보이고 S4로.
  4. 영어 모드일 때 영어 읽기 녹음이 없는 동화는 뒤로 정렬하고 '한국어만' 작은 표시.
- 동작: 타일 톡 = 제목 읽기 + 살짝 들림. 같은 타일 다시 톡 = S5의 **읽어 주기 변형**(큰 버튼이 '읽어 주기')으로 이동. 동화 페이지는 별도 문서라 iOS 오디오 허락을 받을 톡이 그 페이지 안에서 한 번 필요하다 → 시작 화면을 건너뛸 수 없다(READ_MODE §10-4).
- 빈 상태: 읽기 준비된 동화가 0이면(초기 빌드) 머리 그림 + "읽어 주기는 준비 중이에요" + [동화 탭으로].
- 잠긴 상태: 마개 타일 → S4.
- 오프라인: 변화 없음(녹음은 번들).

### S3. 스티커북 탭 (모은 것) — 2026-10-27 사용자 결정으로 다시 씀

- 목적: 아이가 모은 것이 쌓이는 자리. **퍼즐 스티커 갤러리** + 종이별 접시.
- 누가: 아이.
- 두 가지 보상의 구분
  - **스티커**: 아이가 **직접 눌러서(놀이로) 처음 끝까지 한 동화**마다 1장. 읽어 주기(잠자리)·자동 재생 완주는 주지 않는다(사용자 결정). 한 번 받으면 끝(같은 동화를 다시 해도 새로 생기지 않음). 잠금을 풀지 않는 순수 기록.
  - **종이별**: 놀이 완주 하루 1개, 5개로 잠긴 동화 1편 열기(MONETIZATION.md). 이름은 '구름과자'에서 바꿈(담배 은어로 오인 우려).
- 퍼즐판 5개(동화 31편이 겹치지 않게 하나씩 속함, `tales/catalog.js` 의 origin·also 로 정함)

| 퍼즐판 | 조각 | 동화 |
|---|---|---|
| 공주 퍼즐 | 8 | also: princess 전부(신데렐라·백설공주·인어공주·미녀와 야수·완두콩 공주·라푼젤·개구리 왕자·잠자는 숲속의 공주) |
| 우리 옛이야기 | 6 | origin: korean |
| 이솝 동물 친구 | 6 | origin: aesop |
| 세계 명작 | 8 | origin: world 중 공주 아닌 것 |
| 창작 동화 | 3 | origin: original |

  - 판마다 큰 그림 한 장(생성 페이퍼아트)을 조각 수로 나눈다. 스티커를 받으면 그 조각 자리에 동화 스티커(인물 그림)가 붙고, 판을 다 채우면 스티커들이 뒤집혀 **완성 그림**이 나타난다(종이 뒤 광원 연출 한 번 + 음성 "공주 퍼즐을 다 모았어요!").
  - 새 동화가 나오면 해당 판에 조각이 하나 늘어난다. 이미 완성한 판은 '완성' 표시를 지우지 않고 새 조각 자리만 빈 새김으로 덧붙는다(아이가 잃는 느낌이 없게).
  - **빈 조각은 실루엣 새김만**. 자물쇠·가격·'사면 채울 수 있어요' 같은 문구는 아이 화면에 절대 두지 않는다(어린이 카테고리: 아이에게 구매를 유도하지 않음). 주간 무료 로테이션·기다무·종이별로 시간이 지나면 돈 없이도 모든 판을 채울 수 있다(로테이션 4편/주면 몇 주 안에 전 편이 한 번씩 무료로 돈다).
- 화면 요소
  1. 위: 퍼즐판 다섯 개가 가로 줄(아이패드 가로는 한눈에 5개, 세로·아이폰은 가로 넘김). 판 톡 = 그 판을 크게.
  2. 큰 판 보기: 조각 격자(2×4, 2×3, 1×3). 스티커 톡 = 동화 제목 읽기 + 스티커 들썩(들어가지는 않음). 빈 조각 톡 = "아직 비어 있어요" 한 번.
  3. 오른쪽(세로는 아래) 작은 **종이별 접시**: 별 0~5개, 보호자용 작은 글자 "3 / 5". 5개면 [동화 하나 열기](112px) → S12(종이별 모드).
- 끝 화면(S7) 연출: 놀이 완주 때 스티커가 처음이면 그림 창에서 스티커가 떨어져 나와 오른쪽 아래 스티커북 구멍으로 날아간다 + "스티커를 받았어요!" 종이별도 받는 날이면 스티커 다음에 별이 접시로(한 번에 하나씩, 0.8초 간격).
- 빈 상태: 모든 판이 실루엣 새김. 음성 "동화를 끝까지 하면 스티커가 생겨요".
- 잠긴 상태: 없음(이 탭은 잠기지 않는다).
- 오프라인: 변화 없음. 연결된 다른 기기의 스티커·별은 온라인이 되면 합쳐진다.
- 웹 공개판: 스티커는 웹에서도 모은다(기기 안 저장). 종이별 접시와 [동화 하나 열기]는 앱 모드에서만.
- 저장: 동기화 state 의 `stickers`(합집합). SYNC_API.md 참고.

아이패드 가로
```
┌────┬───────────────────────────────────────────────────────────────────┐
│로고│                                                        [⚙]        │
│    │  ((공주 3/8)) ((옛이야기 2/6)) ((이솝 4/6)) ((세계 1/8)) ((창작 0/3))│
│(동화)│  ┌─────────────────────────────────────────┐   ┌──────────────┐  │
│    │  │ [스티커][스티커][ 빈 ][ 빈 ]             │   │ (( 별 접시 )) │  │
│(잠자리)│ │ [스티커][ 빈 ][ 빈 ][ 빈 ]   공주 퍼즐  │   │  ★ ★ ★ · ·   │  │
│    │  └─────────────────────────────────────────┘   │    3 / 5      │  │
│((스티커북))│                                          └──────────────┘  │
└────┴───────────────────────────────────────────────────────────────────┘
```
세로: 판 줄(가로 넘김) → 큰 판 → 별 접시 순서로 위에서 아래. 아이폰: 같은 순서, 큰 판 2열.

### S4. 잠김 쪽지 (아이용)

- 목적: 잠긴 동화를 눌렀을 때 아이에게 먼저 그림·소리로 알리고, 보호자가 있을 때만 다음으로 간다. 지금처럼 산수가 바로 뜨지 않는다.
- 누가: 아이(보고 듣기), 보호자(다음 단계).
- 요소: 화면 가운데 종이 한 장(모달). 그 동화 타일(마개 덮임) + 자물쇠 그림 + 음성 "이 동화는 잠겨 있어요. 어른과 함께 열어요." 보호자용 한 줄: "이번 주 무료는 월요일마다 바뀌어요." 버튼: [닫기](아이, 큰 동그라미) / [어른이 열기](작게, **1초 꾹** → S10 부모 확인 → S11). 종이별이 5개면 [종이별로 열기](아이용, 큰 버튼) → S12.
- 아이폰: 같은 쪽지, 세로로 쌓음.

### S5. 동화 시작 화면 (동화 페이지 안)

- 목적: 한 동화의 표지. 아이가 누를 것은 하나.
- 누가: 아이.
- 두 변형(같은 화면, 들어온 탭에 따라 큰 버튼이 바뀐다)
  - 동화 탭에서: 큰 [▶ 이야기 시작](237×68 이상) 하나. 보조로 작은 [책 읽어 주기](읽기 준비된 동화만).
  - 잠자리 탭에서(`?read=1`): 큰 [책 읽어 주기] 하나. 보조로 작은 [▶ 놀이].
- 그 밖: 왼쪽 위 집 아이콘(56px, 홈으로 — 지금 '처음으로' 알약 대신). '자동 재생' 알약은 뺀다(보호자 영역 설정으로만, 켜져 있으면 시작 화면 모서리에 작은 표시).
- 시작 화면이 열리면 제목을 한 번 읽어 주고, 5초 무입력이면 손가락 힌트를 큰 버튼 위에(§2 엔진 규칙을 시작 화면에도).
- 키아트는 가로 `_key_wide`, 세로 `_key_tall`. 글자·버튼 자리는 종이색으로 비운다(AUDIT #10·#11).
- 아이폰 가로: 키아트를 왼쪽 60%, 제목·버튼을 오른쪽 40%에.

```
가로                                             세로
┌────────────────────────────────────┐          ┌──────────────────┐
│[집]                                │          │[집]              │
│      ((  키아트 16:9  ))           │          │  ((  키아트  ))   │
│                                    │          │  ((  3:4     ))   │
│  팥죽할멈과 호랑이     [▶ 이야기 시작] │          │                  │
│                        (책 읽어 주기)│          │ 팥죽할멈과 호랑이  │
└────────────────────────────────────┘          │ [▶ 이야기 시작]   │
                                                │  (책 읽어 주기)   │
                                                └──────────────────┘
```

### S6. 동화 진행 (장면)

- 지금 엔진 그대로. 이 기획에서 바꾸는 것: 왼쪽 위 집 아이콘은 1초 꾹(보호자용 '끝내기', 지금 `#finBtn`과 통합), 놀이 시간이 되면 장면 전환 때 S13(쉬는 화면). 읽어 주기 회차에서는 화면이 꺼져도 끝까지 읽는다(READ_MODE §10-4, 변경 없음).
- 잠자리 회차에 쉬는 화면이 끼어들지 않게 할지 → §7 판단.

### S7. 끝 화면 (뒷표지) + 종이별 받기

- 목적: 끝났다는 느낌, 보상, 다음 행동 둘(홈 / 한 번 더).
- 누가: 아이.
- 요소: 종이 한 장(안쪽 종이 `#EBDFC8` 유지) + 끝 그림 창(`_back_*`) + '만세!'(오린 글자) + 동그라미 둘(홈 96px, 한 번 더 96px). **리본·박음질·도장은 뺀다**(소품 금지). 색종이는 처음 2초만.
- 종이별 연출(앱 모드, 오늘 처음 완주): '만세!' 1초 뒤 종이별 한 개가 그림 창에서 튀어나와 **오른쪽 아래 작은 접시**(S3와 같은 그림, 112px)에 톡 내려앉는다. 음성 "종이별 하나 받았어요!" 접시에 지금 개수만큼 별이 보인다. 5개째면 접시 뒤가 밝아지고 "다섯 개! 동화를 하나 열 수 있어요" + 접시 톡 → 홈의 스티커북 탭(S3)으로.
- 오늘 이미 받았으면: 접시는 보이되 별이 날아오지 않고 음성도 없다(실망 문구 없음). 접시 톡 = S3.
- 한 번 더 = 같은 모드로 다시(읽기 회차면 읽기).
- 아이폰: 같은 배치, 접시를 홈 버튼 옆으로.

```
┌────────────────────────────────────────────┐
│                                            │
│     ((  끝 그림 창  ))        만세!         │
│                               (집) (↻)     │
│                                            │
│                               ((접시 o o o))│  ← 종이별이 날아와 앉는 자리
└────────────────────────────────────────────┘
```

### S8. 전환 (조리개)

- 홈 카드 → 조리개 닫힘(크림) → 동화 시작 화면에서 조리개 열림. 종이 색은 모두 `#F5EFE9`로 같게(AUDIT #6). 탭 전환은 조리개가 아니라 구멍 열림/오므림(§2-3).

### S9. 보호자 영역 (톱니 1초 꾹)

- 목적: 보호자 설정과 정보를 한 곳에, 성격별로 나눠서. 돈·연결·외부 링크는 안에서 한 번 더 S10.
- 누가: 보호자.
- 구조: 아이패드는 **설정 앱식 2열**(왼쪽 항목 목록, 오른쪽 내용). 아이폰은 1열 목록 → 눌러 들어가는 쪽(push). 전체는 크림 종이 위에 얹힌 한 장의 큰 종이(모달 전체 화면), 왼쪽 위 [닫기].
- 항목(위에서 아래로, 자주 쓰는 순서)

| 항목 | 내용 | 게이트 |
|---|---|---|
| 소리와 글 | 제목·탭 이름 읽어 주기(끌 수 없음, 설명만), 대사 자막 보이기, 자동 재생(설명: "놀이 조작 없이 흘러가요. 잠자리에는 '잠자리' 탭의 읽어 주기를 써요") | 없음 |
| 놀이 시간 | 끄기/10/15/20/30분, "하루 기준, 시간이 되면 조용한 쉬는 화면" | 없음 |
| 언어 | 한국어 / English (두 칸). 바꾸면 글·목소리·동화 정렬이 바뀐다. "영어 자료가 없는 동화는 한국어로 나와요" | 없음 |
| 동화 찾기 | 지금의 태그 두 줄(이야기 종류·배우는 것)과 동화 31편 목록 + 한 줄 소개. 체크한 필터는 동화 탭 서가에 적용되고 머리줄에 "필터 중" 작은 표시, [필터 지우기] | 없음 |
| 이용권 | 이번 주 무료 4편(월요일 갱신), 열어 둔 동화, 기다무(남은 날 수 / 지금 열 수 있음 → [한 편 고르기]), 종이별 개수, [모든 동화 열기 $4.99], [구매 복원] | 고르기·구매·복원 앞 S10 |
| 기기 연결 | 설명 + [코드 만들기] [코드 넣기] → S11-2 | S10 |
| 정보 | 개인정보 처리방침(앱 안 문서 보기, 외부 링크 아님), 버전, 문의 이메일(글자), 그림·소리 출처(CREDITS) | 외부로 나가는 링크가 있다면 S10 |
| 기록 | [동화 진행 기록 지우기] [이 기기의 종이별·기록 초기화](확인 두 번) | S10 |

- 아이패드 가로 와이어프레임

```
┌───────────────────────────────────────────────────────────────────────┐
│ [닫기]  보호자                                                          │
│ ┌──────────────┬──────────────────────────────────────────────────────┐│
│ │ ● 소리와 글   │  소리와 글                                            ││
│ │   놀이 시간   │  [v] 대사 자막 보이기                                 ││
│ │   언어        │  [ ] 자동 재생  — 놀이 조작 없이 흘러가요…              ││
│ │   동화 찾기   │  제목·탭 이름은 항상 읽어 줘요(아이가 글을 못 읽어요)     ││
│ │   이용권      │                                                      ││
│ │   기기 연결   │                                                      ││
│ │   정보        │                                                      ││
│ │   기록        │                                                      ││
│ └──────────────┴──────────────────────────────────────────────────────┘│
└───────────────────────────────────────────────────────────────────────┘
```
세로: 같은 2열(왼쪽 목록 폭 280). 아이폰 세로: 목록 한 장 → 항목을 누르면 내용 장이 오른쪽에서 들어오고 [<] 로 돌아옴. 아이폰 가로: 2열.
- 오프라인: 이용권의 가격은 StoreKit 값이 올 때까지 "가격 확인 중", 기기 연결은 "서버에 닿지 않아요" 문구.

### S10. 부모 확인 (공통 부품)

- 목적: 돈·연결·외부·초기화 앞의 문. 아이가 우연히 못 넘게.
- 요소: "어른이 확인해 주세요" + 두 자리 곱셈(6~9단) + 답 4개. **정답 버튼을 1.5초 꾹 눌러야** 통과(톱니와 같은 링 게이지). 틀리면 쪽지가 닫히고 30초 동안 다시 열리지 않는다(아이의 무작위 톡 방지). 쉬는 화면의 '+10분' 확인도 이 부품을 쓴다.
- 통과하면 **지금 시트 안에서만 유효**(닫으면 다시 묻는다).
- 아이폰: 같은 쪽지.

### S11. 이용권 열기 (잠긴 동화에서 들어왔을 때)

- 목적: 잠긴 동화 한 편을 두고 보호자가 셋 중 고른다. 결제가 가장 큰 버튼이 되지 않게.
- 요소: 위에 그 동화 타일과 제목. 세 칸이 같은 크기로 나란히: **이번 주 기다리기**(무료 로테이션 설명, 월요일), **기다무·종이별로 열기**(열 수 있을 때만 활성, → S12), **모든 동화 열기 $4.99**(비소모성, 한 번). 아래 [다음에](기본 포커스) / [구매 복원](작게).
- 가격은 `Entitlements.PRICE`(StoreKit 지역 통화).
- 결제 실패/취소: "결제가 끝나지 않았어요" 한 줄, 쪽지는 그대로.
- 아이폰: 세 칸을 세로로.

### S12. 동화 고르기 (기다무 / 종이별)

- 목적: 열 수 있는 잠긴 동화 중 한 편을 고른다.
- 누가: 종이별 모드 = 아이(게이트 없음, §7 판단), 기다무 모드 = 보호자(S10 뒤).
- 요소: 타일 격자(가로 4열, 세로 3열). 톡 = 제목 읽기 + 눌림. 같은 타일 다시 톡 또는 아래 [열기]. 종이별 모드면 위에 접시(5개)가 있고 열 때 별 5개가 타일로 날아가 마개가 떨어진다. 음성 "'○○'이 열렸어요!" → 동화 탭(S1)으로 가며 그 동화가 큰 동화로.
- 빈 상태: 열 수 있는 동화가 없으면 "지금 열 수 있는 잠긴 동화가 없어요" + [닫기]. 종이별은 그대로 남는다.

### S11-2. 기기 연결

- 목적: 로그인 없이 두 기기를 같은 기록으로 묶기(SYNC_API).
- 요소: 두 큰 버튼 [이 기기에서 코드 만들기] / [다른 기기의 코드 넣기]. 만들기: 8자리 코드를 큰 글자(48px, 4-4로 띄움) + 남은 시간(10분 카운트다운) + "다른 기기의 '코드 넣기'에 입력하세요". 넣기: 8칸 입력(대문자, 혼동 글자 제외 안내), [연결하기]. 결과 문구는 지금 `MSG_LINK` 그대로.
- 오프라인: 두 버튼 비활성 + "인터넷이 있어야 해요".

### S13. 쉬는 화면 (놀이 시간)

- 목적: 시간이 되면 조용히 멈춘다. 알람 없음.
- 요소: 종이 구멍 안에 **잠든 인물 한 장**(기존 스프라이트, 예: 사자 잠), 오린 글자 "오늘은 여기까지", 큰 동그라미 [집]. 한 번만 조용히 읽어 준다. 오른쪽 아래 작은 [어른이 +10분] → S10.
- 잠자리 읽기 회차: §7 판단(권장: 읽는 중에는 끼어들지 않고 끝 화면 뒤에 적용).

### 화면 수

아이용 8(S0 스플래시, S1~S3 탭 셋, S4 잠김 쪽지, S5~S7 동화 페이지 셋) + 보호자 5(S9, S10, S11, S11-2, S12) + 공통 2(S8 전환, S13 쉬는 화면) = **15 화면**(S5의 두 변형은 하나로 세고, 상태별 분기는 제외).

## 4. 핵심 흐름

### 4-1. 첫 실행
1. 앱 아이콘 → S0 스플래시 6.4초(자동 종료).
2. 앱 모드면 뒤에서 `POST /v1/account`(실패 무시). `firstRun` 날짜 저장(기다무 기준).
3. S1 동화 탭. 큰 동화 = 카탈로그 첫 공개 동화. 첫 실행 1회 보호자 쪽지 4초.
4. 아이가 타일 톡 → 제목 음성 → 큰 동화 톡 → S8 조리개 → S5 → [이야기 시작] → S6 → S7.

### 4-2. 잠긴 동화 → 부모 확인 → 구매/기다무/종이별
1. S1 또는 S2에서 마개 타일 톡 → S4 잠김 쪽지(음성 "잠겨 있어요. 어른과 함께 열어요").
2. 아이 혼자: [닫기] → 돌아감. 종이별 5개면 [종이별로 열기] → S12(종이별) → 열림 → S1.
3. 보호자: [어른이 열기] 1초 꾹 → S10 부모 확인(정답 1.5초 꾹) → S11 이용권 열기.
4. S11에서 (가) 기다리기 = 닫기, (나) 기다무 가능하면 → S12(기다무) → 열림, (다) 구매 → StoreKit 시트 → 성공 시 모든 마개가 떨어지는 연출 + 음성 "모든 동화가 열렸어요!" → S1.
5. 동화 주소로 직접 들어온 잠긴 경우(`guard()`): 홈으로 보내며 S4부터.

### 4-3. 잠자리 읽어 주기
1. S2 잠자리 탭 → 타일 톡(제목) → 다시 톡 → S8 → S5 읽기 변형.
2. [책 읽어 주기] 톡(이 톡이 iOS 오디오 허락) → 읽기 시작. 잠금 화면에 제목·표지·일시정지(Media Session).
3. 화면을 꺼도 끝까지 읽음 → S7 끝 화면(종이별 받기 포함) → 그대로 두면 소리 없이 멈춤. 자동으로 다음 동화로 이어 읽기는 §7 판단.
4. 홈으로 돌아오면 마지막 탭(잠자리)로 돌아온다(`sessionStorage`에 탭 저장).

### 4-4. 동화 완주 → 종이별 받기
1. S6 끝 → `finishPlay()` 참이면 S7에서 '만세!' 1초 뒤 별 한 개가 접시로 날아감 + 음성.
2. 접시 개수 갱신. 5개째면 접시 뒤 밝아짐 + 음성 + 스티커북 탭 구멍에 구리색 점.
3. 오늘 이미 받았으면 연출 없음. 웹(비앱 모드)에서는 접시 자체를 숨긴다.

### 4-5. 종이별 5개 교환
1. S3 스티커북 탭 [동화 하나 열기] (또는 S4·S7 접시에서) → S12(종이별 모드).
2. 타일 톡(제목) → 다시 톡/[열기] → 별 5개가 날아가 마개가 떨어짐 → `cloudUnlock()` → 음성 → S1로 이동, 그 동화가 큰 동화.
3. 실패(동시에 다른 기기에서 썼거나 열 수 없음): "열지 못했어요. 다시 골라 주세요", 별은 그대로.

### 4-6. 기기 연결
- 코드 만들기: S9 기기 연결 → S10 → S11-2 [코드 만들기] → 8자리 + 10분 카운트다운. 시간이 지나면 코드 숨기고 "새로 만들어 주세요".
- 코드 입력: 다른 기기에서 S9 → S10 → S11-2 [코드 넣기] → 8자 입력 → [연결하기] → 성공 문구, 동화 탭 마개·접시 개수 갱신. 실패 코드는 `MSG_LINK`.

### 4-7. 언어 바꾸기
1. S9 언어 → English 톡 → 즉시 적용: 로고·탭 이름·보호자 글, 홈 제목 음성(영어 녹음), 동화 정렬(영어 자료 있는 편 먼저, 없는 편은 '한국어만' 표시).
2. 동화 안은 `lang` 키로 영어 대사·녹음. 영어 읽기 녹음이 없는 동화는 S2에서 뒤로.
3. 홈에는 언어 스위치가 없다.

### 4-8. 놀이 시간 타이머 → 쉬는 화면
1. S9 놀이 시간 20분 선택(하루 기준).
2. 누적 20분이 되면 다음 장면 전환 때(또는 S5에서 시작을 눌렀을 때) S13.
3. 아이: [집] → S1. 보호자: [어른이 +10분] → S10 → 10분 연장, 이어 진행.
4. 잠자리 읽기 회차: 권장안은 읽는 중 끼어들지 않음(§7).

4. **종이별**: S3 탭(접시·책장), S7 끝 화면 연출(리본·도장 제거 포함), 완주 기록 로컬 키. 확인: 하루 1개 제한, 5개 교환, 웹 모드 숨김.

8. **아이폰 구도**: 가로 844×390 레일 + 좌우 2분할, 세로 2.5칸. 쪽지류 세로 쌓기.

## 확정 사항 (이 문서 기준, 사용자 확인 전)

- 최상위: 아이용 탭 3(동화·잠자리·스티커북) + 보호자 문 1(톱니 1초 꾹). 보호자 탭 없음.
- 탭 표현: 같은 크림 종이의 구멍 3개. 선택 = 열린 구멍에 색 그림, 비선택 = 새김. 한 번 톡으로 전환 + 이름 읽기.
- 아이패드 가로 = 왼쪽 레일 128px, 세로·아이폰 세로 = 아래 막대, 아이폰 가로 = 왼쪽 레일 96px. 톱니는 늘 오른쪽 위.
- 홈에서 EN·태그·종이별 알약 제거. 언어·필터는 보호자 영역, 종이별은 탭.
- 잠긴 동화는 아이용 잠김 쪽지(S4)가 먼저, 부모 확인은 '어른이 열기' 1초 꾹 뒤.
- 끝 화면에 종이별 받기 연출(접시). 리본·박음질·도장 제거.
- 화면 수 15, 구현 10단계, 새 그림 19장(+재사용 1).
