# 창작 동화 아이 이름 바꾸기 — 기능 기획 (초안 2026-11-06)

사용자 요청(2026-11-06): "4.99달러에 창작동화 이름바꿔주기 기능도 넣어줘. 그럼 서버세팅이 필요할거야."
근거: CLAUDE.md §1 "다음 업데이트에서 보호자가 아이 이름을 바꾸는 기능을 넣는다."
관련 문서: docs/MONETIZATION.md(과금), docs/SYNC_API.md(연결 서버), server/README.md(배포), tools/elevenlabs/gen_tale.py(녹음 스크립트).
절대 규칙: TTS(기계 음성) 금지 — 녹음 없는 말은 하지 않는다. 그래서 이름을 바꾸면 그 이름이 든 대사를 ElevenLabs로 새로 녹음해야 하고, ElevenLabs 키는 앱에 넣을 수 없으므로 서버를 거친다.

## 2. 사용자 흐름 (보호자 화면)

3~4세 아이가 아니라 보호자가 쓰는 화면이다. 홈 톱니(1초 꾹) → 부모 확인(곱셈, home.js S10) → 보호자 메뉴에 **'우리 아이 이름으로'** 항목을 더한다.

| 단계 | 화면 | 내용 |
|---|---|---|
| 1 | 보호자 메뉴 | '우리 아이 이름으로' 항목. 전체 구매 전이면 잠금 표시 + '전체 구매로 열려요' |
| 2 | 안내 | "창작 동화 4편의 아이 이름을 바꿔요. 목소리는 그대로, 이름이 든 대사만 새로 녹음해요. 그림은 바뀌지 않아요. 이름은 녹음을 만드는 동안만 서버에 보내고 저장하지 않아요." + 동의 체크(§6-3 문구) |
| 3 | 이름 입력 | 자리 3개: **A(여자아이, 지금 '다현')·B(남자아이, '이현')·C(막내, '은우')**. 자리마다 한글 이름 칸 + 영어 이름 칸. 빈 자리는 원래 이름 유지. 어느 동화에 나오는지 작게 표시 |
| 4 | 미리 듣기 | 자리마다 대표 한 줄(한·영)을 서버에서 만들어 바로 들려준다(예: "언덕 위에 ○○이가 서 있어요."). 들어 보고 마음에 안 들면 다시 입력 |
| 5 | 만들기 | '이 이름으로 만들기' → 진행 막대(동화별 n/98). 앱을 켜 둔 채 1~5분. 중간에 나가면 '이어서 만들기' |
| 6 | 적용 | 동화별로 한·영 전부 받아졌을 때만 '적용' 활성. 적용 뒤 동화 시작 화면에서 바로 확인 가능 |
| 7 | 되돌리기 | 같은 메뉴에서 '원래 이름으로' 한 번에 복구(파일은 남겨 두고 스위치만 끔). 횟수에 세지 않음 |

### 2-1. 입력 제한

| 항목 | 규칙 |
|---|---|
| 한글 이름 | 완성형 한글만(가-힣), 2~4글자. 공백·숫자·기호 금지. 성 없이 이름만 안내 |
| 영어 이름 | 영문자만, 2~12자. 첫 글자 대문자로 맞춤. 비우면 영어 모드는 원래 이름 유지(§8-3) |
| 금칙어 | 욕설·비속어 목록(서버·앱 양쪽)과 대조. 걸리면 "다른 이름을 적어 주세요" |
| 같은 이름 | A·B·C에 같은 이름은 막는다(구름 공장에서 셋이 같은 이름이 되면 이야기가 깨짐) |

### 2-2. 받침(조사) 규칙 — 앱과 서버가 같은 함수를 쓴다

원문의 이름 토큰을 `이름 + (이) + 조사`로 쪼개고, 새 이름의 **마지막 글자 받침 유무**로 다시 조립한다. 받침 판정: `(code - 0xAC00) % 28 !== 0`.

| 원문 꼴(예) | 받침 있는 새 이름(예 지민) | 받침 없는 새 이름(예 서아) | 실측 빈도 |
|---|---|---|---|
| 다현이는 | 지민이는 | 서아는 | 43 |
| 다현이가 | 지민이가 | 서아가 | 16 |
| 다현이 (뒤에 체언: '다현이 발이') | 지민이 발이 | 서아 발이 | 8 |
| 다현이한테 | 지민이한테 | 서아한테 | 5 |
| 다현이와 | 지민이와 | 서아와 | 4 |
| 다현이의 | 지민이의 | 서아의 | 4 |
| 다현이를 | 지민이를 | 서아를 | 3 |
| 다현이에게 | 지민이에게 | 서아에게 | 3 |
| 다현이도 / 다현이랑 | 지민이도 / 지민이랑 | 서아도 / 서아랑 | 1 / 1 |
| 은우는 / 은우가 (받침 없는 원문) | 지민이는 / 지민이가 | 서아는 / 서아가 | 8 |
| 이현이야(호격, 화면만) | 지민아 | 서아야 | 1 |

- 원문 '은우'는 받침이 없어 '이'가 안 붙어 있다. 바꿀 때는 위 규칙으로 '이'를 넣거나 빼므로 원문 꼴에 상관없이 같은 함수로 된다.
- '와/과'는 원문이 모두 '이와'(모음 뒤)라 새 이름도 '이와' 또는 '와'로 끝난다. '과'는 안 나온다.
- 시험표를 부록 B에 둔다. 함수는 `engine/name_form.js`(앱)와 `server/src/name_form.js`(서버)에 같은 코드를 둔다.

## 4. 서버 설계 (server/, Cloudflare Workers + KV)

원칙: **이름을 저장하지 않는다. 줄 하나를 만들어 바로 돌려주고 잊는다.** 대기열·R2·작업 저장소를 쓰지 않으므로 Workers 무료 요금제로 충분하고, 요청 하나가 ElevenLabs 호출 한 번(2~4초)이라 시간 제한에 안 걸린다.

### 4-1. 엔드포인트 (SYNC_API.md 규칙과 같음: Bearer `<accountId>.<token>`, JSON, CORS)

| 메서드·경로 | 요청 | 응답 | 조건 |
|---|---|---|---|
| `GET /v1/name/catalog` | - | `{ version, tales: { unicorn: { lines: [ { id, slot: "A", role: "nar", ko: "언덕 위에 {A}가 서 있어요. …", en: "On a hill stands {A_en}, …" } ] } }, limits }` | 인증·구매 필요. 앱이 줄 수·진행률 계산에 쓴다 |
| `POST /v1/name/check` | `{ names: { A: "서아", A_en: "Seoa" } }` | `{ ok, errors: { A: "banned" } }` | 금칙어·형식 검사. 저장 없음 |
| `POST /v1/name/line` | `{ tale, id, lang: "ko", names: { A: "서아", A_en: "Seoa" } }` | **mp3 바이트**(`audio/mpeg`) + 헤더 `X-Name-Version`, `X-Credits-Left`(선택) | 구매 필요. 줄 하나 생성. 미리 듣기도 같은 경로(`preview: true`로 한도만 다르게) |
| `GET /v1/name/quota` | - | `{ runsLeftThisMonth, linesLeftToday, previewsLeftToday }` | 화면 표시용 |

- 이름은 요청마다 보내고, 서버는 응답 뒤 아무것도 남기지 않는다(KV에 이름 없음, 로그에 본문 없음).
- `names`는 그 줄에 필요한 자리만 보내도 된다. 서버는 템플릿의 `{A}`·`{B}`·`{C}` 자리에 §2-2 규칙으로 조립해 넣는다.
- 오류: `not_owned`(403), `name_invalid`(400), `name_banned`(400), `quota_exceeded`(429), `tts_failed`(502), `busy`(503, 전체 일일 상한).

### 4-2. 템플릿 (서버가 가진 것)

| 파일 | 내용 | 만드는 법 |
|---|---|---|
| `server/src/name_lines.js` | 98줄 × {id, tale, slot, role, voiceId, modelId, settings, ko 원문(자리 표시), en 원문, 연기 지시 태그} | `tools/elevenlabs/build_name_lines.py`가 `tales/<id>/voice_script_el.json`·`read_script_el.json`·`narration_el*.js`·`home_narration_el.js`에서 이름 든 줄을 뽑아 생성. 목소리가 바뀌면 다시 돌려 `version`을 올린다 |
| `server/src/name_form.js` | 받침·조사 조립 함수 | 앱 `engine/name_form.js`와 같은 파일을 복사 |
| `server/src/banned_names.js` | 금칙어 목록(한·영) | 손으로 관리. 부분 일치 |

앱은 임의 문장을 보낼 수 없고 `id`만 고르므로, 구매자가 서버를 일반 TTS로 쓰는 남용이 불가능하다.

### 4-3. 구매 확인

- KV `acct:<id>`의 `state.owned === true`일 때만 `/v1/name/*` 허용(영수증 엔드포인트가 올린 값, 클라이언트 PUT은 무시됨 — 기존 규칙 그대로).
- 웹(GitHub Pages) 공개판은 잠그지 않는 정책이지만, 이 기능은 **앱 모드에서만** 연다(웹은 계정이 없고 크레딧이 들기 때문).

### 6-2. 줄이는 방법 (추천 설계에 이미 반영)

1. 이름은 **보호자 화면에서만** 입력(부모 확인 뒤).
2. 서버는 **저장·로그 없음**, 응답 뒤 소멸. KV에는 숫자 카운터만.
3. ElevenLabs 요청에 계정·기기 식별자를 넣지 않고, zero-retention 옵션을 쓴다.
4. 이름을 연결 서버 state에 넣지 않는다(기기 간 동기화하지 않음).
5. 이름 대신 **별명·호칭도 된다**고 안내(예: '콩콩이'). 실명을 강요하지 않는다.
6. 삭제: '원래 이름으로' + 기기 파일 삭제 버튼. 서버에는 지울 것이 없다.

## 7. 가격 — 판단 필요

사용자 문장 "4.99달러에 … 넣어줘"는 두 가지로 읽힌다.

| | ① 기존 4.99달러 전체 구매에 포함 | ② 별도 4.99달러 상품(비소모성) |

| 장점 | 상품 하나라 심사·복원·서버 검증 그대로. "전체 구매 = 다 됨"이라 설명이 쉽다. 구매 유인이 커진다 | 크레딧 비용을 따로 받는다. 전체 구매자 중 원하는 사람만 산다 |

| **추천** | **①** | |

추천 이유: 지금 단계는 구매 전환이 중요하고, 크레딧 비용은 한도로 막힌다. 반응을 본 뒤 비용이 크면 '추가 생성 3회 0.99달러(소모성)'를 2차에 붙인다.
