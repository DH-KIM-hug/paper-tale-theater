# 앱 과금·무료 정책 (아이패드·아이폰·안드로이드 공통)

원칙: **로그인 없음, 개인을 식별하는 정보 수집 없음.** 기록은 기기 안에 저장하고, 다른 OS 기기와 잇고 싶을 때만 아주 작은 서버에 무작위 ID로 올린다(2026-10-27 사용자 결정: 연결 코드 방식 A). 웹(GitHub Pages) 공개판은 잠그지 않는다. 잠금은 앱 모드에서만 적용한다.

## 1. 무료로 열리는 동화
| 구분 | 내용 |
|---|---|
| 항상 무료 4편 | 토끼와 거북이, 커다란 순무, 신데렐라, 팥죽할멈과 호랑이 |
| 창작 동화 | 구름 공장, 나의 빨간 자동차, 유니콘을 찾아서 등 origin=original. 항상 무료, 로테이션 제외 |
| 주간 로테이션 4편 | 항상 무료 4편과 창작 동화를 뺀 나머지(전래·이솝·세계 명작)에서 뽑는다. 월요일 시작, 기기 날짜로 계산. 이미 열어 둔 편이 뽑혀도 된다 |
| 기다무 | 첫 실행 7일 뒤 1편 선택, 14일 뒤 +1편. **부모 확인**(간단한 산수)을 거쳐 연다 |
| 종이별 | 놀이로 동화 한 편을 끝까지 하면 1개, 하루 최대 1개. 5개를 모으면 1편 선택해 연다. 이름은 2026-10-27 '구름과자'에서 바꿈(담배 은어로 오인 우려) |
| 스티커 | 놀이로 처음 끝까지 한 동화마다 스티커 1장(읽어 주기·자동 재생은 제외). 묶음별 퍼즐판을 채운다. 돈과 상관없는 기록이며 잠금을 풀지 않는다 |

## 2. 구매
- **전체 구매 4.99달러**, 비소모성, 한 번 결제. 구매 복원 버튼 제공.
- 구매는 스토어마다 결제한다(애플 StoreKit 2, 구글 Play Billing). 영수증을 서버에서 검증해 연결된 기기 전체에 "전체 구매"를 표시한다. 어느 OS에서 샀든 연결된 기기에서 열린다. 아이폰 앱 안에서도 애플 결제로 살 수 있어야 한다(애플 규정).
- 연결하지 않은 기기는 같은 스토어 안에서 "구매 복원"으로 이어진다.
- 구매·외부 링크·복원 앞에는 모두 부모 확인을 둔다.

## 2-1. 기기 연결 (연결 코드)
- 앱을 처음 열면 서버가 **무작위 ID**를 만든다. 이름·이메일·전화번호는 받지 않는다.
- 보호자가 부모 확인을 거쳐 설정에서 **연결 코드**(8자리, 10분 유효, 1회용)를 만든다. 다른 기기에서 코드를 입력하면 같은 기록으로 묶인다(아이패드↔아이폰↔안드로이드).
- 서버에 저장하는 것: 종이별 기록, 스티커(완주한 동화 목록), 열어 둔 동화 목록, 첫 실행 날짜, 구매 여부(영수증 검증 결과). 그 밖의 것은 저장하지 않는다.
- 합치기: 오프라인에서는 기기 안 저장으로 동작하고, 온라인이 되면 합친다. 종이별 합은 큰 쪽이 아니라 기기별 기록을 더하되 하루 1개 제한을 날짜 기준으로 다시 적용한다. 열어 둔 동화와 구매는 합집합.
- 연결하지 않아도 앱은 완전히 동작한다. 연결은 선택이다.
- 한계: 모든 기기를 잃으면 복구할 수 없다. 필요하면 나중에 선택 사항인 복구용 이메일을 추가한다(그때 처리방침 수정).
- 서버 후보: Supabase 또는 Cloudflare Workers+KV(월 몇 달러 이하). 어린이 앱 규정상 외부 분석·광고 SDK는 넣지 않는다.

## 3. 출시 첫 버전에서 뺀 것
- 가입·로그인(네이버·카카오·구글·애플): 연결 코드로 대신한다. 개인정보 수집과 어린이 앱 심사 부담 때문에 뺐다.
- 친구에게 0.99 이용권 선물: 스토어 정책상 앱 안에서 만들 수 없다.
- 추가 슬롯 0.99달러(고정 2 + 로테이션 2, 최대 5회): 전체 구매와 겹치고 구현이 복잡해서 출시 후 반응을 보고 정한다.
- 복구용 이메일: 출시 후 요청이 있으면 선택 사항으로 추가.

## 4. 알려진 한계
- 연결하지 않은 채 기기를 바꾸거나 앱을 지우면 종이별, 첫 실행 날짜, 열어 둔 동화가 초기화된다. 구매는 복원된다.
- 기기 시계를 조작해 7일·14일을 앞당길 수 있다. 어린이 앱 특성상 허용한다.

## 5. 어린이 앱 심사 체크
- 광고·외부 분석 SDK 없음. 개인정보 처리방침(`privacy.html`)에 "무작위 ID와 진행 기록을 서버에 저장, 개인 식별 정보는 수집하지 않음"을 추가한다(연결 코드 기능 때).
- 애플 5세 이하 등급 / Google Play 가족용 정책.
- 출시 전 확인: Typecast 상업 이용 허용 여부, Apple 개발자 계정($99/년), Google Play 개발자 계정($25), AI 그림 심사 노트, 가족 참고 사진은 앱에 넣지 않기.

## 6. 코드 작업 목록
1. `entitlements.js`: 항상 무료 6편·주 2편·2.99달러를 4편·주 4편·4.99달러로 바꾸고, 첫 실행 날짜·기다무·종이별을 추가한다.
2. 연결 서버(무작위 ID, 코드 발급·입력, 기록 합치기, 영수증 검증)와 앱 연결 화면.
3. 부모 확인 화면(산수 문제) 공통 컴포넌트.
4. StoreKit 시험용 상품 파일 가격을 4.99달러로 맞춘다.
5. 안드로이드: Capacitor Android 플랫폼과 Play Billing 플러그인.
6. 골디락스는 `ready:false`이고 자장가 holdMelody와 세로 QA가 남아 있어 출시 전에 마무리한다.
