# 톡톡 동화극장 (Toki Toki Tale) — 앱 기능 정리

작성 2026-11-22. 스토어 설명(store/listing_ko.md, listing_en.md)과 같은 사실만 적는다. 기능이 바뀌면 이 문서와 스토어 문구를 함께 고친다.

## 한 줄 소개
2~5세 어린이가 종이를 오려 만든 동화 속으로 들어가 이야기를 함께 이어 가는 동화 앱. 광고 없음, 로그인 없음.

## 대상과 분류
- 대상: 3~4세 중심, 부모님이 함께 보는 것을 전제로 함
- App Store: 기본 교육, 보조 도서. 게임으로 분류하지 않음
- Kids 카테고리: 5세 이하

## 화면 구성
- **홈**: 추천 배너, 동화 목록(분류별), 보호자 톱니(오른쪽 위)
- **잠자리(읽어 주기)**: 화면을 꺼도 끝까지 읽어 주는 잠자리 동화. 재생 목록, 이어 듣기
- **스티커북**: 놀이를 끝까지 하면 스티커를 한 장씩 모음. 모은 스티커로 나만의 무대를 꾸밈
- **보호자 메뉴**: 길게 눌러 열기(1초). 소리, 자막, 놀이 시간, 언어, 동화 찾기, 이용권, 기기 연결, 아이 이름, 공지사항, 정보, 기록 지우기

## 동화 (34편)
- 전래동화, 이솝 우화, 세계 명작, 창작 동화 4편
- 창작 동화 4편: 구름 공장, 나의 빨간 자동차, 유니콘을 찾아서, 사탕 마녀의 핼러윈. 보호자가 주인공 이름과 모습(여자아이·남자아이)을 정할 수 있음
- 동화마다 배경 음악과 효과음이 있음(ElevenLabs로 만든 음악·효과음 포함)

## 두 가지 모드
- **놀이 모드**: 화면을 누르고, 고르고, 순서대로 놓으며 이야기를 이어 감. 틀려도 벌이 없음. 조작은 이야기에 이유가 있을 때만 넣음
- **읽어 주기 모드**: 처음부터 끝까지 소리 내어 읽어 줌. 화면을 꺼도 계속 재생됨(백그라운드 오디오)

## 언어
- 모든 동화를 한국어와 영어로 들을 수 있음
- 같은 목소리가 천천히 읽어 주고, 화면에 글자가 함께 나옴
- 언어는 보호자 메뉴에서 바꿈

## 무료와 유료
- **항상 무료**: 기본 무료 동화 4편, 창작 동화 4편
- **매주 무료**: 매주 4편이 바뀌어 무료로 열림
- **별 조각**: 동화를 끝까지 놀면 하나씩 받음. 별 조각 5개로 잠긴 동화 한 편을 열 수 있음
- **모든 동화 열기 (4.99달러, 한 번 결제)**: 모든 동화가 열림. 창작 동화 4편의 아이 이름·모습 첫 설정 1회 포함. 가족 공유 켜짐
- **아이 이름 변경권 (1.99달러)**: 창작 동화 4편의 아이 이름·모습을 한 번에 정하거나 바꿈. '모든 동화 열기'가 없어도 살 수 있음. 소모품, 가족 공유 없음
- **구매 복원**: 기기를 바꾸거나 앱을 다시 깔았을 때 구매를 되살림

## 아이 이름 (보호자 기능)
- 창작 동화 4편에서 주인공 이름과 모습을 정함
- 이름이 들어간 대사는 입력한 이름으로 새로 녹음함(같은 목소리)
- 이름 입력 전에 보호자 동의와 어른 확인(곱셈 문제 정답을 1.5초 누르기)이 필요함
- 녹음은 기기에 저장되고, 서버는 이름을 저장하거나 기록하지 않음

## 보호자 확인
- 구매, 기기 연결, 외부 문서 보기, 이름 설정, 기록 지우기 앞에 어른 확인이 있음
- 아이가 혼자 누를 수 없도록 곱셈 문제의 정답을 1.5초 눌러야 함

## 서버와 개인정보
- 서버: Cloudflare Workers (paper-tale-sync)
- 서버가 하는 일: 기기 연결(연결 코드), 구매 영수증 확인, 이름 녹음 생성(ElevenLabs 호출)
- 서버가 저장하지 않는 것: 아이 이름, 얼굴 모습, 식별 정보
- 인터넷이 없어도 동화는 볼 수 있음. 인터넷은 기기 연결, 구매 확인, 이름 녹음, 공지 받기에만 씀
- 개인정보 처리방침: https://ddoystory.com/tokitoki/privacy/ (옛 주소 https://paper-tale-sync.papertale.workers.dev/privacy 도 열림)
- 지원 페이지: https://ddoystory.com/tokitoki/support/

## 공지와 의견
- **공지사항**: 보호자 메뉴에서 서버 공지를 읽음. 아직 안 읽은 공지가 있으면 그 줄에만 점이 뜸. 인터넷이 없으면 마지막으로 받은 공지를 보여 줌
- **의견 보내기**: 보호자 메뉴 '정보'에서 어른 확인 후 메일 앱을 열어 hello@ddoystory.com으로 보냄. 앱 버전과 기기 종류가 미리 적힘

## 처음 실행
- 처음 열면 부모님용 안내 카드 4장이 뜸(낮 놀이, 밤 읽어 주기, 영어, 보호자 메뉴)
- 보호자 메뉴 '정보'의 '처음 안내 다시 보기'로 다시 볼 수 있음

## 기기 지원
- iPhone과 iPad (아이패드 우선, 접는 iPhone Duo 대응 완료)
- 가로와 세로 모두 지원
- iOS 15.0 이상

## 제외된 것 (의도적으로 없음)
- 광고, 외부 분석 SDK, 추적
- 로그인과 회원가입
- 아이에게 보이는 구매 버튼
- 외부 링크 (보호자 영역의 문서 외)
- 점수, 승패, 레벨 같은 게임 요소
