## 2. 방향

### 2-1. 한 문단

화면은 여전히 **크림 종이 한 장**이다. 다만 그 종이는 바탕이고, 아이가 누르는 모든 것은 **그 위에 올려 둔 색지 조각**이다: 누르라는 것은 감빛 종이, 모은 것은 구리색 종이, 밤 것은 남색 종이, 판은 크래프트 종이. 조각은 크고(짧은 변 88px 이상), 글자는 조각에 오려 붙인 남색 글자(굵고 자간 넓게), 그림자는 왼쪽 위 빛 하나에서 나오는 웜 다크 그림자뿐이다. 겹겹이 상자를 파지 않는다: 바탕에 파는 구멍은 '그림이 들어가는 창'(탭 구멍·동화 그림 창·퍼즐판) 세 가지뿐이고, 나머지는 전부 올린 조각이다. 움직임은 "들린다 → 미끄러진다 → 내려앉는다" 하나다. 튕기지 않는다.

### 2-2. 원칙 (3~4세 + 보호자)

1. **아이가 누르는 것은 88px, 색이 있다.** 아이패드 88pt, 아이폰 72pt 이상. 1차 행동은 감빛 종이 한 개뿐(화면당 하나). 회색 음각은 '안 눌림'의 뜻으로만 쓴다.
2. **그림이 먼저, 글은 보호자용.** 아이 화면의 글자는 제목(들려주는 것과 같은 말)과 숫자뿐. 설명 문장은 보호자 영역과 쪽지 맨 아래 한 줄로 몰아넣는다. 음성이 이미 이름을 읽어 주므로 글자는 **크게 적되 적게** 쓴다.
3. **상자 안 상자 금지.** 한 요소는 바탕 위 조각 하나(양각) 또는 바탕에 뚫린 창 하나(음각)다. 조각 안에 다시 음각 상자를 파지 않는다.
4. **한 광원.** 왼쪽 위. 모든 그림자 dx:dy = 1:2, 색 `#2E241C`. 하이라이트는 아래·오른쪽 '입술' 1px뿐.
5. **움직임은 종이 무게.** 160~320ms, 감속 곡선(overshoot 없음). 예외는 보상(종이별·스티커 받기) 한 번의 가벼운 '톡' 착지뿐.
6. **보호자 영역은 아이 화면과 다른 밀도**이되 같은 재료. 글자 17~18px, 줄 높이 64px, 색지 조각은 켜짐 스위치에만.

### 5-2. 탭 전환

1. 누른 탭: 그림이 72%→100%로 커지며 바탕에 구멍이 열린다(구멍 바닥과 `--cut`을 0→1로 페이드 + 감빛 고리 scale .9→1). **260ms**, `cubic-bezier(.2,.8,.2,1)`.
2. 이전 탭: 구멍이 닫히고 그림이 100%→72%로 작아지며 `--sh-1`이 돌아온다. 200ms, 같은 곡선.
3. 내용: 이전 뷰가 `opacity 1→0, translateX(0 → −24px)` 140ms로 나가고, 새 뷰가 `opacity 0→1, translateX(+24px → 0)` 220ms로 들어온다(동시에 시작, 들어오는 쪽이 길다). 방향은 탭 순서(동화→잠자리→스티커북이 오른쪽으로). 세로/아이폰 막대도 같다(가로 이동).
4. 소리 `tap` + 탭 이름 읽기(지금과 같음).
5. `prefers-reduced-motion`: 구멍·그림 크기 변화 없이 상태만 바뀌고, 내용은 120ms 크로스페이드.

### 5-4. 쪽지(시트)·보호자 종이 열고 닫기

- 열기: 베일 `0→.42` 200ms. 쪽지 `opacity 0→1`, `translateY(24px)→0`, `scale(.97)→1` **240ms** `cubic-bezier(.2,.8,.2,1)`. 쪽지 안 첫 글자·그림은 쪽지보다 60ms 늦게 페이드(종이가 먼저 놓이고 내용이 보인다).
- 닫기: 쪽지 `opacity 1→0`, `translateY(0→16px)` 160ms `ease-in`; 베일 180ms.
- 쪽지 안 단계 바꿈(S4→S11, S11→S12): 쪽지 크기는 `height` 전환 240ms, 내용은 이전 것이 80ms로 사라진 뒤 새 것이 160ms로 나타난다.
- 보호자 영역(전면): 오른쪽 위 톱니에서 **종이가 펼쳐지듯** `transform-origin: top right`, `scale(.92)→1`, `opacity 0→1` 280ms. 닫을 때 반대 200ms. 아이폰 1열 → 본문 들어오기: 본문 종이 `translateX(100%)→0` 260ms, 목록은 `translateX(0→−20%)` + 어두워짐 .12.
- 구현: `[hidden]` 대신 `data-state="open|closing"`으로 바꾸고 `transitionend`에서 `hidden`을 붙인다. 포커스는 열릴 때 첫 아이용 단추로.

### 5-5. 큰 동화 넘기기(히어로)

- 감속 전용: 스프링 없음. reduced-motion: 크로스페이드 160ms.

2. 0.4초 머문 뒤 오른쪽 아래 **작은 접시/스티커북 구멍**(끝 화면 모서리에 미리 그려 둔 112px 창)으로 **2차 곡선**으로 날아간다: 640ms, `cubic-bezier(.4,0,.2,1)`, 가는 동안 `scale 1→.4`, 회전 ±8° 이내.
3. 착지: 80ms `scale(1.06)`→100ms `1`(이것이 유일한 '톡' 착지). 소리 `tap` 한 번. 음성 "스티커를 받았어요!".
4. 홈으로 돌아오면 스티커북 탭 구멍 옆 구리 점이 200ms로 나타나고, 스티커북을 열면 그 조각이 자리에서 `scale(1.08)→1` 240ms 한 번 들썩인다(처음 볼 때만).
5. reduced-motion: 날아가지 않고 목표 자리에서 페이드 200ms, 음성은 같다.

### 5-8. 1초 꾹(톱니·어른이 열기·편집)·1.5초 꾹(정답)

- 누르기 시작 → 둘레 **감빛 링**(stroke 4, 지름 = 단추 + 8)이 선형으로 찬다. 다 차면 링이 60ms 밝아졌다(크림) 사라지고 동작. 중간에 떼면 링이 200ms에 되감긴다 + 안내 쪽지(지금 `toast`).
- 톱니는 누르는 동안 `--ink-3`→`--ink`로 진해진다(지금은 색 변화 없음).

### 5-9. 요약표

| 전환 | 시간 | 곡선 | reduced-motion |
|---|---|---|---|
| 누름 반응 | 90 / 160~180 | ease-out | 유지(짧아서) |
| 탭 구멍 열림 | 260 | `.2,.8,.2,1` | 없음 |
| 탭 내용 교체 | 140 out / 220 in | `.2,.8,.2,1` | 120 페이드 |
| 쪽지 열기/닫기 | 240 / 160 | `.2,.8,.2,1` / ease-in | 120 페이드 |
| 보호자 종이 | 280 / 200 | `.2,.8,.2,1` | 120 페이드 |
| 히어로 넘김 | 200 out / 320 in | `.2,.8,.2,1` | 160 페이드 |
| 조리개 | 420 / 380 | `.4,0,.2,1` | 200 페이드 |
| 보상 날아가기 | 240 + 640 + 180 | `.4,0,.2,1` | 목표 자리 200 페이드 |
| 꾹 링 | 1000 / 1500 선형 | linear | 유지 |
| 첫 실행 쪽지 | 240 in / 200 out | `.2,.8,.2,1` | 페이드 |

CSS 변수로 둔다: `--ease: cubic-bezier(.2,.8,.2,1); --ease-in: cubic-bezier(.4,0,1,1); --t-1: 160ms; --t-2: 240ms; --t-3: 320ms;` `@media (prefers-reduced-motion: reduce) { :root { --t-1: 80ms; --t-2: 120ms; --t-3: 120ms; } }` + 이동량 변수 `--mv: 24px`(reduced에서 0).
