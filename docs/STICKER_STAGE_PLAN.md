## 0. Shape 브리프 (2026-11-04, 사용자 답 반영 — 2026-11-05 확정)

> 아래 브리프가 본문(1~9)보다 우선한다. 본문과 다르면 브리프를 따른다.

1. **누가·언제**: 3~4세 아이가 **아무 때나 혼자** 스티커북 탭에서 꺼내 논다. 동화 끝 화면과 묶지 않는다(사용자 답). 글 없이 그림·소리·손가락 하나.
2. **성공**: **내가 만든 장면이 쌓이고 다시 열 수 있다**(사용자 답). 모은 친구 스티커가 쓸모를 얻어 동화를 더 하게 된다. 정답·점수·칭찬 연출은 없다.
3. **들어가는 곳 (본문 2-0 고침)**: 오늘 홈에서 흰 감싸기 카드를 없앴으므로, 스티커북 탭 맨 위에 **'내 무대' 줄**을 둔다 — 머리글(단색 아이콘 + '내 무대') 아래 가로 줄: 첫 칸 [+ 새 무대](이 탭의 감빛 행동 하나), 그 뒤 저장한 장면 카드(최근 것이 앞). 줄은 다른 분류 줄처럼 화면 오른쪽 끝에서 잘린다. 장면 카드 톡 = 그 장면을 이어서 꾸미기(따로 보기 화면 없음).
4. **무대 화면**: 탭을 숨긴 전체 화면. 가운데 종이 무대(그림 세계, 페이퍼아트), 아래(세로·폰) 또는 옆(가로) 스티커 서랍(평평한 2판 UI). 무대와 서랍의 경계 = 무대 테두리 하나. 위 왼쪽 [닫기](홈으로, 저절로 저장됨), 위 오른쪽 [배경]. [처음부터]는 1초 꾹.
5. **핵심 손맛(초점)**: 스티커를 들 때 1.03배·그림자 깊게·1~2° 기울고, 놓으면 살짝 내려앉으며 종이 소리. 이 한 동작이 놀이의 전부라 가장 공들인다.
6. **상태와 범위**: 처음(스티커 0장: 서랍에 '동화를 하면 친구가 와요' 그림 안내 + 소리, 무대는 열림), 스티커 1~10장(대부분), 100장 넘게(서랍 가로 넘김, 동화별 묶음). 저장 장면 0·1·12장(12장 꽉 차면 가장 오래된 것 위에 새로 — 판단 6). 배경 잠김 상태(판단 1).
7. **하지 않는 것**: 크기 조절·회전·핀치·두 손가락, 글 입력, 그리기 도구, 정답형 문제, 공유·서버 저장(1판), 홍보 노출(아이 캐릭터 스티커가 든 장면).
8. **제약**: 누르는 영역 80px 이상(서랍 칸 96px), 녹음 전 공개 안 함(TTS 금지), 아이패드 사파리에서 그림자 흐림 애니메이션 금지(구운 그림 + transform), 움직임 줄이기면 들기 연출 없이 바로 이동.
9. **만드는 사람이 마음대로 정하면 안 되는 것**: 본문 9장의 13개 판단(추천안 있음), 배경 6장의 그림(숲 1장 먼저 확인).

## 1. 목적과 아이가 하는 일

**한 줄 목적**: 동화를 끝까지 해서 모은 친구 스티커가 '구경하는 것'에서 '가지고 노는 것'이 된다 — 종이 무대 위에 내 마음대로 붙여 내 장면을 만든다.

3~4세가 하는 일(모두 손가락 하나):
1. 배경 고르기 — 종이 한 장을 톡.
2. 서랍에서 스티커를 **끌어 올리거나 톡** 해서 무대에 붙이기.
3. 붙인 스티커를 **끌어서 옮기기**.
4. 붙인 스티커를 **서랍으로 끌어 내려 떼기**(쓰레기통 없음).
5. 붙은 스티커를 **톡** = 이름 듣기 + 좌우 뒤집기(판단 ③).
6. 끝. 저장 단추는 없다 — 만드는 대로 저절로 남는다(판단 ⑥).

배움(수세기 아님): 위치어(위·아래·옆·앞·뒤), 왼쪽·오른쪽 보기(뒤집기), 누가 누구와 함께 있나(동화를 섞어 이야기 짓기). 정답은 없다. 고르기·순서 같은 정답형 조작은 두지 않는다.

## 2. 화면 구성

### 2-0. 어디서 들어가나
스티커북 탭(`#view-stickers`, `curTab === 'stickers'`) **맨 위에 '내 무대' 흰 카드 한 장**을 새로 둔다. 별 카드(`#pzPlate`)·동화별 친구 스티커 카드(`.cs-sec`)는 그 아래 그대로.

```
┌ 내 무대 ───────────────────────────────────────────┐
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌ ─ ─ ─ ┐         │
│ │ + 새   │ │(장면 1) │ │(장면 2) │   비어      → 가로 넘김
│ │  무대  │ │ 숲      │ │ 밤하늘  │ │  있음  │         │
│ └────────┘ └────────┘ └────────┘ └ ─ ─ ─ ┘         │
└────────────────────────────────────────────────────┘
```
- `+ 새 무대` 카드 = 이 카드의 1차 행동(감빛 `--act` 알약은 화면당 하나 → 스티커북 탭에서는 이 카드에 쓴다. 별 카드의 [반짝 스티커 만들기]는 지금처럼 구리색 보상 톤으로 남긴다).
- 저장된 장면 카드 톡 = 그 장면을 다시 연다(편집 계속). 카드는 저장 데이터로 다시 그린 작은 무대(§5).
- 친구 스티커가 0장이면 '내 무대' 카드는 숨긴다(지금 빈 상태 `cast-none` 그대로).

### 2-1. 편집기(무대 화면) — 동화 안처럼 탭 레일·막대를 숨긴 전체 화면 겹 (`#stage`, index.html 안)

공통 요소
| 요소 | 무엇 | 크기(짧은 변) | 위치 |
|---|---|---|---|
| 무대 | 배경 종이 그림 + 붙인 스티커. 모서리 r28 흰 카드 안, 1px 테두리, 그림자 없음(홈 2판) | 화면에서 가장 큼 | 가운데 |
| 서랍 | 모은 친구 스티커 한 줄, 가로 넘김. 흰 카드 | 칸 112px(아이패드) / 96px(폰) | 무대 아래 |
| [닫기] ✕ | 스티커북으로 돌아감(저절로 저장됨) | 80px | 왼쪽 위 |
| [배경] | 배경 고르기 띠를 연다(§4) | 80px | 오른쪽 위 |
| [처음부터] | **1초 꾹**: 붙인 것이 모두 서랍으로 돌아감 | 80px | 오른쪽 위, [배경] 옆 |

- 홈 2판 UI와 종이 그림의 경계: **화면(바탕 `#F3F3F1`, 흰 카드, 단색 기호 단추)은 평평하고, 카드 안의 것(배경 종이·스티커)만 종이다.** 무대 카드 테두리가 곧 경계다. 무대 안에는 UI 글자·단추를 올리지 않는다(스티커가 묻히지 않게). 서랍의 스티커는 지금 스티커북과 같은 흰 칼선 테두리(§7-1 예외), 무대에 붙은 뒤에도 칼선은 그대로(실물 스티커처럼).
- 서랍 내용: **모은 것만**. 안 모은 칸은 서랍에 **보이지 않는다**(서랍은 '내 것'. 빈 실루엣은 스티커북 카드에서 이미 보여 준다). 무대에 올린 스티커는 서랍에서 **빠진 자리(흐린 실루엣)**로 남는다(판단 ⑤ 한 장씩).
- 서랍 순서: 받은 순서(`Entitlements.state().cast` 순서) 그대로. 동화가 바뀌는 자리에 그 동화 썸네일 동그라미(48px, 톡 = 제목 읽기, 누르는 영역은 칸 높이 전체)를 끼워 '어느 동화 친구들'인지 보인다.
- 반짝 스티커(`shiny`)는 무대 위에서 **홀로그램 테두리 색만**(정지), 스치는 빛·깜빡이 애니메이션은 켜지 않는다(성능, 판단 ⑨).

### 2-5. 배경 고르기 띠 ([배경] 톡)
무대 위로 흰 카드 띠가 내려온다(아래로 사라지는 서랍과 같은 문법). 배경 6장이 16:9 작은 종이(아이패드 200×112, 폰 128×72)로 한 줄. 톡 = 바로 바뀜(확인 없음) + 띠 닫힘 + 배경 이름 읽기. 아직 안 열린 배경(§4)은 **연회색 눌린 자리 `--paper-dn` + 실루엣** 으로(자물쇠·문구 없음, PUZZLE_PLAN 빈 조각과 같은 표현).

| 뒤집기 | 무대 위 스티커 **톡** = 이름 읽기 + 좌우 뒤집기(한 동작) | 방향(누가 누구를 보나, CLAUDE §5-1)을 아이가 직접 만든다. 실수해도 다시 톡이면 원래대로(판단 ③) |

누르는 영역
- 무대 위 스티커: 그림 상자 짧은 변 **96px 이상**(폰 80px). 작은 그림(`sh` 작은 것)은 투명 영역을 넓혀 96px.
- 서랍 칸 112(아이패드)/96(폰), 단추 80. 모두 세로 화면에서도 화면 안.
- 끌기 중 서랍 띠 전체가 '떼기' 영역(높이 136).

## 5. 저장·보기

- **저절로 저장**(판단 ⑥): 붙이기·옮기기·떼기·뒤집기·배경 바꾸기마다 그 장면을 `localStorage` 에 바로 쓴다(디바운스 300ms). 저장 단추·"저장할까요?" 없음. 3~4세에게 저장은 개념이 없고, 화면을 끄거나 홈으로 가도 그대로 있으면 된다.
- 장면 수: **최대 12장**. 12장이면 `+ 새 무대` 카드가 눌린 회색(흐림)으로 바뀌고 톡하면 "무대가 가득 찼어요"(녹음 필요, §6) 한 줄. 아이 작품을 조용히 지우지 않는다.
- 지우기: 스티커북 '내 무대' 줄의 장면 카드 **1초 꾹** → 카드가 흔들리며 ✕ 가 나타남 → ✕ 톡 = 지움(색종이 없이 종이 구겨지는 `zip_away`). 보호자 확인(산수)까지는 두지 않는다(돈·개인정보 아님).
- 위치: `localStorage['paperTheater.stages']`(배열, §8), 마지막 연 장면 `paperTheater.stageCur`. 장면 하나 ≈ 1KB(스티커 30장 기준) → 12장 ≈ 12KB. 썸네일 그림은 저장하지 않고 **데이터로 다시 그린다**(카드 크기 240×135 작은 무대, 배경 webp + 스티커 img 를 CSS `transform: scale` 로). 용량·일관성 모두 유리.
- 서버 동기화: **1판은 기기 안만**(판단 ⑧). SYNC_API 의 state 에 넣지 않는다. 기기 연결 때 합치지 않아도 된다(장면은 '그 기기의 작품').
- 보는 곳: 스티커북 탭 '내 무대' 줄(§2-0)뿐. 동화 안·잠자리 탭·끝 화면에는 나오지 않는다.
- 잠자리 탭: 노출 없음(잠자리는 듣는 모드, 화면 끄고 듣는 규칙).
- **홍보·스토어 스크린샷 규칙**: 아이 캐릭터 스티커(창작 4편 `kkultteok`·`red_car`·`unicorn`·`witch_candy` 의 아이·강아지 캐릭터)가 **하나라도 들어간 장면은 홍보물·스크린샷·소개 영상에 쓰지 않는다**(CLAUDE §1 예외는 앱 안 공개에 한함). 홍보용 장면은 일반 캐릭터(원작 기반 동화 스티커)만으로 따로 만든다. 저장 데이터에 `kid: true` 표시를 붙여(아이 캐릭터 `k` 목록으로 판정) 나중에 보호자 영역 '사진으로 저장'을 넣을 때도 같은 표시를 쓴다.
- '사진으로 저장(앨범)'·'공유'는 1판에 넣지 않는다(어린이 앱 심사: 외부 공유는 보호자 확인 뒤, 다음 판 판단).

## 8. 구현 메모 (코드는 아직 쓰지 않는다)

### 8-1. 파일 나누기 — **새 파일**
- `stage.js` (새, 홈과 같은 IIFE) + `stage.css` (새). `home.js` 는 1,886줄이라 더 붙이지 않는다. `home.js` 에는 ① 스티커북 탭 '내 무대' 카드 그리기(`drawStageRow()`, `drawCastAll` 안에서 부름) ② `Stage.open(idx|null)` 호출 ③ 배경 열림 알림(`paintTabBadge` 옆) 세 군데만 더한다.
- `index.html`: `<section id="stage" hidden>`(전체 화면 겹) + `stage.js?v=`·`stage.css?v=` + `home.js`·`home.css` 캐시 버전 올리기(메모 규칙).
- `tales/stickers.js`: 칸마다 선택 필드 `sh`(무대 높이 비율, 없으면 0.30)와 `kid: true`(아이 캐릭터) 추가. 그림 목록 자체는 그대로.
- `assets/stage/`: 배경 12장 + `stage.json`(배경 목록·열림 조건)는 코드 상수로 충분하므로 json 없이 `stage.js` 안 `BGS` 배열.
- 효과음·녹음: `sounds/sfx` 기존 파일, `home_narration_el.js` 에 §6-2 줄 추가(`gen_home.py` 목록에 넣어 생성).

### 8-2. 데이터
```js
// localStorage 'paperTheater.stages'  (배열, 최대 12)
[{ id: 'st_1730700000', bg: 'forest', at: 1730700000,
   items: [ { c: 'patjuk.tiger_stand', x: .42, y: .63, f: 0 },   // c = 친구 스티커 키('<동화id>.<k>', entitlements cast 키와 같음)
            { c: 'rabbit.turtle_walk', x: .70, y: .66, f: 1 } ] }]   // x·y = 스티커 가운데의 무대 비율(0~1), f = 1 이면 좌우 뒤집힘
// 'paperTheater.stageCur' = 마지막 연 장면 id
```
- 그리기: `items` 순서 = 겹침 순서(마지막이 맨 위). 들면 배열 끝으로 옮긴다.
- 크기: 스티커 상자 높이 = 무대 높이 × `sh`(기본 .30, 아이패드 가로 675 → 약 200px). 그림마다 캔버스 여백이 달라 보이는 크기가 다르므로(`pj3_tiger_stand` 700×523, `wc_kid_stand` 360×600) `sh` 는 **같은 부위 폭을 재서** 정한다(CLAUDE §4-1 코드 규칙과 같은 방법). 처음엔 동화 단위로 한 값, 눈에 띄는 것만 칸별로 고친다.
- 무대 비율이 가로(16:9)·세로(3:4)로 달라도 `x·y` 비율은 그대로 두고 배경만 바뀐다. 배경 6장 모두 '가운데 아래가 빈 면'이라 자리가 크게 어긋나지 않는다(§4-2 규칙의 이유).
- 아이 캐릭터 판정: `items.some(i => STICKERS[...].kid)` → 장면에 `kid` 플래그를 매번 계산(저장하지 않아도 됨).
- 배경 열림: `Entitlements.state().cast.length >= 10/20/30`. 열린 것을 본 기록 `paperTheater.stageBgSeen`(배열)으로 알림 한 번.

### 8-3. 입력
- 무대·서랍 모두 `pointerdown`에서 시작, `setPointerCapture`, 전역 `pointermove/up/cancel`(지금 퍼즐 끌기 `pzDrag` 와 같은 뼈대 — 함수를 공유하지 말고 `stage.js` 안에 따로 둔다, 두 끌기가 동시에 살아 있지 않게 편집기 열릴 때 `#view-stickers` 는 숨김).
- `touch-action: none` 은 **무대 상자와 들린 스티커에만**. 서랍은 가로 스크롤이 필요하므로 `touch-action: pan-x`, 서랍 스티커는 세로로 10px 이상 움직였을 때만 들린다(가로 10px 이상이면 스크롤로 넘긴다).
- 하나의 `pointerId` 만. 두 번째 손가락은 `preventDefault` 만 하고 무시.
- 톡 판정: 10px 미만·300ms 안.

### 8-4. 성능 (아이패드 사파리)
- 움직임은 `transform` 만(translate·scale·rotate). 들린 스티커에만 `will-change: transform`, 놓으면 뗀다.
- **그림자 흐림을 애니메이션하지 않는다.** 칼선 테두리 + 그림자는 `filter: drop-shadow` 4+1 겹(지금 `.cast-grid .cs img` 와 같음)인데, 이것을 끌기 중 매 프레임 다시 계산하면 느리다 → 무대 위 스티커는 **칼선+그림자를 미리 한 번 그린 캔버스(offscreen, 스티커당 1회, 메모리 캐시)** 를 `<img>`/`<canvas>` 로 쓰고 끌 때는 transform 만 바꾼다. 들린 그림자는 같은 캔버스 두 장(평소·들림) 중 하나를 보이기(opacity 교체). 서랍의 스티커는 지금 CSS 그대로.
- 무대 위 스티커 최대 30장(넘으면 서랍 톡·끌기가 살짝 흔들리며 거절, 말 없음). 배경 1장 + 스티커 30 = 레이어 31, 아이패드에서 충분.
- 배경 webp 1600×900 ≈ 200KB, 띠용 썸네일은 같은 파일을 `<img>` 로 줄여 씀(브라우저 캐시 1벌). 편집기 열 때 6장 전부 미리 받지 않고 현재 배경 + 띠를 열 때 나머지.
- 썸네일 카드(§5)는 같은 렌더러를 240px 폭으로 — `<img>` 12장 × 스티커 ≤ 30 이면 DOM 360개까지 가능하므로 **보이는 카드만 그리고 나머지는 배경만** 보여 준다(`IntersectionObserver`).
- `#pzBoard` 의 `.pz-glow`(`filter: blur(26px)`)는 편집기 열 때 숨긴다.

### 8-5. 안전·검수
- 아이 화면에 글자: 단추는 기호(✕·배경 그림 기호·되감기 기호)만, 글자 없음. 보호자용 작은 글자는 두지 않는다.
- 자물쇠·가격·구매 문구 없음(어린이 카테고리).
- 검수 사진: 아이패드 가로·세로, 폰 세로 각각 (가) 빈 무대 (나) 스티커 8장 (다) 끌기 중 (라) 배경 띠 열림 (마) 서랍 되돌리기 중 — 5장 × 3 = 15장. 인물 크기 비교(§4-1)는 같은 동화 두 자세를 나란히 붙여 머리 폭을 잰다.
