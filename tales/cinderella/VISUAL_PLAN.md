# 신데렐라 — 시각 재기획 (아주 화려하게: 무도회장·요정 변신·성 계단·신데렐라 집)

작성 2026-10-22. 사용자 요청: "공주 동화들도 화려함이 필요한 부분들 아주 화려하게 재기획. … 신데렐라도 아주 화려하게."

이 문서는 **배경·레이어 소품·코드 연출**만 다룬다. 인물 그림(신데렐라·새엄마·언니들·요정 대모·왕자·생쥐·말·마부·시종)과 누르는 소품(호박·쥐덫·언니 머리·시계 카드·발 카드)은 바꾸지 않는다. 대사·녹음·조작은 그대로다. 코드 좌표는 그림이 온 뒤 이 문서의 자리표를 기준으로 맞춘다.

작업표: 코드가 쓰는 그림은 `cd2_*`(`cinderella.js` 머리글 참고)이므로 **`tools/app/gen/jobs_cinderella2.json`** 끝에 18항목(배경 `cd2_bg_*_v2` 6 + 레이어 소품 `cd2_layer_*` 12)을 붙였다. `jobs_cinderella.json`(옛 `cd_` 판)은 건드리지 않았다. 기존 항목·기존 그림 파일은 그대로 두고, 코드 `BGS` 를 `_v2` 로 바꿀 때 옛 배경은 쓰지 않는다.

형식은 `tales/kkultteok/VISUAL_PLAN.md`, `tales/red_car/PLAN.md` '시각 재기획' 절과 같다.

## 1. 방향과 원칙

- **화려하게 하는 장면**: ① 무도회장(7·8장) — 샹들리에·계단·커튼, ② 요정 변신(3장 요정 등장, 4·5·6장 밤 텃밭) — 호박 마차·드레스 반짝, ③ 성 계단(8장 뒤), ④ 신데렐라 집 — 거실(2·9·10장)은 부잣집답게 화려하게, 부엌(1·3장)은 소박하되 겹을 더해 "진짜 부엌" 느낌으로. 집은 장면에 맞게: 새엄마의 거실은 분홍·금빛으로 번쩍이고, 신데렐라가 일하는 부엌은 따뜻하지만 수수하다(이 대비가 이야기다).
- CLAUDE.md §7 "평평한 종이 한 장 + 요소 2~3개"를 이 동화의 모든 장면에서 풀고 **다층 페이퍼아트**로 간다: 먼 층(배경 그림 안쪽, 밝고 연하게) → 중간 층(배경 그림 앞쪽 + 인물 뒤 `put` 소품) → 앞 가림 층(모든 배우 뒤에 `put` 해 맨 앞, 화면 위·아래 모서리).
- **색지 제한 해제(2026-10-22)**: 장면마다 10~20색. 지키는 것 — **1조각 1색**, 광택·그라데이션·펄 금지(유리 구두·샹들리에 '수정'도 무광 Ice Blue 종이 조각), 그림자는 **어두운 웜 그림자**만, 유채색 그림자 금지, 소품 얼굴 없음(샹들리에·촛대·꽃병·호박 덩굴·등불에 눈 없음), 원근법 금지(계단도 기존 `cd2_bg_stairs` 처럼 납작한 띠를 어긋나게 쌓은 모양).
- **광원**: 부엌(1장)·거실(2·9·10장)은 세트 A(낮, 왼쪽 위 → 그림자 오른쪽 아래). 부엌 밤(3장)·텃밭(4·5·6장)·무도회장(7·8장)·계단(8장)은 세트 B(밤, 오른쪽 위 달·앰버 → 그림자 왼쪽 아래). 한 장면 안에서 바꾸지 않는다. 달빛 줄기는 그림 안의 **연한 단색 띠**(투명·그라데이션 없음).
- **인물·누르는 대상 주변 비우기**(무대 1000×560, 배경 1600×902 는 무대 x −40~1040, y −24~585. 그림 가로 % = (무대 x + 40) / 1080, 세로 % = (무대 y + 24) / 609. 사람은 1.35배(`K`)라 키 약 270~285, 바닥 `FL` 532):
  - 1장 부엌: 네 사람이 x 150~640 에 선다 → 세로 55% 아래, 가로 10~65% 는 벽·바닥만. 소품은 벽 위쪽(세로 <50%)과 오른쪽 가장자리(가로 >92%)에.
  - 2·9·10장 거실: 2장 x 190~620 + 편지(330,300), 9장 x 270~800 + 발 카드(320·680, y 360, 위에 크림 덮개), 10장 x 140~885. 즉 **아래쪽 전체**가 인물 자리 → 중간 소품은 가로 <8%·>94% 와 벽 위쪽(세로 <50%)뿐. 편지가 뜨는 자리(그림 가로 30~40%, 세로 45~58%) 벽은 무늬를 성기게.
  - 4·5·6장 텃밭: 호박(660, 톡 대상 ±120 → x 540~780), 마차(190/700/820), 쥐덫(600), 생쥐(420~820), 말(370~660), 요정(260~350), 신데렐라(400~925), 마부·시종(770·845) → 아래쪽 전체. 중간 소품은 가로 <9%·>96% 만. 배경의 꽃·채소는 세로 55~70% 띠(인물 뒤 울타리 아래)에만.
  - 7·8장 무도회장: 춤추는 둘 x 390~610, 언니들 x 760~950, 바구니 720, 시계 카드(250·500·750, y 380, 인물은 0.35 로 흐려짐). **벽시계 자리**(무대 565,118, 지름 150 → 그림 가로 46~63%, 세로 7~39%)는 **민무늬 벽판**(금 몰딩 테두리만). 샹들리에 두 개는 그 양옆(무대 x 300·780).
  - 계단: 신데렐라가 (860,185)→(640,262)→(430,335)→(220,410)→(−150,440)로 달려 내려오고 구두는 (656,260), 왕자는 980→920(y 175). 계단 모양·자리는 **기존 그림과 같게**(refs). 분수·장미 항아리 등 새 요소는 오른쪽 아래(그림 가로 >62%, 세로 >74%)와 왼쪽 위 하늘에만.
- 세로 화면(P)은 가운데 430px 만 보인다. 앞 가림 소품은 그 밖(x < 285 또는 x > 715)에 둔다. 카메라가 따라가는 계단(`follow(520)`)·5장 생쥐(`camTo`)에서는 앞 소품을 두지 않는다.
- 크기 일관성(§4-1): 같은 소품은 어느 장면이든 같은 높이(아래 §8 높이표). 거실의 작은 샹들리에는 무도회장 샹들리에와 **다른 그림이 아니라 같은 그림을 0.73배**로 쓴다(멀리 있는 것이 아니라 작은 샹들리에라 판단 1).

## 3. 신데렐라 집 — 부엌 (1장 재투성이, 3장 혼자 남은 밤)

현재: 회색 돌벽, 아궁이, 창, 빗자루. 밤은 같은 구도의 어두운 판.

바꿈 — 배경 `cd2_bg_kitchen_v2`(세트 A, 기존 `cd2_bg_kitchen` 과 **같은 구도**: 아궁이 왼쪽 가로 0~35%, 창 오른쪽 위 가로 78~100%, 바닥 세로 70% 아래):
- **먼 층**: Warm Stone·Paper Cream 두 색 돌벽(돌 하나하나가 조각), 천장 아래 Bark Brown 들보 한 줄(세로 0~6%).
- **중간 층**: 아궁이(Bean Red·Persimmon 벽돌 두 색, Charcoal 솥, 불꽃 Persimmon+Ember Amber 두 조각), 아궁이 위 선반에 Copper 냄비 2·주전자 1·Sky Blue 무늬 단지 2(가로 5~35%, 세로 8~22%), 들보에 매단 Olive 허브 묶음 2 와 Sunny Yellow 양파 줄 1(가로 40~75%, 세로 6~28%), 가운데 벽 선반에 Paper Cream 접시 4(가로 42~72%, 세로 32~46%), 창(기존 자리)에 Kraft 작은 커튼 한 쌍, 빗자루(기존 자리).
- **앞 층(그림 안)**: Cocoa·Bark Brown 바닥 널 두 색, 아궁이 앞 돌 디딤판.
- 밤 `cd2_bg_kitchen_night_v2`: v2 낮과 같은 구도(refs 둘 다), 창은 Deep Indigo 하늘 + Paper Cream 초승달 + 별 5, 창에서 바닥으로 **Moonlight 달빛 띠 두 줄**(오른쪽 위 → 왼쪽 아래, 세트 B), 벽은 어두운 Warm Stone 톤(`#8F8373` 한 단계 어둡게 한 색지 — 밤용 색지), 아궁이 불은 작은 Ember Amber 한 조각, 선반 위 Sunny Yellow 촛불 하나. 요정 대모가 서는 자리(x 700 ± 150, 세로 55% 아래) 벽은 비운다.

레이어 소품: `cd2_layer_basket_veg`(채소 바구니, 높이 80) x 985, y 585(앞 오른쪽, 1장만). 3장은 소품 없음(요정 반짝이 주인공).

## 10. 코드 작업 (이 문서 확정 뒤, 별도 큐)

- `cinderella.js`: `BGS` 여섯을 `_v2` 로, `ASP` 에 `layer_*` 12개 추가(후처리 ASP 표 측정), `prop()` 으로 소품 생성, 장면 `sceneCard` 콜백에 `put` 순서(중간 소품 → 배우 → 앞 소품).
- 새 도우미: `fireflies(T, n)`, `twinkle(T, n, area)`, `glimmer(T, cx, cy, r)`, `sparkleRing(T, x, y, r, n, colors)`(기존 `sparkle` 확장, 색 인자), `sway(a, deg, ms)`, 백설공주 `tint()` 이식.
- §5 변신 2종, §6 입장 카메라·열두 시 틴트, §7 등불·별 깜빡.
- 테스트: 자동 재생으로 1~10장 앞뒤 사진. 소품이 누르는 대상(언니 머리·호박·쥐덫·시계 카드·발 카드·마지막 신데렐라)과 인물 얼굴·손을 가리지 않는지, 시계가 벽판 위에 또렷한지, 같은 소품이 같은 높이인지(§4-1), 세로 화면에서 앞 소품이 가운데로 들어오지 않는지.
- 컷 5장(`cd2_cut_*`)은 옛 배경을 바탕으로 그려져 있다(판단 2).

## 11. 판단이 필요한 부분

1. **거실 샹들리에 크기**: 같은 그림을 0.73배(높이 110)로 쓴다. §4-1 "같은 소품은 같은 크기" 원칙과 부딪히지만, 이것은 "작은 샹들리에"라는 다른 소품으로 본다. 원칙대로 하려면 거실용 `cd2_layer_chandelier_small` 을 따로 그려야 한다(1장 추가). 추천: 같은 그림 0.73배.
2. **컷 5장 재생성**: `cd2_cut_coach`(텃밭)·`cut_gown`(텃밭)·`cut_midnight`(무도회장)·`cut_stairs_slipper`(계단)·`cut_fit`(거실)은 옛 배경 묘사로 그려져 있어 새 배경과 어긋난다. 새 배경이 나온 뒤 컷 5장을 새 배경을 refs 로 다시 만들지(5장 추가, 기존 항목 프롬프트 수정 필요), 그대로 둘지. 추천: 배경 v2 가 확정된 뒤 다시 만든다(별도 작업표).

## 12. 확정 사항

- 인물·누르는 소품·대사·녹음·조작은 바꾸지 않는다.
- 모든 장면의 배경을 다층으로 바꾸되 집은 거실(화려)·부엌(수수하지만 겹이 있음)으로 나눈다. 1조각 1색·무광·웜 그림자·소품 얼굴 없음·원근법 금지·인물 주변 비우기는 그대로.
- 작업표 18장은 코드가 쓰는 `jobs_cinderella2.json` 끝에 붙였고 기존 항목은 바꾸지 않았다.
