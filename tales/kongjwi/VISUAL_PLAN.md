# 콩쥐팥쥐 — 시각 재기획 (가을 농가의 화려한 다층 페이퍼아트 + 라이트박스 두 장면)

작성 2026-10-23. 사용자 요청: "기존 동화도 화려한 다층 페이퍼아트로 재기획, 큰 순간 1~3장면은 종이 뒤 광원(라이트박스) 실루엣 장면으로."

이 문서는 **배경·레이어 소품·코드 연출**만 다룬다. 인물 그림(콩쥐·새엄마·팥쥐·소·두꺼비·참새·선녀·원님)과 누르는 소품(물동이·항아리·참새 떼·북·장구·꽹과리·꽃신 세 켤레·떡)은 바꾸지 않는다. 대사·녹음·조작(톡 6번: 콩쥐 쓸기, 물동이 3번, 두꺼비, 참새 5번, 콩쥐 징검다리, 북, 나비 꽃신 고르기, 콩쥐 만세)은 그대로다. 코드 좌표는 그림이 온 뒤 이 문서의 자리표를 기준으로 맞춘다.

작업표: `tools/app/gen/jobs_kongjwi.json` 끝에 붙인 21항목(배경 `kj_bg_*_v2` 8 + 라이트박스 배경 `kj_bg_*_lb` 2 + 레이어 소품 `kj_layer_*` 8 + 실루엣 소품 `kj_layer_*_sil` 3). 기존 5항목(키아트)과 기존 그림 파일은 그대로 두고, 코드 `BGS` 를 새 id 로 바꿀 때 옛 배경은 쓰지 않는다(파일 보관).

형식은 `tales/snow_white/VISUAL_PLAN.md` 와 같다.

## 1. 방향과 원칙

- **참고 그림에서 가져온 화려함의 요소**(사용자가 준 스타일 참고 4장, 작업표 refs 에는 넣지 않음): ① lightbox_deer — 흰 종이 7~8겹을 뒤에서 호박빛으로 비춘 빛 상자. 맨 뒤(달·하늘)가 가장 밝고 앞으로 올수록 한 단계씩 어두워져 맨 앞은 검은 실루엣(가지 틀·물결 땅·사람). ② lightbox_whale — 빛 색이 위(파랑)→가운데(보라)→아래(호박)로 층마다 바뀜(층별 색지가 다름, 조각 안 그라데이션 아님). 양옆 나무 줄기가 틀, 구멍 뚫린 종이의 빛 점이 반짝임. ③ lavish_layers — 난색 나무·꽃(주황·분홍·노랑)과 한색 물결 띠 5~6겹의 대비, 색지 15색 이상, 아래쪽 꽃 덤불이 빈틈없이 가득. ④ city_waves — 노을 하늘 색지 띠 3~4장, 실루엣 두 줄, 앞 물결 5겹, 깊이는 밝기 차이로만.
- 우리 규칙으로 옮기면: 먼 층은 밝고 연하게, 앞 층은 어둡고 진하게(§7-2) / 산·논·물결·안개는 **한 장씩 색이 다른 띠 3~6겹** / 나무·꽃 덤불은 양옆·위 모서리에 가득, 가운데 아래(인물 자리)는 민무늬 / 라이트박스는 '종이 뒤 광원': 뒤 층 색지 밝기를 단계로 두고 맨 앞은 `#2E241C`·`#1A1410` 실루엣 / 조각 안 그라데이션·광택·유채색 그림자 금지, 소품 얼굴 없음, 원근법 금지(멀리는 "작게"가 아니라 "연하게").
- **계절을 초가을 하나로 묶는다.** 지금 배경은 마당(여름 초록), 개울(봄 복사꽃), 멍석(가을 벼)이 제각각이다. 새 배경은 모두 **초가을**: 감·국화·코스모스·억새·황금 논·단풍(빨강)·은행(노랑). 원작의 잔치(추수 뒤 마을 잔치)와도 맞는다. 밭 갈기(2장)는 이 계절에 어색할 수 있으나 종이 세상이라 그대로 둔다(§9 판단 아님, 확정).
- **화려하게 하는 장면**: 9장면 모두. 배경 10장(우물가 `jar` 는 3장에서 두 번 쓰임)을 전부 다시 그린다. 그중 **라이트박스 두 장면**: ① **3장 '독 안'(`jarbottom_lb`)** — 두꺼비가 구멍을 막아 주는 기적의 순간. 독 안에서 위를 올려다보는 구도가 그 자체로 빛 상자다(입구가 가장 밝고 독 벽 고리가 앞으로 올수록 어두움). ② **9장 '혼례'(`wedding_lb`)** — 결말의 밤 장면. 보름달·창호 빛·홍등이 뒤에서 빛나고 앞은 소나무 실루엣. 개울의 꽃신(6장)은 낮 장면이고 뒤에 이어지는 잔치(7장)도 낮이라 라이트박스로 하면 시간이 어긋나 **하지 않는다**(§9 판단 3에 선녀 장면 대안을 적음).
- CLAUDE.md §7 "평평한 종이 한 장 + 요소 2~3개"를 풀고 **다층 페이퍼아트**로 간다: 먼 층(배경 그림 안쪽, 밝고 채도 낮게) → 중간 층(배경 그림 앞쪽 + 인물 뒤에 `put` 하는 소품) → 앞 가림 층(모든 배우 뒤에 `put` 해 맨 앞, 화면 아래·위 모서리).
- **색지 제한 해제(2026-10-22)**: 장면마다 10~20색(§2). 지키는 것 — 1조각 1색, 광택·그라데이션·펄 금지, 그림자는 어두운 웜 그림자(`#2E241C`)만, 소품 얼굴 없음(참새는 기존 배역 그림), 원근법 금지.
- **광원**: 낮 장면은 모두 세트 A(왼쪽 위 → 그림자 오른쪽 아래). 라이트박스 두 장면은 '종이 뒤 광원'이라 층 밝기 단계로 표현하되 프롬프트의 경계 그림자 방향은 기존 그대로 둔다.
- **인물·누르는 대상 주변 비우기**(무대 1000×560, `BGBOX` x −40, y −24, w 1080, h 609. 그림 가로 % = (무대 x + 40) / 1080, 세로 % = (무대 y + 24) / 609. 땅선 `GROUND` 505 = 세로 87%). 장면마다 §3~§7 에 적었다.
- 세로 화면(P)은 가운데 430px(x 285~715)만 보인다. 앞 가림 소품은 모두 그 밖(x < 285 또는 x > 715)에 두고, 가로로 긴 아래 띠(`grass_sil`)는 세로 화면에서 두지 않는다. 카메라는 모든 장면 `camSnap(500, 280, 1)` 그대로(§8 에 혼례 진입 때 밀기 하나만 추가).
- 크기 일관성(§4-1): 같은 소품은 어느 장면이든 같은 높이(§7 높이표). 위에서 내려오는 가지(감·버들·소나무)는 y −24 에 걸어 위 모서리에서 나온다. 인물 발 앞을 가리는 앞 소품은 발목까지만(높이 ≤ 120).

## 3. 농가 마당 (1장 마당 쓸기, 3장 우물가, 4장 멍석)

현재: 셋 다 이미 요소가 많지만 색이 초록·흙색뿐이고 계절이 제각각이다. 마당은 여름 초록, 우물가는 감나무가 헐벗었고, 멍석은 가을이다. 인물 뒤 돌담 앞에 볏단·장독이 인물과 겹친다(마당 x 150~330 볏단은 콩쥐 x 440 바로 왼쪽).

바꿈:

### 3-1. `kj_bg_yard_v2` (1장, pass 1, 땅선 세로 62%)
- **먼 층**: Pale Sky → Peach 띠 → 산 3겹(Mist Blue, Slate Blue, Pine Green; 멀수록 연함) → 크림 구름 두 장.
- **중간 층**: 돌담(가로 8~92%, 위가 세로 48%) 뒤로 가을 나무 줄(은행 노랑·단풍 빨강·감 주황·소나무). 왼쪽 0~28%: 초가집 모서리(초가·흙벽·문살·툇마루), 장독 셋, 볏단 둘. 오른쪽 82~100%: 감 달린 감나무와 둘째 초가 모서리, 나무 대문. 국화(노랑·흰)·코스모스는 **담 양 끝(28% 왼쪽, 82% 오른쪽)에만**. 담 면 30~90% 는 민무늬 돌.
- **앞 층(그림 안)**: Honey Earth 흙 한 장(세로 62~100%), 가로 30~90% 완전히 비움. 돌·풀은 양 모서리 8% 안에만.

### 3-2. `kj_bg_jar_v2` (3장, pass 2 ← `kj_bg_jar.png`)
- **유지**: 우물과 틀·두레박(가로 6~28%, 세로 25~72%), 땅선(세로 62%). 프롬프트에 "EXACTLY at the same position and size as the reference; only the surroundings change".

## 11. 판단이 필요한 부분

1. **개울 징검돌 높이**: 지금 배경의 징검돌 다섯은 그림 세로 58~65%(무대 y ≈ 330~370)에 있고 콩쥐 발은 505(세로 87%), 꽃신은 y 540~560 으로 떠내려간다. 즉 콩쥐는 돌이 아니라 **앞 모래 둑 위를 뛰고**, 꽃신도 모래 위를 떠내려간다(AUDIT 에 "화면 미확인"으로 남아 있던 장면). 브리프 지시대로 물·징검돌 자리를 유지하는 pass 2 로 작업표를 썼다. **대안**: 물 띠를 세로 70~100% 로 내리고 징검돌 네 개를 x 370·445·520·595(세로 87%)에 두면 콩쥐가 돌을 밟고 꽃신이 물에 떠내려간다. 대안을 고르면 `kj_bg_stream_v2` 를 pass 1 로 바꾸고 SCENE 의 '유지' 문장을 "water band from 70% of the height to the bottom, four stepping stones at 38%, 45%, 52%, 59% of the width on the 87% line" 로 고친다(코드 좌표는 안 바뀜). 추천: **대안**(아이가 "징검다리를 건너요"를 눈으로 확인할 수 있다).
2. **원님 댁 대문**: 원님(사또) 댁인데 지금은 초가 대문이다. 기와 솟을대문으로 바꾸면 '유지' 원칙(대문 자리·크기)과 어긋나므로 초가 그대로 두고 둘레만 화려하게 했다. 기와로 바꾸려면 `kj_bg_gate_v2` 프롬프트에 "replace the thatch roof of the gate with a roof-slate tiled roof of the same size" 한 줄만 더한다. 추천: 기와로 바꾼다(위치는 유지).
3. **세 번째 라이트박스 — 선녀 장면(5장)**: 브리프의 후보(독 안·개울·혼례) 중 개울은 낮이라 뺐다. 대신 선녀가 내려오는 5장을 '창호지 문이 뒤에서 환한' 실내 라이트박스로 할 수 있다(문·창 빛 Honey Amber, 벽·가구 실루엣, 콩쥐·선녀 자리 마루는 민무늬). 다만 선녀 얼굴(y 150~190, 세로 29~35%)이 창(20~42%) 바로 옆에 떠 있어 밝은 판과 겹칠 위험이 있다. 지금은 낮 방 안 v2 로 두었다. 추천: 두 장면으로 충분, 선녀 장면은 반짝(코드)으로.
4. **혼례 라이트박스의 홍등 줄 소품**: 실루엣이 아니라 컬러(Persimmon·Ember Amber) 소품을 중간 층에 건다. 라이트박스 안에서 '빛나는 것'은 색을 가져도 되지만 순수한 실루엣 미학을 원하면 뺀다(배경에 지붕 홍등 둘은 남음). 추천: 건다.
5. **계절 통일(초가을)**: 밭 갈기(2장)가 가을에 어색하다고 보면 2장만 봄(연두 언덕·흰 꽃)으로 둘 수 있다. 지금 `kj_bg_field_v2` 는 가을(단풍·메밀꽃·황금 띠)이다. 추천: 통일 유지.

## 12. 확정 사항

- 인물·동물·누르는 소품·대사·녹음·조작은 바꾸지 않는다. 배경 10장 전부 새로, 라이트박스는 3장 '독 안'과 9장 '혼례' 둘.
- 우물·입구와 구멍·멍석·문/창/병풍·물과 징검돌·대문은 기존 자리·크기(pass 2 + refs). 땅선 505(세로 87%)는 모든 장면 같다.
- 1조각 1색·무광·웜 그림자·소품 얼굴 없음·원근법 금지·인물 주변 비우기·세로 화면 앞 소품 가운데 금지는 그대로.
- 작업표 21장은 `jobs_kongjwi.json` 끝에 붙였고 기존 5항목은 바꾸지 않았다. 그림 생성과 코드 수정은 이 문서 확정 뒤 별도 큐.
