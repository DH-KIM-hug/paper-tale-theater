# 구름 공장 — 콘텐츠 묶음

여기 있는 원고는 **초안**이다. 사람이 소리 내어 읽어 보고 고쳐 쓴다. 서버는 아이 수와 막내 나이로 벌을 고르고 이름·조사·호칭만 바꾸므로, 원고의 리듬과 말맛은 전적으로 이 파일을 쓰는 사람 몫이다. 토큰 규칙은 `docs/manuscript-format.md`.

## 파일

```
story.json                제목 틀, 장면 수, 역할표, 자세 목록, 표지 장면
manuscripts/
  c1-sound.json           아이 1명 · 막내(= c1) 소리 대사
  c1-sentence.json        아이 1명 · 문장 대사   (대사를 3분의 1로 줄인 벌)
  c2-sound.json           아이 2명 · 막내(= c2) 소리 대사
  c2-sentence.json        아이 2명 · 문장 대사
  c3-sound.json           아이 3명 · 막내(= c3) 소리 대사
  c3-sentence.json        아이 3명 · 문장 대사   ← 기준 원고. 다른 7벌은 여기서 파생
  c4-sound.json           아이 4명 · 막내(= c4) 소리 대사 (찾는 아이가 "어! 어!" 하고 가리킨다)
  c4-sentence.json        아이 4명 · 문장 대사   (찾는 아이 "저기 봐!" 5줄 추가)
layout/c1.json … c4.json  장면별 캐릭터 자리·자세·크기 (아이 수별)
backgrounds/01.svg … 16.svg  배경 자리표시 그림 (원화가 오면 같은 번호의 png로 바꾼다)
tools/validate.mjs        `node content/tools/validate.mjs` — 토큰·장면 수·자세·안전 영역 검사
```

벌 고르는 규칙: 막내가 만 3세 미만이면 `*-sound.json`, 아니면 `*-sentence.json`. 단추는 늘 "따라 하는 아이"가 누른다 (1명이면 c1, 2명이면 c2, 3~4명이면 c3).

## 16장면 개요

1. 아침, 창밖. 구름이 하나, 둘, 셋. "구름은 어디서 올까?"
2. 강아지가 코를 킁킁. "구름 냄새다!" 문밖으로 달려 나간다.
3. 냄새만 따라 언덕을 넘고 풀밭을 지난다. 길가 꽃을 살짝 만진다.
4. 언덕 위 굴뚝. 하얀 구름이 퐁! 퐁! (4명 벌: "저기 봐!")
5. 굴뚝 아래 동그란 공장 문. 살짝 미니 끼이익, 강아지가 먼저 들어간다.
6. 구름 공장 안. 구름 솥이 보글보글, 퐁! 퐁! 다 같이 외친다.
7. 구름을 톡 건드리면 토끼, 물고기. 퐁! 퐁! 퐁!
8. 구석의 빨간 단추. "눌러도 돼?" 따라 하는 아이가 꾹!
9. 덜컹. 작은 아기 먹구름이 나왔다. 눈이 그렁그렁. "왜 울어?"
10. "나는 하얗지 않아." 훌쩍, 후두둑. 눈물이 비가 되어 모두 흠뻑.
11. 위로. "비 좋아! 장화 신고 첨벙첨벙!"
12. 번쩍! 우르르 쾅! 아이들이 강아지를 꼭 껴안는다. "괜찮아, 괜찮아."
13. 먹구름이 눈물을 닦고 처음으로 방긋. 비가 그친다.
14. 하늘에 무지개. "누가 만들어?" "내가!" 퐁!
15. 해가 기울고 집으로. "먹구름아, 또 놀자!" 강아지가 앞장선다.
16. 밤, 창밖. 작은 먹구름이 손을 흔든다. "잘 자, 먹구름아." 퐁.
