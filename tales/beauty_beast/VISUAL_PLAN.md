# 미녀와 야수 — 시각 재기획 (아주 화려한 눈보라 성·연회장·장미 정원·변신)

작성 2026-10-22. 사용자 요청: "공주 동화들도 화려함이 필요한 부분들 아주 화려하게 재기획."

이 문서는 **배경·레이어 소품·연출**만 다룬다. 인물(벨·야수·왕자·아버지·언니들·말) 그림, 대사, 녹음, 조작(톡 2·배움 3)은 바꾸지 않는다. 줄거리·장면 수(11장)도 그대로다. 코드 좌표는 그림이 온 뒤 SPEC §3 에 맞춰 고친다.

방향: **사람 세계(시골집 1·2·6·10장)는 수수하게 그대로** 두고, **야수의 궁전(3·4·5·7·8·9·11장)만 아주 화려하게** 한다. 시골집 → 궁전으로 넘어갈 때 색과 밀도가 확 바뀌는 대비가 이 동화의 "겉모습" 교훈과도 맞는다. 새 배경 `bb_bg_*_v2` 는 지금 배경을 참고 그림으로 넣어 **같은 구도·같은 바닥선·같은 빈 자리**를 지킨다. 기존 파일은 그대로 둔다.

작업표: `tools/app/gen/jobs_beauty_beast.json` 끝에 추가한 13항목(`bb_bg_*_v2` 배경 5 + `bb_layer_*` 소품 8). 코드·그림 생성은 이 문서를 확정한 뒤 한다.

## 1. 지키는 것

- **1조각 1색.** 금장식도 Straw Gold 종이 한 장이다. 광택·펄·그라데이션 금지. 촛불·샹들리에 불꽃은 Ember Amber 종이 조각(뒤 백라이트 번짐 없음).
- **그림자는 어두운 웜 그림자만.** 밤 장면에서도 남색 그림자를 쓰지 않는다.
- **소품에 얼굴 없음.** 촛대·샹들리에·찻잔·시계·토피어리·장미에 눈·입을 넣지 않는다(디즈니식 말하는 가구 금지는 PLAN 과 같다).
- **원근법 금지.** 연회장 바닥·천장도 평평한 띠로만.
- **인물·누르는 대상 주변 비우기.** 4장 장미 덤불 둘(많고 적음 세기), 7B 꽃병 셋(위·아래·옆), 8장 창문 카드 셋, 11장 샘 — 이 둘레에는 배경 장미·꽃병·창문·물을 두지 않는다(아래 §4 '비우는 자리').
- **광원 한 방향.** 세트 A(낮 정원·벨의 방·시골집)는 왼쪽 위, 세트 B(눈보라 밤·연회장 저녁)는 오른쪽 위.

## 6. 코드 작업 (이 문서 확정 뒤, 뒤의 큐)

- `beauty_beast.js`: `BGS` 에 `snow_forest_v2`·`dining_v2`·`garden_v2`·`garden_bloom_v2`·`room_v2` 추가(또는 `BGV2 = {…}` 로 `bgSrc` 분기). 장면 호출을 v2 로 바꾸고 `cottage`·`cottage_front` 는 그대로. `ASP` 에 `layer_*` 8개 추가, post 뒤 측정.
- `put` 순서: 중간 소품 → 배우 → 앞 소품. 3B·8 의 `feast` 는 `tableL` 다음에 put.
- 4장에는 앞·중간 소품을 두지 않는다(세기 놀이). 5·7A·11 만 토피어리·덤불.
- 11장 크로스페이드 함수(구름 공장 16장과 같은 방식: `T.bg` 두 번째 image + opacity 애니메이션) + 꽃잎 흩날림 + sparkle 2배.
- 효과음 규칙 유지: 새 효과음 없음.
- 테스트: 자동 재생으로 3A·3B·4·7B·8·11장 사진. 4장 덤불 둘이 배경과 또렷한지, 8장 카드 셋이 벽과 또렷한지, 11장 크로스페이드 전후 담·문 자리가 같은지.

## 7. 판단 필요

1. **4장 배경 장미의 범위**: 추천은 "장미는 담 위 덩굴 띠와 궁전 창가에만, 눈밭에는 없음"으로 v2 를 4장에도 쓰는 것(5·7A·11 과 같은 장소라는 연속성). 그래도 아이가 담 위 장미까지 셀까 걱정되면 **4장만 기존 `garden` 유지**(코드에서 4장 호출만 그대로 두면 됨).
2. **11장 끝의 봄 정원 크로스페이드**: 원작은 변신 뒤 계절을 말하지 않는다. "눈 속 장미"가 겨울 설정이므로 눈이 녹고 꽃이 피는 것은 마법이 풀린 표시로 읽히지만 각색이다. 거절하면 `bb_bg_garden_bloom_v2` 항목을 작업표에서 지우고 11장은 `garden_v2` 로 끝낸다(꽃잎·반짝은 그대로).

## 8. 확정 사항

- 인물 그림·대사·녹음·조작은 바꾸지 않는다. 시골집 두 배경은 그대로(사람 세계는 수수하게).
- 새 배경은 `*_v2` 5장, 기존 파일은 참고 구도로 쓰고 남긴다.
- 4장 세기 놀이·7B 위치 놀이·8장 순서 놀이 둘레에는 배경 장미·꽃병·창·밝은 무늬를 두지 않는다.
- 1조각 1색·광택 금지·소품 얼굴 없음·원근법 금지·광원 한 방향은 그대로.
