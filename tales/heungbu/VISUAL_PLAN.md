# 흥부와 놀부 — 시각 재기획 (화려한 다층 페이퍼아트 + 라이트박스 2장면)

작성 2026-10-23. 사용자 요청: "기존 동화도 새 동화와 같은 수준의 다채롭고 화려한 다층 페이퍼아트로 다시 그린다. 큰 순간은 종이 뒤 광원(라이트박스) 실루엣 장면으로."

이 문서는 **배경·레이어 소품·코드 연출**만 다룬다. 인물 그림(흥부·흥부 아내·놀부·놀부 아내·제비·아기 제비·도깨비 컷)과 누르는 소품(박 `gourd2_*`·줄기 `gourd2_vine`·씨앗 `seednf`·쌀자루 `ricenf`·금은보화 `treasurenf`·붕대 컷)은 바꾸지 않는다. 대사·녹음·조작(톡·톡톡톡 세기)은 그대로다. 코드 좌표는 그림이 온 뒤 이 문서의 자리표를 기준으로 맞춘다.

작업표: `tools/app/gen/jobs_heungbu.json` 끝에 붙인 21항목(배경 `hb_bg_*_v2` 7 + 라이트박스 배경 `hb_bg_*_lb` 2 + 레이어 소품 `hb_layer_*` 7 + 실루엣 소품 `hb_layer_*_sil` 5). 기존 키아트 5항목과 기존 그림 파일(`assets/v3w/hb_bg_*.webp`)은 그대로 두고, 코드의 `scene()` 키만 새 id 로 바꾼다(옛 배경 파일 보관).

형식은 `tales/snow_white/VISUAL_PLAN.md` 와 같다.

## 1. 방향과 원칙

### 1-1. 참고 그림에서 가져오는 화려함 (`assets/raw/refs_visual/`, 스타일 참고만, refs 에 넣지 않음)
- **lightbox_deer**: 흰 종이 7~8겹을 뒤에서 호박빛으로 비춘 빛 상자. 가장 뒤(달·하늘)가 가장 밝고 앞으로 올수록 한 단계씩 어두워져 맨 앞은 검은 실루엣(가지 틀·물결 땅·사람). → 가을 노을 장면(5장)의 구조.
- **lightbox_whale**: 빛 색이 층마다 다르다(위 파랑 → 가운데 보라 → 아래 호박). 양옆 큰 나무가 틀을 만들고, 구멍 뚫린 종이의 빛 점이 반짝인다. → 박 장면(7장)의 '뒤에서 쏟아지는 금빛'과 빛 점.
- **lavish_layers**: 색지 15색 이상, 물결 띠 5~6겹, 양옆·위 모서리를 나무·꽃이 가득 채우고 가운데는 비운다. → 봄 들판(1·6장)·기와집(10장)의 벚꽃 틀과 산 띠.
- **city_waves**: 노을을 색지 띠 3~4장으로, 실루엣 층은 단색, 깊이는 밝기 차이로만. → 가을 하늘의 띠 구조.
- 우리 규칙으로 옮기면: ① 먼 층은 밝고 연하게, 앞 층은 어둡고 진하게(§7-2) ② 산·안개·들판 띠는 **한 장씩 색이 다른 띠 4~6겹** ③ 나무·꽃은 양옆·위 모서리에, 가운데 아래(인물 자리)는 민무늬 ④ 라이트박스는 '종이 뒤 광원': 뒤 층 밝기를 단계로 두고 맨 앞은 `#2E241C`/`#1A1410` 실루엣 ⑤ 조각 안 그라데이션·광택·유채색 그림자 금지, 소품 얼굴 없음, 원근법 금지(멀리는 "작게"가 아니라 "연하게").

### 1-2. 어느 장면을 화려하게, 어느 장면을 라이트박스로
- **모든 장면(10장, 배경 8종)을 다층으로 다시 그린다.** 장면군은 넷: ① 봄 들판(1·6장 `sky_spring`), ② 흥부네(3장 `eaves`, 4·7장 `yard`), ③ 놀부네(2장 `nolkitchen`, 8장 `nol_eaves`, 9장 `nolyard`), ④ 기와집(10장 `giwa`).
- **라이트박스 2장면**:
  - **5장 가을 — 제비가 남쪽으로 떠나요** (`hb_bg_sky_autumn_lb`). 인물이 제비 한 마리뿐이고 하늘이 주인공이라 빛 상자에 가장 잘 맞는다. 해가 가장 밝은 뒤 층, 산이 한 단계씩 어두워지고, 맨 앞은 갈대·마른 나무 실루엣. 이별의 큰 순간.
  - **7장 박이 열렸어요 — 첫 박을 타는 순간** (`hb_bg_yard_lb`). 이야기의 절정. 장면은 낮 마당(`hb_bg_yard_v2`)으로 시작해 박을 세고, **첫 박을 톡 하는 순간 배경이 금빛 라이트박스 마당으로 바뀐다**(같은 구도, 빛만 바뀜). 하늘 뒤에서 보물 빛이 쏟아지고 초가·돌담·감나무가 중간 어둠 층이 된다.
  - 후보였던 '봄에 제비가 돌아오는 하늘'(6장)은 넣지 않는다. 6장은 1장과 같은 배경을 쓰고(흥부 인사 장면은 밝은 낮이어야 함), 가을 노을(떠남) ↔ 봄 낮(돌아옴)의 대비가 더 또렷하다. §9 판단 2.
- 광원: 낮 장면은 모두 세트 A(왼쪽 위 → 그림자 오른쪽 아래). 라이트박스는 '종이 뒤 광원'이라 층 밝기 단계로 표현하되 경계 그림자 방향은 프롬프트 그대로(오른쪽 아래).
- **인물·누르는 대상 주변 비우기**. 무대 1000×560, 배경 1600×902 는 `BG = {x −40, y −24, w 1080, h 608.7}` 로 깔린다(엔진 기본과 같음). 그림 가로 % = (무대 x + 40)/1080, 세로 % = (무대 y + 24)/608.7. 땅선 `GROUND = 500` → **세로 86%**. 인물은 세로 30~86% 를 쓴다. 장면별 비울 영역은 §3~§6 에 적고 프롬프트에 `CRITICAL EMPTY AREA` 로 넣었다.
- 세로 화면(P)은 가운데 430px(x 285~715)만 보이고 `fx()` 가 인물을 가운데로 모은다. 앞 가림 소품은 그 밖에 두거나 세로에서는 두지 않는다(장면별 표에 P 자리 적음).
- 크기 일관성(§4-1): 같은 소품은 어느 자리든 같은 높이(§8 높이표). 먼 층의 나무·산은 "작게"가 아니라 "연한 색지"로.

## 4. 흥부네 (3장 흥부네 집 처마 · 4장 마당 · 7장 박이 열렸어요)

### 4-1. 3장 처마 `hb_bg_eaves_v2` (pass 2 ← `hb_bg_eaves.png`)

## 9. 코드 작업 (이 문서 확정 뒤, 별도 큐)

- `heungbu.js`: `scene()` 호출 키를 새 id 로 — `sky_spring→sky_spring_v2`, `nolkitchen→nolkitchen_v2`, `eaves→eaves_v2`, `yard→yard_v2`, `sky_autumn→sky_autumn_lb`, `nol_eaves→nol_eaves_v2`, `nolyard→nolyard_v2`, `giwa→giwa_v2`. 가장 간단한 방법은 `scene()` 안에 `const BGS = {sky_spring:'sky_spring_v2', …}` 표를 두고 `U('bg_' + (BGS[key] || key))` 로 바꾸는 것(읽어 주기 대본 `read_script_el.json` 의 `set:<키>` 는 그대로 둔다). `preload` 목록도 같이.
- `AR` 표에 `layer_*` 12개 추가(`ASP.txt` 에서). `U()` 는 `layer_*` 이름을 그대로 `hb_layer_*.webp` 로 만들므로 손댈 것 없음.
- 새 도우미: `prop(name, x, h, y, front)`(= `spr` + `pointerEvents none`, front 면 배우 만든 뒤 `T.world.appendChild`), `petals(T, n)`·`leaves(T, n)`(낙하), `lightDots(T, n, box)`(반짝 점), `sparkleRing`(신데렐라 이식), `tint`(백설·신데렐라와 같은 코드), `toLightbox(fromKey, toKey)`(§6-2 순서), `wiggle` 은 엔진 것.
- 장면 콜백 순서: 중간 소품(장독) → 배우 → 앞 소품(가지·풀·실루엣). 7장은 낮 소품을 만들어 두고 `toLightbox()` 에서 교체.
- 5장: `scene('sky_autumn_lb')` 뒤 tint 걷기 → 빛 점 → 제비 비행(기존) → 컷.
- 테스트: 자동 재생으로 10장면 앞뒤 사진(가로·세로). 소품이 인물 얼굴·손·누르는 대상(박·쌀자루·줄기·둥지·흥부)을 가리지 않는지, 7장 라이트박스에서 박·쌀자루·보물이 또렷한지, 세로 화면에서 앞 소품이 가운데로 들어오지 않는지, 같은 소품이 같은 높이인지(§4-1). 컷신(`hb_cut_*`)은 손대지 않는다(기존 그림).

## 10. 판단이 필요한 부분

1. **7장 라이트박스 전환 시점**: 첫 박을 톡 하는 순간(이 문서) vs 둘째 박(금은보화)이 열릴 때. 첫 박부터 바꾸면 쌀·보물·새집 세 번의 복이 모두 금빛 안에서 일어나 장면이 하나로 묶인다. 둘째 박으로 늦추면 '쌀'은 낮, '보물'부터 밤이 되어 전환 자체가 보물의 효과처럼 보인다. 추천: 첫 박(작업표·코드 계획은 이 기준).
2. **6장 봄 제비 귀환을 세 번째 라이트박스로 할지**: 새 배경 `hb_bg_sky_spring_lb` 1장(+ 벚나무 실루엣 소품 1장)이 더 든다. 흥부(컬러)가 x 531~749 에 서고 제비가 비행하므로 밝은 하늘 앞에 흥부가 서게 되어 §3 규칙(인물 뒤는 중간 밝기판)과 맞추기 까다롭다. 추천: 넣지 않는다(가을 밤 ↔ 봄 낮 대비).
3. **pass 2 배경의 둥지 자리**: 3장 둥지 소품(`chicks` x 421~564, 세로 7~25%)과 배경에 그려진 둥지(가로 56~67%)가 지금도 정확히 겹치지는 않는다(코드 주석과 달리 배경 둥지가 조금 오른쪽). v2 에서도 기존 자리를 그대로 두게 했으므로 상태는 같다. 둥지를 소품 자리(가로 42~56%)로 옮겨 그리게 하면 더 깔끔하지만 '기존 자리 유지' 원칙에 어긋난다. 추천: 이번엔 그대로, 받은 뒤 사진으로 확인해 코드 x 를 맞춘다.
4. **놀부네 색**: 놀부네(2·8·9장)는 기와·꽃담·장독 줄로 '부유함'을, 흥부네(3·4장)는 초가·논·유채로 '가난하지만 따뜻함'을 구분했다. 놀부네를 더 요란하게(단청 색 `Persimmon`·`Sky Blue` 띠) 하고 싶으면 §2-3 에 두 색을 더해 프롬프트를 고친다(지금은 넣지 않음).
