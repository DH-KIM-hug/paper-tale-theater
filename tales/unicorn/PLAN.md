# 유니콘을 찾아서 — 기획 (창작 동화, 2026-10-21, 외부 기획안 참고 재기획)

참고: 작가 전달용 종합 기획안(16p 대본·숨은 힌트·팔레트·레이어)을 우리 원칙(CLAUDE.md)에 맞게 옮겼다. 줄거리 뼈대(만남→도움→실망 3번, 뒤에서 지켜보던 유니콘, 포옹)는 그대로 둔다.

교훈(내부 목표, 대사로 명시하지 않음): **친절한 마음을 보고 있는 존재가 있다. 진심을 다할 때 더 가까이 있다.**

## 이 동화의 시각 예외 (2026-10-22 사용자 지시): 화려한 다층 페이퍼아트
- 사용자: "전반적으로 페이퍼아트이되 아주 화려하게 만들어 봐." "이 동화는 색채감이 중요해."
- 이 동화는 CLAUDE.md §4·§7-6 배경 규칙('평평한 종이 한 장 + 요소 2~3개')의 **예외**다. 종이 층을 많이 겹친 풍성한 장면으로 만든다: 꽃·잎·별·구름·물결 조각을 여러 겹, 색지 조각 수를 많게, 장식 무늬는 오린 종이로. 대비가 큰 색 조합, 장면마다 주인공 색 하나(§연출 재기획 2 색채 계획).
- **팔레트 제한 해제(유니콘만, 2026-10-22 사용자 지시 "이 세상의 모든 색상의 종이가 있다고 생각해서")**: 이 동화는 CLAUDE.md §7-4 팔레트 토큰에 묶이지 않는다. 분홍·민트·청록·라임·코랄·라일락·하늘·살구·금색 등 색지 수십 가지를 자유롭게 쓴다. 라벤더 `#8B7BB8` 금지 규칙도 이 동화에서는 해제한다. CLAUDE.md 는 고치지 않고 이 문서에만 기록한다. 장면별 색지 목록은 §연출 재기획 2.
- 그래도 지키는 종이 원칙: **1조각 1색**(색이 많아도 조각마다 단색. 그라데이션·광택·볼륨 셰이딩 금지, 펄은 유니콘 뿔·갈기 띠만), 깨끗한 절단면, 깊이는 경계 그림자와 겹침으로만, **그림자는 여전히 유채색 금지**(어두운 웜 그림자 `#2E241C` 만), 사물에 얼굴 없음, 원근법·3D 금지.
- **인물 주변은 비워 둔다**: 화면이 복잡해도 인물·동물과 아이가 누르는 대상(색 조각, 구름, 가시, 유니콘) 둘레에는 장식 조각을 두지 않는다. 풍성함은 화면 가장자리(앞 레이어)와 먼 층(배경 안)에만 둔다. 가림 소품은 인물과 겹치지 않는 자리에 둔다.
- 반투명(opacity 낮춘 그림)은 어디에도 쓰지 않는다. 숨은 유니콘은 실제로 물체 뒤에 두는 z 순서로만 숨긴다.

## 바꾼 것 (우리 원칙 적용)
- **페이지 16장 → 장면 10장.** 3번의 "만남·도움·실망"은 3장면으로 유지하고, 표지·뒤표지는 장면이 아닌 시작·끝 화면으로 옮긴다.
- **"펄 광택·호일 반짝임·그라데이션·드롭섀도우"는 쓰지 않는다.** 우리 원칙: 1조각 1색, 광택 금지. 뿔과 갈기의 무지개는 **색지 띠 조각 7장**(빨·주·노·초·파·남·보)을 겹쳐 만든다. 펄 대신 흰 한지 결.
- **말의 털을 무지개색으로 하지 않는다.** 유니콘과 헷갈리지 않게 말은 **밤색 몸 + 파란 리본**. 무지개는 유니콘 것.
- **그라데이션 뿔 → 색 띠**(나선 띠 3~4장으로 풀린 느낌).
- **배경 팔레트**는 우리 토큰으로 정한다(아래 §6).
- **사람 키·조랑말 크기:** 유니콘은 아이가 안을 수 있는 조랑말 크기 = 아이 머리 폭 기준 3.5배 높이(몸통 길이), 말은 유니콘과 같은 크기로 두되 색으로 구분.

## 펄 종이 예외 (사용자 결정 2026-10-21)
- 유니콘의 **뿔 띠와 갈기 띠에만** 펄 종이 한 장씩 쓴다(색지 한 장 = 한 색 규칙은 그대로). 몸·인물·배경·소품·힌트는 무광.
- 나머지 동화에는 적용하지 않는다(CLAUDE.md §7-1 예외 문장 참고).

# 연출 재기획 (2026-10-22)

## 0. 사용자 지적 (2026-10-22)
1. 배경이 밋밋하다 — 연출이 정면 일자 배치라서. → 깊이 평면 3~4개와 카메라 변화(§3·§4).
2. 유니콘이 부위별로 숨어 있는 게 어색하고 반투명도 이상하다. → 장소별 '숨는 자세' + 가리는 물체로 전면 재설계(§8).
3. 폭포 위치가 완전히 잘못됐다. → 폭포를 배경 안에 그리고 좌표 기준을 정한다(§5).
4. 걷는 속도가 너무 느리다. → 이동 시간표(§7).
5. 양이 뛰어내리는 곳이 어색하다. → 높이·거리·착지(§6-1).
6. 양의 집이 없다. → 3장에 양의 집과 엄마 양, 헤어지는 연출(§6-2).
7. 전체를 화려한 다층 페이퍼아트로, 색채감이 중요. → 맨 앞 시각 예외 + 색채 계획(§2).
8. 색지는 이 세상 모든 색을 쓴다(팔레트 해제). → §2-2 장면별 색지 10~20색.
9. 아이 이름 '다현이'. → §12.
10. 다현이 옷은 공주 옷. → §13.

## 1. 깊이 평면 (정면 일자 배치를 버린다)
한 장면은 뒤에서 앞으로 **네 평면**이다. 원근법·3D 는 금지이므로 깊이는 **겹침 · 크기 차이(소품만) · 밝기·채도 차이**로만 낸다. 인물 크기는 전 장면 같다(§4-1).

| 평면(z 뒤→앞) | 무엇 | 깊이 표현 | 그림 |
|---|---|---|---|
| P0 먼 배경 종이 | 하늘 + 먼 층 2~3겹(먼 언덕·먼 구름·먼 나무)을 **한 장**에 그린다 | 멀수록 밝고 채도 낮게 | `uc_bg2_*` 6장(새 id, 옛 `uc_bg_*` 파일은 그대로) |
| P1 중간 소품 | 장면의 사건 소품: 양 구름·양의 집·무지개·가시 덤불·달 무리·길모퉁이 덤불 | 인물과 같은 밝기 | `uc_mid_*`, 기존 `uc_prop_*` |

## 4. 배경 재생성 원칙
- 6장 모두 새 id `uc_bg2_*` 로 다시 그린다(화려한 다층 + 폭포 위치). 옛 `uc_bg_*` 파일과 작업표 항목은 지우지 않고 '교체 예정' 표시만.
- 배경 한 장 = 하늘 종이 + 먼 층 2~3겹 + 가까운 땅. 먼 층일수록 밝고 저채도. **가운데·아래 가운데(인물 자리)는 비운다.**
- 8장 빈 길만 일부러 조각이 적다(외로움). 그 앞뒤 장면이 화려해서 대비가 생긴다.
- 폭포(6~7장)·달(9~10장)·해는 배경 안에 그린다. 무지개·달 무리·양의 집·덤불은 소품(움직이거나 나타나야 함).

## 5. 폭포 장면 구도 (6~7장) — 폭포는 배경 안에
- **결정: 폭포 기둥은 `uc_bg2_waterfall` 배경 안에 그린다.** 소품 `uc_prop_waterfall` 은 쓰지 않는다(쓰지 않음 표시). 이유: 절벽 턱→기둥→웅덩이가 한 장에서만 정확히 이어진다. 폭포는 움직이지 않으므로 소품일 이유가 없다. 움직여야 하는 물보라(가림)와 무지개만 소품이다.
- 배경 안 배치(그림 비율 → 월드):

## 8. 숨은 유니콘 재설계 (반투명 금지)
### 8-1. 방식 결정
- **몸 전체 실루엣이 있는 '숨는 자세'를 그리고, 별도의 가리는 물체(앞·중간 레이어 소품)가 z 순서로 덮는다.** 보이는 부분만 잘라 그린 부분 그림(옛 `uc_hint_*` 5장)은 쓰지 않는다. 가리는 물체와 유니콘을 한 장으로 그리는 방식도 쓰지 않는다.
- 이유: ① §4-1 — 머리·몸 폭을 기준 그림(`uc_unicorn_stand`)과 같은 수치로 잴 수 있다(부분 그림은 잴 부위가 없고, 한 장 합성 그림은 배경과 색이 붙어 크기를 못 바꾼다). ② 가리는 물체가 그 장면의 깊이 소품을 겸한다(구름·둥치·물보라·덤불). ③ 3~4세에게 '저기 뒤에 있다'가 분명하다: 9장에서 같은 유니콘이 덤불 뒤에서 **걸어 나오는** 연속성이 생기고, 10장에서 같은 크기로 선다. ④ 보이는 비율은 코드에서 위치만 옮겨 조정한다.
- 주의: 가림 소품은 유니콘 상자보다 20 % 이상 크게, 바닥은 유니콘 발보다 아래. 발굽이 새어 나오면 유니콘을 조금 위로(멀리 있으면 바닥이 높아지는 원근은 허용).
- 투명도(opacity)는 0 또는 1 만. 반짝 효과(glow)는 10장에만.

### 8-3. 크기 일관성 (§4-1)
- 숨는 자세 5장은 ref 에 `uc_unicorn_stand` 를 넣고 "머리·몸 크기를 기준 그림과 똑같이, 조랑말 크기"를 프롬프트에 쓴다. 전신이 그림 안에 다 있어야 한다(가림은 코드).

- 엄마 양 1.4 : 작은 양 1 (털뭉치 폭 기준). 양의 집은 엄마 양 1.3.
- 테스트: 1·2·4·6·9·10장 사진을 나란히 놓고 유니콘 몸통 길이·얼굴 폭을 비교한다.

## 13. 다현이 공주 옷 (2026-10-22 사용자 지시)
- 기존 멜빵바지·버킷 모자(성별 중립)를 **공주 드레스**로 바꾼다. 3~4세 그림책 느낌의 페이퍼아트 드레스: 색지 여러 겹 프릴로 부풀린 치마, 작은 왕관(금색 색지, 광택 없음), 허리 리본, 별 장식 조각 2~3개(색지, 반짝임 없음). 길이는 **발목 위**(걷기·뛰기·안기 동작에 걸리지 않게, 신발이 보인다). 머리(짧은 단발)·얼굴은 기존 일반 캐릭터 그대로(실제 아이 얼굴·사진 참고 금지).
- **주 색 권장: Blush Pink `#F3A9BE` 치마 + Rose `#D8708F` 가슴판·리본.** 이유: ① 무지개 7색에 분홍이 없어 유니콘·무지개와 겹치지 않는다. ② 흰 유니콘, 초록 언덕, 남색 밤, 하늘색 구름 나라, 저녁 살구 하늘 어디서도 튄다. ③ 3~4세가 '공주'로 바로 읽는다. 보조: 왕관·별 Marigold `#F2B134`, 속치마 프릴 Snow White `#F4F6FA`, 별 조각 Lemon `#F6E27F`, 신발 Bean Red `#A93B32`(기존). 대안: Mint `#7FD8D3` + Teal `#2A9D8F`(폭포 물색과 겹쳐 비권장).
- **크로마키 주의**: 생성 그림은 마젠타 배경을 `min(R,B)-G` 로 지우므로(tools/gpu_night/chromakey.py, 30 이상이면 가장자리가 투명해짐) 드레스에 핫핑크·마젠타 계열(`#E85D8A` 같은 보라 기운 분홍)을 쓰면 안 된다. Blush Pink(21)·Rose(31)는 안전. 프롬프트에 "soft blush pink, NOT hot pink, NOT magenta"를 넣는다.
- 배경 꽃 조각의 분홍(Blush Pink)은 아이 자리(x 150~750) 둘레에는 두지 않는다(드레스와 겹침 방지).
- 그림: `uc_kid2_stand`(기준, ref `uc_kid_stand` 로 머리 폭·2.5등신 유지) → 나머지 6자세는 refs 에 `uc_kid2_stand`(옷·얼굴) + 옛 같은 자세 `uc_kid_*`(동작)를 넣고 "머리·몸 크기를 기준 그림과 똑같이"를 쓴다. 컷 4장(`uc_cut2_*`)도 새 옷으로. 키아트는 나중.
- 코드 HT 는 옛 자세와 같은 방법(모자 챙 대신 **머리카락 폭**)으로 다시 잰다. 치마가 넓어 ASP 가 커지므로 손잡기(3장)·바구니 자리 x 오프셋을 다시 본다.

### 14-6. 코드 연출 (계획만, 별도 큐)
1. `BGS` 에 `'uc_bg2_moon_night_lb'`, `'uc_bg2_night_forest_lb'` 추가(preload). `BGPH` 자리표시는 `key.replace('bg2_','bg_')` 가 `_lb` 를 못 지우므로 `.replace(/_lb$/,'')` 한 줄 추가. `FG` 목록에 `'grass_band_sil'`, `'branch_frame_sil'` 추가, `bandR = deco('fg_grass_band_sil')` 하나 더. HT 두 값(360·420).
2. **10장**: `scene('uc_bg2_moon_night_lb', 500, 1)` 로 바꾼다(9장은 그대로). 순서: 배경 → `halo`(T.bg) → `tint`(신데렐라식 rect, T.bg, `#1F2A56` 0.35) → 다현이·유니콘(opacity 0) → `bandL`·`bandR`·`branch`(맨 앞, 세로는 branch 생략). 카드가 열리면 tint 를 2.5초에 0.35→0 으로 걷으면서 `fadeIn(uni)` — '밤이 환해진다'. 포옹 때 `T.world.appendChild(kid.pos)` 뒤에 `bandL`·`bandR` 를 다시 appendChild 해 띠가 맨 앞에 남게 한다. 빛 점 반짝: T.bg 에 크림 원 6~8개(배경 별 구멍 자리, 달 둘레 밖)를 opacity .3↔1, 3초 반복(신데렐라 sparkle 과 같은 방식). 효과음은 기존 그대로.
3. **4~5장**(선택): `forest()` 의 배경 키만 `_lb` 로, `put` 뒤에 `bandL`·`bandR`·`branch` 를 맨 앞에 추가. 가시 톡·세기·컷은 그대로. 반딧불 반짝은 덤불 구멍 자리(x <16 %, >86 %)에 호박 원 4개 opacity 반복.
4. 세로 화면 값은 표의 둘째 값(`X()`)으로, 그림 도착 뒤 가로·세로 사진으로 §14-4·§14-5 검산.

### 14-8. 판단이 필요한 부분
1. **4~5장 라이트박스를 넣을지**: 10장만으로도 요청(1~2장면)은 충족한다. 4장에는 세기 놀이가 있어 배경이 덜 화려한 편이 집중에 낫다는 의견도 가능. 먼저 10장만 생성해 보고 4~5장은 그 결과를 본 뒤 결정해도 된다(작업표 항목은 미리 넣어 둠).
2. **9장도 라이트박스로 할지**: 지금은 9장 어두운 밤 → 10장 밝은 라이트박스 전환(켜짐)을 권장. 9장까지 같은 `_lb` 배경이면 전환은 없어지지만 덤불·숨은 유니콘이 밝은 판 앞에 서서 숨는 느낌이 약해진다.
3. **10장 하늘 색**: 참고 그림(deer)처럼 금빛 하늘 대신 **보라·남색 고리 + 지평선 호박 띠**를 골랐다. 이유: 7색 무리의 빨강·주황·노랑이 금빛 하늘에 묻히지 않게. 금빛을 원하면 고리 색만 Honey/Amber 계열로 바꾸면 된다(작업표 SCENE PAPERS 줄 수정).
4. 실루엣 소품에 뚫린 구멍(빛 점)을 넣지 않았다(마젠타 크로마키 가장자리 위험). 빛 점은 배경 안 구멍 + 코드 반짝으로만.
