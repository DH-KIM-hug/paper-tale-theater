# 은혜 갚은 까치 — 시각 재기획 (화려한 가을 산·밤의 라이트박스·새벽 종탑)

작성 2026-10-23. 사용자 요청: "기존 동화도 화려한 다층 페이퍼아트로 다시 기획하고, 큰 순간 1~3장면은 종이 뒤 광원(라이트박스) 실루엣 장면으로." 까치 동화의 추가 지시: **둥지는 움직이지 않는다(둥지 자리 고정), 새끼 까치는 둥지 장면에서만 보인다, 종탑 장면에는 새끼가 없다.** 이 세 가지는 지금 코드(`magpie.js` 3장·6장·7장·9장)가 이미 그렇게 되어 있고, 이 기획은 그것을 바꾸지 않는다(새끼 소품·새끼 실루엣을 어느 장면에도 더하지 않는다).

이 문서는 **배경·레이어 소품·코드 연출**만 다룬다. 인물 그림(선비·여인·구렁이·까치 엄마·아빠·친구·새끼)과 누르는 소품(활·화살 `mg2_prop_arrow`·종 `mg2_prop_bell`·둥지 앞테 `mg2_prop_nest_rim`)은 바꾸지 않는다. 대사·녹음·조작(톡 3번 + 숫자 알기 1개)은 그대로다. 코드 좌표는 그림이 온 뒤 이 문서의 자리표를 기준으로 맞춘다.

작업표: `tools/app/gen/jobs_magpie.json` 끝에 붙인 21항목(배경 10 + 레이어 소품 8 + 실루엣 소품 3). 기존 15항목과 기존 그림 파일은 그대로 두고, 코드에서 배경 파일 이름만 새 id 로 바꿀 때 옛 배경은 쓰지 않는다(파일 보관).

형식은 `tales/snow_white/VISUAL_PLAN.md` 와 같다. 좌표 환산: 무대 1000×560, 배경 1600×902 는 기본 `BGBOX`(x −40~1040, y −24~585)에 깔리므로 **그림 가로 % = (무대 x + 40) / 1080, 세로 % = (무대 y + 24) / 609**. 둥지(`BG_PLACE` 1.25배, dx 40, dy 47)는 가로 % = (x + 135) / 1350, 세로 % = (y + 53) / 761. 아침 종탑(`BG_PLACE` 1.2배, dx 130, dy −100)은 가로 % = (x + 18) / 1296, 세로 % = (y + 185) / 730.

## 1. 방향과 원칙

### 1-1. 참고 그림에서 가져오는 화려함 (사용자 제공 4장, 스타일 참고만 — 작업표 refs 에 넣지 않는다)
- **lightbox_deer**: 흰 종이 7~8겹을 뒤에서 호박빛으로 비춘 빛 상자. 맨 뒤(달·하늘)가 가장 밝고 앞으로 올수록 한 단계씩 어두워져 맨 앞은 검은 실루엣(가지 틀, 물결 땅, 사람). 둥근 창 안에 장면. → 6장 달밤·7장 종탑의 뼈대.
- **lightbox_whale**: 빛 색이 층마다 다르다(위 파랑 → 가운데 보라 → 아래 호박. 조각 안 그라데이션이 아니라 층별 색지). 양옆 큰 나무가 틀, 빛 점(구멍)이 반짝임. → 종탑의 기둥·지붕이 틀, 숲 층에 뚫린 빛 점.
- **lavish_layers**: 난색 나무·꽃(주황·분홍·노랑)과 한색 물결 띠 5~6겹의 대비, 색지 15색 이상, 빈틈없는 가장자리. → 1·2장 가을 산(단풍 난색 + 호수 한색 띠), 9장 벚꽃 종탑.
- **city_waves**: 노을 하늘을 색지 띠 3~4장으로, 실루엣 두 줄, 앞 물결 5겹. 깊이는 밝기 차이로만. → 4장 밤 산(능선 4단 + 안개 띠), 9장 새벽 하늘 띠 4장.
- 우리 규칙으로: ① 먼 층은 밝고 연하게, 앞 층은 어둡고 진하게(§7-2) ② 능선·안개·호수 띠는 **한 장씩 색이 다른 띠 4~6겹** ③ 나무·단풍·꽃은 양옆·위 모서리에 가득, 가운데 아래(인물 자리)는 민무늬 ④ 라이트박스는 '종이 뒤 광원': 뒤 층 색지 밝기를 단계로 두고 맨 앞은 `#2E241C`/`#1A1410` 실루엣 ⑤ 조각 안 그라데이션·광택·유채색 그림자 금지, 소품 얼굴 없음, 원근법 금지(멀리는 "작게"가 아니라 "연하게").

### 1-2. 어느 장면을 어떻게
- **화려한 낮 장면(다층 v2)**: 1장 산길, 2장 큰 소나무, 3장 둥지(둘레만), 9장 새벽 마당·아침 종탑. 가을 난색(감·단풍·짚)과 호수·먼 산 한색 띠의 대비, 새벽은 분홍·산호·복숭아 하늘 띠와 벚꽃.
- **화려한 밤 장면(다층 v2, 남색)**: 4장 깊은 밤 산길·외딴집 마당. 남색 능선 4단 + 안개 띠, 따뜻한 빛은 집의 창·등잔뿐.
- **라이트박스(종이 뒤 광원) 3장면**: **6장 달밤의 까치**(`mg2_bg_moonnest_lb` — 까치들이 달빛을 가르며 날아오르는 큰 순간), **7장 종탑**(`mg2_bg_belltower_night_lb` — 까치가 머리로 종을 치는 이야기의 절정), **8장 새벽**(`mg2_bg_paperdoor_lb` — 창호문 뒤의 달·새벽빛. 여인이 구렁이로 변해 떠나는 결말 직전). 창호문은 5장도 같은 배경 키(`mg_bg_paperdoor`)를 쓰므로 5장에도 같은 라이트박스 배경이 보이되, 5장은 틴트 .35 로 더 어둡고 8장은 .28 → 0 으로 밝아진다(§7 판단 1). 밤의 후반(5~8장)이 통째로 빛 상자가 되어 낮(1~3·9장)의 밝은 다층과 대비된다.
- **광원**: 낮 장면은 세트 A(왼쪽 위 → 그림자 오른쪽 아래). 밤·라이트박스는 '종이 뒤 광원'이라 층 밝기 단계로 표현하되 프롬프트의 경계 그림자 방향(LIGHTING 블록)은 기존 그대로 둔다. 4장·7장 달은 오른쪽 위(세트 B)로 기존 배경과 같은 자리.
- **색지 제한 해제(2026-10-22)**: 장면군마다 12~18색(§2). 지키는 것 — 1조각 1색, 광택·그라데이션·펄 금지, 그림자는 어두운 웜 그림자(`#2E241C`)만, 소품 얼굴 없음, 원근법 금지.
- **인물·누르는 대상 주변 비우기**(§3~§6 장면마다 % 로 적음). 특히 2장 선비(톡 1)·3장 숫자 카드 띠·7장 종(톡 2)·9장 선비(톡 3) 둘레.
- **세로 화면(P)** 은 가운데 430px 만 보인다. 앞 가림 소품은 모두 x < 285 또는 x > 715 에 두고(이 문서의 자리표 전부 그렇다), 아래 띠(`grass_sil`)만 가로로 길게 둔다. 카메라가 움직이는 4장 `follow(540)`·9장 `follow(560)` 에서는 앞 소품을 두지 않는다.
- **크기 일관성(§4-1)**: 같은 소품은 어느 자리든 같은 높이(§8 높이표). 먼 층의 나무·산은 "작은 것"이 아니라 "연한 색지"로 멀어 보이게 한다. 새끼 까치는 어느 소품에도 넣지 않는다.

## 3. 가을 산 (1장 산길, 2장 큰 소나무)

현재: 두 배경 모두 이미 단풍·언덕·호수가 있어 가장 화려한 편이다. 그러나 능선이 2단, 안개 띠 없음, 양옆이 비어 있고, 앞 가림 층이 없다. 2장은 "큰 소나무"인데 단풍나무로 그려져 있다(§7 판단 3 — 이번에는 그대로 둔다).

바꿈 — 배경 `mg2_bg_path_v2`(pass 2 ← `mg_bg_path`), `mg2_bg_bigtree_v2`(pass 2 ← `mg_bg_bigtree`):
- **유지(refs + "EXACTLY at the same position and size")**: 1장은 앞 길(윗선 세로 68%, 선비 발 87%), 양옆 단풍나무 두 그루, 호수로 가는 오솔길, 지평선. 2장은 오른쪽 큰 나무(줄기 가로 70~88%, 땅까지), 위를 덮는 나무갓, **둥지(가로 67%, 세로 13%)**, 모서리 바위, 땅선(72%, 발 87%).

## 10. 코드 작업 (이 문서 확정 뒤, 별도 큐)

- **배경 파일 이름 바꾸기 — 키는 그대로**: 읽어 주기 대본 `read_script_el.json` 과 `READ_ACTS` 의 `PXM`·`CAMP`·분기(`key === 'mg_bg_paperdoor'` 등)가 기존 키 이름을 그대로 쓰므로, `BGS` 키는 바꾸지 않고 `src()` 앞에 파일 이름 표를 둔다: `const BGFILE = { mg_bg_path: 'mg2_bg_path_v2', mg_bg_bigtree: 'mg2_bg_bigtree_v2', mg_bg_nest: 'mg2_bg_nest_v2', mg_bg_night: 'mg2_bg_night_v2', mg_bg_porch: 'mg2_bg_porch_v2', mg_bg_paperdoor: 'mg2_bg_paperdoor_lb', mg_bg_moonnest: 'mg2_bg_moonnest_lb', mg2_bg_belltower_night: 'mg2_bg_belltower_night_lb', mg_bg_dawn: 'mg2_bg_dawn_v2', mg_bg_belltower: 'mg2_bg_belltower_v2' }` 를 `bgImage()` 와 preload 에서만 쓴다. 그러면 대본·PXM·CAMP·`BG_PLACE`·`bgImage` 의 `/night/` 자리표시 색은 손대지 않아도 된다.
- `ASP` 에 `mg2_layer_*` 11개 추가(후처리 ASP 표에서 측정), `prop()` 으로 소품 생성, 각 `sceneCard` 콜백에 `put`(순서: 중간 소품 → 배우 → 앞 소품). 4장 컷 B·9장 컷 B 처럼 `T.clear()` 로 배경만 바꾸는 곳도 소품을 다시 `put`.
- 새 도우미: `fallingLeaves(T, file, n, h, xRanges)`(낙엽·꽃잎 공용, 장면 끝에 지움), `fireflies(T, n, xRanges)`, `lightDots(T, n, box)`, `lightRing(T, x, y)`, `sway(a, deg, ms)`, `drift(a, px, ms)`, `sparkleRing(T, x, y, r, n, colors)`(신데렐라 `sparkle()` 이식), 촛불 깜빡 `flicker(el)`.
- 틴트 색: 5·6·7·8장 `tint('#1F2A56', …)` 를 `'#1A1410'` 으로. 4장 잠드는 틴트는 그대로(남색 밤).
- `BG_PLACE.mg_bg_belltower` 아래 빈 띠 수정(§7), `BG_PLACE.mg_bg_nest` 는 그대로(둥지 고정). 둥지 v2 가 어긋나면 `BGFILE.mg_bg_nest` 만 빼서 기존 그림을 쓴다.
- 컷 그림 5장(`mg_cut_*`)은 이번에 바꾸지 않는다. 옛 파란 밤 배경과 라이트박스 호박빛이 컷에서 잠깐 어긋나 보일 수 있다(§11 판단 4).
- 테스트: 자동 재생(가로 1366×1024, 세로 390×844, `?n=5`)으로 1~9장 앞뒤 사진. 소품이 인물 얼굴·손·누르는 대상(2장 선비·3장 카드·7장 종·9장 선비)을 가리지 않는지, 같은 소품이 같은 크기인지(§4-1), 세로 화면에서 앞 소품이 가운데로 들어오지 않는지, 3장 둥지와 새끼 자리가 그대로인지(`NX 564`, `RIM_Y 284`), 7장 쓰러진 까치가 Warm Sand 판 위에 있는지, 라이트박스 장면에서 검은 까치가 배경에 묻히지 않는지.

## 11. 판단이 필요한 부분

1. **창호문 라이트박스를 5장에도 쓸지**: 5장과 8장이 같은 배경 키라 한 그림을 둘이 쓴다(5장 틴트 .35 로 더 어둡게, 8장 .28 → 0). 5장만 기존 파란 창호문으로 두려면 `BGS` 에 키를 하나 더 만들고 대본의 8장 `set` 만 새 키로 바꿔야 한다(읽어 주기 대본 수정 포함). 추천: 한 그림을 둘 다 쓴다(밤 → 새벽이 같은 방에서 밝아지는 것이 자연스럽다).
2. **둥지 v2 를 넣을지**: 사용자 지시가 "둥지 고정"이라 pass 2 + "nest does not move and is not redrawn" 로 적었지만 생성이 조금이라도 밀릴 수 있다. 추천: 넣되 받은 그림을 기존과 겹쳐 ±2% 를 넘으면 버리고 기존 `mg_bg_nest` 를 그대로 쓴다(`BGFILE` 에서 한 줄만 뺀다). 두 번 어긋나면 포기.
3. **2장 "큰 소나무"가 단풍나무로 그려진 것**: 컷 `mg_cut_arrow`·`mg_cut_flee` 와 대사(L3 "큰 소나무")가 이미 이 나무로 녹음·제작되어 있어 이번 v2 는 나무 모양을 그대로 둔다(pass 2 유지). 소나무로 바꾸려면 둥지·줄기·컷 3장을 함께 다시 그려야 하므로 별도 결정.
4. **컷 그림과 라이트박스 색 차이**: 6장 `mg_cut_flock`·7장 `mg_cut_ring` 은 파란 밤 컷이고 새 배경은 호박빛이다. 컷은 전체 화면 그림이라 4초 뒤 돌아오면 색이 바뀌어 보인다. 추천: 이번에는 그대로 두고, 눈에 띄면 컷 2장만 라이트박스 색으로 다시 그린다(별도 작업표 항목).
5. **6장 횃대 가지를 배경 안에 그린 것**: 까치가 앉는 가지를 소품이 아니라 배경(Dark Brown 중간 단계)에 그렸다. 생성된 가지 윗선이 세로 61% 에서 ±4% 벗어나면 코드의 `FL - 160` 을 ±25 안에서 맞춘다(가지를 소품으로 빼면 검은 새와 검은 가지가 겹쳐 묻히므로 배경 쪽을 추천).

## 12. 확정 사항

- 인물·누르는 소품(활·화살·종·둥지 앞테)·대사·녹음·조작은 바꾸지 않는다. 새끼 까치는 3장 둥지에만 보이고(코드 그대로), 어느 새 소품에도 넣지 않는다. 둥지 자리·크기는 그대로(pass 2, `BG_PLACE.mg_bg_nest` 유지). 7장 종탑에는 새끼가 없다.
- 라이트박스는 6장 달밤·7장 종탑·8장 새벽(5장이 같은 창호문 배경을 공유) 셋. 나머지는 다층 v2.
- 1조각 1색·무광·웜 그림자·소품 얼굴 없음·원근법 금지·인물 주변 비우기는 그대로. 색지는 장면군별 12~18색.
- 작업표 21장은 `jobs_magpie.json` 끝에 붙였고 기존 15항목은 바꾸지 않았다. 생성·git 은 이번에 하지 않는다.
