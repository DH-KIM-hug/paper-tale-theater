# 인어공주 — 시각 재기획 (아주 화려한 바다 밑 궁전·불꽃놀이·궁전 정원·결혼 배)

작성 2026-10-22. 사용자 요청: "공주 동화들도 화려함이 필요한 부분들 아주 화려하게 재기획."

이 문서는 **배경·레이어 소품·연출**만 다룬다. 인물(인어공주·언니들·왕·할머니·왕자·마녀·아가씨)과 물고기 배역 그림, 대사, 녹음, 조작은 바꾸지 않는다. 줄거리·장면 수(11장)도 그대로다. 코드 좌표는 그림이 온 뒤 SPEC §6 에 맞춰 고친다.

인어공주 배경은 이미 한 번 `mer_bg2_*`(겹을 더한 판)·`mer_bg3_*`(비례 고침)로 바꿨다. 이번은 **그 위에 더하는 방식**이다: 새 배경 `mer_bg5_*` 는 지금 쓰는 그림(`mer_bg2_*` 또는 `mer_bg3_*`)을 참고 그림으로 넣어 **같은 구도·같은 지평선·같은 빈 자리**를 지키고, 겹과 색만 더 쌓는다. 기존 파일은 그대로 둔다.

작업표: `tools/app/gen/jobs_little_mermaid.json` 끝에 추가한 19항목(`mer_bg5_*` 배경 5 + `mer_layer_*` 소품 14). 코드·그림 생성은 이 문서를 확정한 뒤 한다.

## 1. 지키는 것 (CLAUDE.md §7-4 2026-10-22 색 제한 해제 아래서도)

- **1조각 1색.** 조각 안 그라데이션·명암 칠·광택·펄 금지(진주도 무광 크림 종이 한 장이다).
- **그림자는 어두운 웜 그림자만**(`#2E241C` 계열). 유채색 그림자 금지. 물속이라고 파란 그림자를 넣지 않는다.
- **소품에 얼굴 없음.** 물고기 떼·해파리·산호·말미잘·조개·불꽃·해·달에 눈·입을 넣지 않는다(물고기 배역 `fish_a/b/c` 는 기존 얼굴 규칙 그대로).
- **원근법 금지.** 깊이는 종이 겹과 얇은 경계 그림자로만. 먼 층 궁전·물고기 떼는 "멀어서 작다"가 아니라 "한 층 통째로 밝고 연하게, 같은 비율로" 줄인다(§4-1).
- **인물·누르는 대상 주변 비우기.** 각 장면 표의 '비우는 자리'를 배경 그림에서도, 코드로 얹는 소품에서도 지킨다. 앞 가림 소품은 화면 아래 모서리(x < 120 또는 x > 900)에만 둔다.
- **광원 한 방향.** 세트 A(낮·바다 밑·정원)는 왼쪽 위, 세트 B(밤바다·배 갑판)는 오른쪽 위. 한 장면 안에서 바꾸지 않는다.
- 하늘 톡(2장)·가마솥 톡(6장)·고르기(1·8장) 대상은 소품에 가리지 않는다.
