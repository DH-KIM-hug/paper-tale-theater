# 토끼와 거북이 — 시각 재기획 (개울 배경 수정 최우선 + 화려한 다층 + 라이트박스)

작성 2026-10-23. 사용자 지시: "헤엄치는 곳 배경 고쳐야 할 듯" + CLAUDE.md §7-5-1(기존 동화도 화려한 다층 페이퍼아트, 라이트박스 장면 허용).

이 문서는 **배경·층 소품·라이트박스 배경**만 다룬다. 토끼·거북이·관객 동물·물고기·소품 그림은 바꾸지 않는다. **js 는 건드리지 않는다**(다른 에이전트가 응원 동물 빼기·자장가 작업 중). 코드 좌표는 그림이 온 뒤 별도 큐.

작업표: `tools/app/gen/jobs_rabbit.json` 끝 18항목(배경 `rab_bg_*_v2` 9 + 라이트박스 `rab_lb_*` 3 + 층 소품 `rab_layer_*` 6). 생성 ID는 `tools/app/gen/restyle/lavish_g1_ids.txt`. 출력 `assets/raw/restyle/rabbit/` → `post_tale.py rabbit`.

참고 그림 분석은 `tales/patjuk/VISUAL_PLAN.md` §0 과 같다(뒤 층이 가장 밝은 라이트박스, 6~8겹, 보색 대비, 층층 물결).

무대 ↔ 그림: 그림 1600×902 는 무대 x −40~1040, y −22~583(`BGX`). 그림 가로 % = (무대 x + 40) / 1080, 세로 % = (무대 y + 22) / 605.

## 1. 개울 헤엄 장면 — 무엇이 잘못됐나 (최우선)

현재 `rab_bg_stream`(10장 '개울'): 그림 아래 25% 만 물(그림 세로 75~100% = 무대 y ≈ 432~583), 그 위 세로 55~75% 는 **노란 모래톱**, 양 아래 모서리는 갈색 흙이 물을 가린다. 물은 화면 가로로 흐르는 띠다.

코드(rabbit.js 1317~1351): 거북이는 `put(turtle, 200, 492, 1.35)` — 헤엄 그림 190×112 를 1.35배 → 약 256×151, 발끝 y 492 기준이라 몸은 **y 341~492** 에 있다. 물 윗선이 y ≈ 432 이므로 거북이 몸의 위 90px 가 모래톱 위에 떠 있다(물에 반쯤 잠긴 게 아니라 **모래 위에서 헤엄치는 것처럼** 보인다). 물고기 세 마리(y 470·500·520)만 물 안. 또 "개울을 건넜어요"인데 물이 가로 띠라 거북이는 개울을 **따라** 가는 것처럼 읽힌다. 앞 흙 모서리는 거북이 뒤(배경)라 물에 들어간 느낌을 주지 못한다.

고침(배경만, js 그대로): `rab_bg_stream_v2`
- 물이 **그림 세로 52% 아래 전부**(무대 y ≈ 293~583)를 채운다. 수면선 y ≈ 293 이라 거북이(341~492)·물고기(470~520)·헤엄 bob(−16)이 전부 물 안. 뒤 둑은 수면선 위 얇은 모래 띠(47~52%)+갈대+숲 층.
- 좌우 가장자리(가로 0~8%, 92~100%)에 풀 둑을 두어 **왼쪽 둑에서 오른쪽 둑으로 건너는** 그림이 된다(거북이 x 200→755 = 가로 22%→74%, 둑 사이).
- 물은 city_waves 처럼 **물결 띠 5겹**(Powder Blue → Baby Blue → Sky Blue → Lagoon → Sea Teal, 앞으로 올수록 진하게) + 크림 물마루 띠. 앞 모서리 흙·바위 없음.
- 앞 가림: `rab_layer_water_front`(진한 물결 띠, 폭 ≈1000, 높이 60)를 모든 배우 **앞** y 590 에 깔고 좌우 ±15 로 아주 느리게 흔들면 거북이 발이 물에 잠긴다. `rab_layer_reeds_front` 를 x 30·y 590(왼쪽 둑 앞)에.
- 세로 화면은 `camSnap(270,280,1)` 로 왼쪽을 보므로 왼쪽 둑·갈대가 들어온다. 물 가운데(가로 10~90%, 세로 55~100%)는 비운다.

## 3. 라이트박스 장면 (3장)

1. **토끼의 꿈·시상식** `rab_lb_dream` — 꿈이라 라이트박스가 가장 어울린다. 하늘 Amber Glow 뒤 빛, 보름달·별은 구멍. 시상대는 원래 색(초록·크림·주황)으로 '빛을 받는 물건'. 당근 트로피 자리 비움.
2. **꼬끼오! 새벽** `rab_lb_dawn` — 해 구멍이 가장 밝고 언덕 5겹이 물결처럼 어두워진다. 울타리·덤불은 Night Navy 실루엣, 앞 풀밭은 Wheat 라 토끼·수탉이 묻히지 않는다. '쉿 살금살금'도 같은 그림.
3. **숲속 잔치** `rab_lb_party` — 초롱 전부가 구멍이라 lightbox_deer 의 '기둥 집 창' 느낌. 무대는 원래 색. 관객 자리 마당은 Wheat.

## 5. 코드 작업 (별도 큐 — 지금 js 수정 금지)

- `ART` 의 bg 키를 `_v2`/`_lb` 로 바꾸고 `EDGE` 색(위·아래 띠)을 새 그림 끝 색으로 다시 잰다. `DRAW` 에 소품 `put`.
- 개울: 그림만 바꾸고 `R10`(x0 200, y 492)은 그대로. 물결 띠 앞 소품 + ±15 흔들림. 고치고 난 뒤 자동 재생 사진으로 거북이가 물 안인지 확인.
- 꿈·시상식 라이트박스는 `num()` 숫자 색(C.gold)이 Amber Glow 하늘과 겹치지 않는지 확인 — 숫자는 시상대 위라 괜찮을 것.

## 6. 판단이 필요한 부분

1. **경주 지도(map)는 안 바꿈**: 코드 `PATH` 점선 좌표가 그림 속 길에 맞춰져 있어 새 그림이 길을 1% 만 옮겨도 깃발·돌·개울·언덕 순서가 틀어진다. 추천: 그대로 둔다.
2. **골목 v2 의 문 4개**: 누르는 대상이라 위치가 1% 만 밀려도 반짝임이 문 밖에 생긴다. 추천: 겹쳐 보고 ±2% 넘으면 기존 그림 유지.
3. **쉿 살금살금까지 새벽 라이트박스**: 토끼가 결승 앞에서 멈춰 자는 장면이 저녁(dusk)인데 새벽 그림과 같은 노을 색이라 같은 그림으로 쓴다. 다르게 보이길 원하면 `rab_bg_dusk` 기존 그림을 그 장면에만 남긴다.

## 7. 확정 사항

- 개울 수정은 배경·앞 물결 띠로만 하고 코드 좌표(x0 200, y 492, 1.35배)는 유지한다.
- 인물·동물·소품 그림, 대사·녹음·조작은 바꾸지 않는다. 지도 배경은 그대로.
- 작업표 18항목은 `jobs_rabbit.json` 끝에 붙였고 기존 5항목(키아트)은 그대로.
