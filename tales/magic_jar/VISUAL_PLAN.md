# 요술 항아리 — 시각 재기획 (가을 농가·봄 마을·단청 부잣집 + 라이트박스 2장면)

작성 2026-10-23. 사용자 요청(2026-10-23 공통 브리프): "기존 동화도 새 동화처럼 다채롭고 화려한 다층 페이퍼아트로 다시 기획하고, 큰 순간 1~3장면은 종이 뒤 광원(라이트박스) 실루엣 장면으로."

이 문서는 **배경·레이어 소품·코드 연출**만 다룬다. 인물 그림(농부·농부 아내·부자·아버지·여덟 아버지)과 누르는 소품(항아리·깨진 항아리·괭이·엽전·금덩이·쌀자루·상)은 바꾸지 않는다. 대사·녹음·조작(농부 톡, 항아리 톡톡 세기 3번, 집 고르기, 부자 톡)은 그대로다. 코드 좌표는 그림이 온 뒤 이 문서의 자리표를 기준으로 맞춘다.

작업표: `tools/app/gen/jobs_magic_jar.json` 끝에 붙인 20항목(배경 8 = `mj_bg_*_v2` 6 + 라이트박스 `mj_bg_*_lb` 2, 레이어 소품 `mj_layer_*` 8, 실루엣 소품 `mj_layer_*_sil` 4). 기존 7항목과 기존 그림 파일은 그대로 두고, 코드 `BGS` 를 `_v2`/`_lb` 로 바꿀 때 옛 배경은 쓰지 않는다(파일 보관).

형식은 `tales/snow_white/VISUAL_PLAN.md` 와 같다.

## 1. 방향과 원칙

- **참고 그림에서 가져온 화려함의 요소**(사용자가 준 네 장, 스타일 참고만):
  - 빛 상자 사슴(lightbox_deer): 흰 종이 7~8겹을 뒤에서 호박빛으로 비춘다. 가장 뒤(달·하늘)가 가장 밝고 앞으로 올수록 한 단계씩 어두워져 맨 앞은 검은 실루엣(가지 틀·물결 땅·사람). 둥근 창 안에 장면.
  - 빛 상자 고래(lightbox_whale): 빛 색이 위(파랑)→가운데(보라)→아래(호박)로 **층마다** 바뀐다(한 조각 안 그라데이션이 아니라 층별 색지가 다름). 양옆 나무 줄기가 틀, 구멍 뚫린 종이가 반짝이는 빛 점.
  - 화려한 층(lavish_layers): 난색 나무·꽃(주황·분홍·노랑)과 한색 물결 띠 5~6겹의 대비, 아래쪽은 꽃 덤불로 빈틈없이 가득, 색지 15색 이상.
  - 도시 물결(city_waves): 노을 하늘은 색지 띠 3~4장, 건물 실루엣 두 줄, 앞은 파랑 물결 5겹. 실루엣 층은 단색, 깊이는 밝기 차이로만.
  - 우리 규칙으로 옮기면: ① 먼 층은 밝고 연하게, 앞 층은 어둡고 진하게(§7-2) ② 산·밭고랑·안개 띠는 **한 장씩 색이 다른 띠 4~6겹** ③ 나무·꽃 덤불은 양옆·위 모서리에 가득, 가운데 아래(인물 자리)는 민무늬 ④ 라이트박스는 '종이 뒤 광원': 뒤 층 색지 밝기를 단계로 두고 맨 앞은 `#2E241C`/`#1A1410` 실루엣 ⑤ 조각 안 그라데이션·광택·유채색 그림자는 여전히 금지, 소품 얼굴 없음(참새만 점 눈), 원근법 금지(멀리는 "작게"가 아니라 "연하게").
- **화려하게 하는 장면군 넷**: ① 가을 농가(1장 밭, 3·4장 마당) — 감·단풍·은행·벼논·코스모스의 가을 수확 색, ② 봄 이웃 마을(5장) — 벚꽃·개나리·배꽃의 봄 색(나눔의 장면이라 밝고 들뜨게), ③ 단청 부잣집(6장 대문, 7장 큰 방, 8·9장 넓은 방) — 단청 적·청·녹·금, 일월오봉도 병풍, 모란, ④ 라이트박스 두 장면(2장 땅속, 10장 잔치). 집·대문·방의 **구조(문·마루·병풍·기둥·땅선)는 기존 그림 자리 그대로**(pass 2 + refs).
- **라이트박스로 하는 장면과 이유**(§7 상세):
  - **2장 땅속(`mj_bg_pit_lb`)** — 이야기의 첫 기적. 땅속에서 요술 항아리가 빛을 내며 나오는 순간이라 '땅속 구멍 안의 빛'이 그대로 빛 상자다. 이 장면은 누르기 없이 저절로 진행되므로 어두운 실루엣 틀을 둬도 조작을 가리지 않는다.
  - **10장 잔치(`mj_bg_feast_lb`)** — 결말. 노을과 등불 아래 모두가 나누는 잔치. 기존 배경이 이미 노을이라 자연스럽게 '저녁 빛 상자'가 된다. 톡 없음(만세는 저절로).
  - 3·4장(괭이·엽전 세기)과 8장(아버지 여덟 세기)은 **세기 놀이**라 배경이 조용해야 하므로 라이트박스로 하지 않는다. 7장 큰 방(금덩이)은 8·9장과 같은 방이라 7장만 밤으로 바꾸면 이어지지 않아 제외했다(§10 판단 2).
- CLAUDE.md §7 "평평한 종이 한 장 + 요소 2~3개"를 모든 장면에서 풀고 **다층 페이퍼아트**로 간다: 먼 층(배경 그림 안쪽, 밝고 채도 낮게) → 중간 층(배경 그림 앞쪽 + 인물 뒤에 `put` 하는 소품) → 앞 가림 층(모든 배우 뒤에 `put` 해 맨 앞, 화면 모서리). 층이 깊을수록 밝고 연하게, 앞일수록 어둡고 진하게.
- **색지 제한 해제(2026-10-22)**: 장면마다 10~20색(§2). 지키는 것 — **1조각 1색**, 광택·그라데이션·펄 금지, 그림자는 **어두운 웜 그림자**(`#2E241C`)만, 유채색 그림자 금지, 소품 얼굴 없음(참새 소품만 점 눈), 원근법 금지.

## 10. 코드 작업 (이 문서 확정 뒤, 별도 큐)

- `magic_jar.js`: `BGS` 를 `['field_v2','pit_lb','jarfront_v2','village_v2','richgate_v2','hall_v2','hallwide_v2','feast_lb']` 로 바꾸고 `scene()` 호출 키를 맞춘다(`bgSrc` 규칙 `mj_bg_<키>` 그대로). `ASP` 에 `layer_*` 12개 추가(후처리 ASP 표에서 측정; `NF` 에 넣어 `nf` 접미가 붙지 않게 하거나 `prop()` 경로를 layer 용으로 하나 더 둔다). `RS` 는 소품에는 두지 않는다.
- 레이어 소품은 `put(T, a, x, y, { raw: true })` 로 두어 세로 화면에서 `fx` 압축을 받지 않게 하고 `pointerEvents = 'none'`. 순서: 중간 소품 → 배우·누르는 소품 → 앞 소품(`T.world.appendChild`). 뒤집기는 `a.turn('right')`.
- 각 장면 `sceneCard` 콜백·`scene()` 뒤에 소품 `put` 을 묶은 도우미: `field()`, `pit()`, `yard()`(3·4장), `village()`, `gate()`, `hall()`(7), `hallWide()`(8·9), `feast()`. 컷신 뒤 `scene('jarfront')`·`scene('hall')`·`scene('hallwide')` 를 다시 부르는 곳은 모두 도우미로 바꾼다.
- 새 도우미: `sway(a, deg, ms)`(rotate 반복), `sparkleRing(T, x, y, r, n, colors)`(신데렐라 `sparkle()` 이식), `glowDots(T, spots, color, r, ms)`(등불·뚜껑 빛 점 깜빡), `petals(T, n)`(백설 꽃잎 이식), 참새 `flyUp(a, dy, ms)`.
- 라이트박스 두 장면: 진입 `tint`(§6·§7), 빛 점, 항아리 솟을 때 카메라 밀기(가로만). 읽어 주기(`READ_ACTS.set`)도 같은 도우미를 쓰게 `set: k => scenes[k]()` 로 바꾼다(읽어 주기 대본 `read_script_el.json` 의 `set` 키 값은 그대로 두고 매핑만).
- 컷신 8장(`mj_cut_*`)은 옛 배경 묘사라 바꾸지 않는다(컷은 별도 그림). `mj2_cut_plop`·`mj2_cut_smash` 프롬프트의 "hall floor" 묘사는 새 방과 어긋나지 않는다.
- 테스트: 자동 재생으로 10장면 앞뒤 사진. 소품이 인물 얼굴·손·누르는 대상(농부·항아리·집 톡 원·부자)을 가리지 않는지, 같은 소품이 같은 크기인지(§4-1: 감나무 가지 1·3·4장, 등불 7·8·9장, 참새 1·3·5장), 세로 화면에서 앞 소품이 가운데로 들어오지 않는지, 라이트박스에서 농부(2장)·네 사람(10장)의 얼굴이 묻히지 않는지.

## 11. 판단이 필요한 부분

1. **땅속 라이트박스에서 농부의 자리**: 농부는 구덩이 오른쪽 Clay 판 위에 서고, 빛나는 구멍은 왼쪽(가로 24~54%)에 둔다. 항아리(가로 43~57%)의 오른쪽 가장자리가 구멍 밖으로 조금 나간다. 구멍을 가운데(가로 32~62%)로 옮기면 세로 화면 농부 머리(가로 52~59%, 세로 61~70%)가 가장 밝은 판에 겹쳐 얼굴이 날아갈 수 있다. 추천: 지금대로(왼쪽 구멍). 받은 그림에서 세로 화면 농부 머리 뒤가 Glow Yellow 면 코드에서 세로 화면 농부 x 를 700 → 740 으로 조금 더 오른쪽에 둔다(`put` 좌표만).
2. **7장 큰 방을 셋째 라이트박스로 할지**: "금덩이가 와르르" 도 큰 순간이다. 하지만 7장·8장·9장은 같은 방이라 7장만 밤(빛 상자)으로 바꾸면 8장(낮)과 이어지지 않고, 8장은 세기 놀이라 조용해야 한다. 7·8·9 모두 라이트박스로 하면 세기 놀이 배경이 어두워진다. 추천: 라이트박스는 2장·10장 둘만, 7장은 금 더미 반짝(코드)으로 대신.
3. **큰 방·넓은 방의 등불을 배경에서 빼고 소품으로 매다는 것**: 흔들림을 주려고 뺐다. 생성에서 등불이 그대로 그려져 오면(pass 2 가 참고 그림을 따라) 소품 등불을 두지 않고 배경 등불을 그대로 쓴다(소품 1장 낭비). 추천: 그대로 진행.
4. **참새**: 동물 소품이라 점 눈 얼굴을 가진다(백설 새·토끼와 같은 규칙). 1·3·5장에 두어 가을·봄 농가의 생기를 준다. 빼면 소품 1장과 §3·§4 의 참새 연출이 빠진다. 추천: 넣는다.
