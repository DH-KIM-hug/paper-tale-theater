# 빨간 모자 — 시각 재기획 (화려한 다층 페이퍼아트 + 라이트박스 2장면)

작성 2026-10-23. 사용자 요청: "기존 동화도 새 동화와 같은 수준의 다채롭고 화려한 다층 페이퍼아트로 다시 그린다. 큰 순간 1~3장면은 종이 뒤 광원(라이트박스) 실루엣 장면으로."

이 문서는 **배경·레이어 소품·코드 연출**만 다룬다. 인물 그림(빨간 모자·엄마·할머니·늑대·사냥꾼)과 누르는 소품(바구니·빵·우유·사과·꽃·꽃병·옷장·창문·액자)은 바꾸지 않는다. 대사·녹음·조작(담기 3·새끼손가락·꽃 고르기 6·노크·다른 곳 찾기 3·옷장·창문·간지럼·나눠 주기)은 그대로다. 코드 좌표는 그림이 온 뒤 이 문서의 자리표를 기준으로 맞춘다.

작업표: `tools/app/gen/jobs_red_hood.json` 끝에 붙인 19항목(배경 `rh_bg_*_v2` 8 + 라이트박스 배경 `rh_bg_*_lb` 2 + 레이어 소품 `rh_layer_*` 7 + 실루엣 소품 `rh_layer_*_sil` 2). 기존 키아트 5항목과 기존 그림 파일은 그대로 두고, 코드 `BGS` 를 `_v2`/`_lb` 로 바꿀 때 옛 배경은 쓰지 않는다(파일 보관).

형식은 `tales/snow_white/VISUAL_PLAN.md` 와 같다.

## 1. 방향과 원칙

### 1-1. 참고 그림에서 가져온 화려함의 요소 (부모 정리 요약)
- **lightbox_deer**: 흰 종이 7~8겹을 뒤에서 호박빛으로 비춘 빛 상자. 가장 뒤(달·하늘)가 가장 밝고 앞으로 올수록 한 단계씩 어두워져 맨 앞은 검은 실루엣(가지 틀, 물결 땅, 사람). 가지가 둘러싼 둥근 창 안에 장면.
- **lightbox_whale**: 빛 색이 위(파랑)→가운데(보라)→아래(호박)로 **층마다** 바뀐다(층별 색지가 다른 것이지 한 조각 안 그라데이션이 아님). 양옆 큰 줄기·가지가 틀, 구멍 뚫린 종이의 빛 점이 반짝임.
- **lavish_layers**: 난색 나무·꽃(주황·분홍·노랑)과 한색 물결 띠 5~6겹의 대비, 아래쪽 꽃 덤불이 빈틈없이 가득, 색지 15색 이상.
- **city_waves**: 노을 하늘을 색지 띠 3~4장으로, 실루엣 층은 단색, 깊이는 밝기 차이로만.
- 우리 규칙으로: ① 먼 층은 밝고 연하게, 앞 층은 어둡고 진하게 ② 언덕·안개·하늘 띠는 한 장씩 색이 다른 띠 4~6겹 ③ 나무·꽃 덤불은 양옆·위 모서리에 가득, 가운데 아래(인물 자리)는 민무늬 ④ 라이트박스는 종이 뒤 광원: 뒤 층 밝기를 단계로, 맨 앞은 `#2E241C`/`#1A1410` 실루엣 ⑤ 조각 안 그라데이션·광택·유채색 그림자 금지, 소품 얼굴 없음(새·나비는 작은 동물 소품이라 점 눈 허용), 원근법 금지(멀리는 "작게"가 아니라 "연하게").

### 1-2. 이 동화에서 화려하게 하는 장면
- **전 장면 10배경을 다시 그린다.** 장면군은 넷: ⓐ 엄마 집 부엌(1장) ⓑ 집 앞·할머니 오두막 바깥(2·6·7장) ⓒ 숲길·꽃밭(3·5·6장 위 칸) ⓓ 할머니 집 안(6장 끝·8·9·10·11장). 여기에 ⓔ 라이트박스 2장면(4장 깊은 숲, 6장 아래 칸 지름길).
- **라이트박스로 하는 큰 순간 둘**(§3 참조): **4장 '늑대'**(`rh_bg_tree_lb`, 늑대가 처음 나타나는 깊은 숲 — 해가 나무 뒤로 숨은 황금빛 숲)와 **6장 '늑대가 먼저' 아래 칸**(`rh_bg_shortcut_lb`, 늑대가 지름길로 달리는 해질녘). 꽃밭(5장)은 라이트박스 후보였지만 색 고르기 학습(꽃·꽃병 6번)이 있어 **밝은 낮 + 빛줄기 띠**로 둔다(라이트박스는 어두워서 꽃 색 비교를 방해한다).
- 무섭지 않게: 라이트박스의 실루엣은 검정이 아니라 **웜 다크**(`#2E241C`)이고, 뒤 층은 노랑·호박·주황의 따뜻한 빛이다. 늑대·빨간 모자는 기존 컬러 그림 그대로 **중간 밝기 민무늬 판(Straw Gold)** 앞에 선다. 입장 때 `tint` 로 아주 살짝 어둡게(0.10) 했다가 빛나는 배경이 드러난다. 소리는 기존 그대로(새 효과음 없음).
- CLAUDE.md §7 "평평한 종이 한 장 + 요소 2~3개"는 이 동화 전체에서 풀고 **다층 페이퍼아트**로 간다: 먼 층(배경 그림 안쪽, 밝고 연하게) → 중간 층(배경 그림 앞쪽 + 인물 뒤에 `put` 하는 소품) → 앞 가림 층(모든 배우 뒤에 `put` 해 맨 앞, 화면 아래·위 모서리). 층이 깊을수록 밝고 연하게, 앞일수록 어둡고 진하게(§7-2).
- **색지 제한 해제(2026-10-22)**: 장면군마다 12~20색(§2). 지키는 것 — 1조각 1색, 광택·그라데이션·펄 금지, 그림자는 어두운 웜 그림자(`#2E241C`)만, 유채색 그림자 금지, 소품 얼굴 없음(새·나비만 점 눈), 원근법 금지(깊이는 겹침과 얇은 경계 그림자로만).
- **광원**: 낮 장면은 모두 세트 A(왼쪽 위 → 그림자 오른쪽 아래). 라이트박스 2장면은 '종이 뒤 광원'이라 층 밝기 단계로 표현하되, 경계 그림자 방향은 프롬프트 LIGHTING 블록 그대로(오른쪽 아래) 둔다. 빛줄기는 그림 안의 **연한 색지 띠**(단색, 반투명·그라데이션 없음).
- **인물·누르는 대상 주변 비우기**: 무대 1000×560 에 배경 1600×902 가 무대 x −40~1040, y −24~585 에 깔린다(`BGBOX`). 그림 가로 % = (무대 x + 40) / 1080, 세로 % = (무대 y + 24) / 609. 장면마다 비우는 영역을 §4~§8 에 적었다. 세로 화면(P)은 가운데 430px 만 보이므로(장면별 cx: 1장 500, 4장 560, 8장 470, 9·10장 330, 11장 540, 나머지 500) 앞 가림 소품은 그 밖(x < cx−215 또는 x > cx+215)에 두거나 세로에서는 두지 않는다.
- **유지하는 자리**(pass 2, refs 에 기존 배경): 1장 식탁·의자·마루선, 2장 집·열린 문·창·계단, 6·7장 오두막 전체(문·창·굴뚝·계단), 8장 침대·협탁·등잔·빈 액자·굽도리선, 9·10장 옷장·창·커튼·침대·깔개, 11장 식탁·의자·창·마루선. 열린 장면(3·4·5·6 아래 칸)은 pass 1 로 땅선 높이만 프롬프트에 적는다.
- 크기 일관성(§4-1): 같은 소품은 어느 자리든 같은 높이(§10 높이표). 새·나비는 빨간 모자 키(230) 기준 비율: 파랑새 34(1/6.8), 나비 26(1/8.8).

## 3. 라이트박스 장면 (4장 '늑대', 6장 '늑대가 먼저' 아래 칸)

**왜 이 둘인가**: 4장은 늑대가 처음 나타나 이야기가 바뀌는 순간(숲이 깊어지고 해가 나무 뒤로 숨는다), 6장 아래 칸은 늑대가 지름길로 먼저 달려가 해가 지는 순간(시간이 흐른다는 뜻)이다. 둘 다 '큰 사건 직전'이고 어둑한 숲이 이야기와 맞는다. 결말(10·11장)은 집 안이고 밝아야 하므로 라이트박스로 하지 않는다.

### 3-1. 4장 깊은 숲 `rh_bg_tree_lb` (pass 1)
현재: 낮 숲, 오른쪽 큰 참나무(구멍), 호수·산, 풀밭. 늑대 그림(`wolf_peek`)은 자기 나무 줄기를 갖고 있어 배경 나무와 따로 논다.

## 11. 코드 작업 (이 문서 확정 뒤, 별도 큐)

- `red_hood.js`: `BGS` 를 `['bed_v2','cottage_v2','door_v2','flowers_v2','kitchen_v2','room_v2','shortcut_lb','table_v2','trail_v2','tree_lb']` 로, `scene()`·`panel()`·`bgImage()` 호출의 키 10곳(`READ_ACTS.BGKEY` 포함)을 함께 바꾼다. `ASP`·`RS` 에 `layer_*` 9개 추가(후처리 ASP 표에서 측정), `prop()` 으로 소품 생성, `NF` 에 소품 이름을 넣지 않는다(파일 이름에 nf 없음).
- 장면 콜백에 소품 `put`(순서: 중간 소품 → 배우 → 앞 소품). 세로 화면(`P`)에서는 §4~§7 "P: 밖" 소품은 그대로 두고(화면 밖), 4장 줄기 틀만 `hide`.
- 새 도우미: `glowDots(T, n, area)`, `flutter(a)`, `sway(a, deg, ms)`, 진입 tint 페이드(`tint` 는 백설 `snow_white.js` 의 것을 이식).
- 7장 오두막 소품은 `s: .45`. 6장 아래 칸 풀 띠는 `panel` 뒤·늑대 뒤에 `put`.
- 테스트: 자동 재생으로 11장면 앞뒤 사진. 소품이 인물 얼굴·손·누르는 대상(빵·우유·사과·꽃병·옷장·창·빨간 모자·늑대)을 가리지 않는지, 같은 소품이 같은 크기인지(§4-1), 세로 화면에서 앞 소품이 가운데로 들어오지 않는지, 라이트박스에서 늑대·빨간 모자 얼굴이 날아가거나 묻히지 않는지. 컷신 7장(`rh_cut_*`)은 옛 배경 묘사로 만들어진 기존 그림이라 그대로 둔다(판단 3).
- 키아트 5항목(`key5_*`)은 손대지 않는다.

## 12. 판단이 필요한 부분

1. **라이트박스 2장면의 어둑함**: 4장(늑대 등장)·6장 아래 칸(지름길)을 황금빛·노을빛 라이트박스로 했다. 실루엣은 웜 다크, 뒤는 노랑·호박이라 무섭지 않게 했지만, 3~4세에게 "숲이 어둑해졌다"는 느낌 자체가 부담이면 4장만 라이트박스로 하고 6장 아래 칸은 낮 `rh_bg_shortcut_v2` 로 바꿀 수 있다(작업표 항목은 `_lb` 한 장이라 그때 프롬프트 1개만 고친다). 추천: 둘 다 라이트박스.
2. **분할 화면의 위(낮)·아래(해질녘) 대비**: 같은 시각인데 위 칸은 밝고 아래 칸은 어둑하다. "지름길은 나무가 빽빽해 어둑어둑"으로 읽히며, 내레이션("위에서는… 아래에서는…")과도 맞는다. 추천: 그대로.
3. **컷신 7장**(`rh_cut_tail/whisper/dash/gulp/granwolf/jumpup/hiccup`)은 옛 배경 분위기(낮 숲)로 이미 생성돼 있다. 4장 앞뒤 컷(`tail`·`whisper`)이 황금빛 라이트박스 장면과 톤이 다르다. 컷은 '그림 카드'라 톤 차이가 허용되지만, 맞추려면 두 컷을 황금빛 숲으로 다시 생성해야 한다(이 문서 범위 밖, 기존 항목 수정). 추천: 지금은 그대로 두고 받은 뒤 사진으로 본다.
4. **8장 빈 액자**: 기존 배경의 빈 액자(가로 73~87%, 세로 4~29%)와 코드의 할머니 사진 소품(가로 70~86%, 세로 17~50%)은 자리가 어긋나 있다(기존 상태). v2 에서는 pass 2 라 빈 액자를 그대로 두지만, 사진 소품 y 를 278 → 150 으로 올려 액자 안에 넣는 코드 수정을 추천한다(다른 곳 찾기 안내 "벽에 걸린 진짜 할머니 사진"과 맞음). 세로 화면(cx 470 → 255~685)에서는 액자(718~892)가 어차피 안 보인다 — 이것도 기존 상태.
5. **파랑새·나비**: 작은 동물 소품으로 점 눈 얼굴을 가진다(백설 판단 2 와 같은 처리). 빼면 소품 2장이 줄고 2·3·5·7장의 hop·flutter 연출이 빠진다. 추천: 넣는다.
