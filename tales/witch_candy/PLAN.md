# 사탕 마녀의 핼러윈 — 기획 (창작 동화, 핼러윈, 2026-10-28)

폴더 `tales/witch_candy`, 그림 접두어 `wc_`(기존 접두어와 겹치지 않음을 확인). 이 문서는 기획서만이다. 코드·그림·녹음은 사용자 확정 뒤에 한다.

> **제목 확정: 「사탕 마녀의 핼러윈」(사용자 결정 2026-10-28).** 처음 정한 「마녀 사탕 가게」는 코코비(키글) 동요 「마녀의 사탕 가게」와 거의 같아 바꿨다. 동요의 가사·구조는 따라 하지 않는다(재료 일부 차용만). 출시 전 KIPRIS·앱스토어 동명 확인. 겹치지 않게 피한 요소는 §0-1.

## 0. 사용자 확정 사항 (2026-10-28, 같은 날 여러 번 고쳐진 최종)
- 3~4세 대상 창작 동화. 핼러윈, 마녀가 운영하는 사탕가게. 교훈 한 줄은 두지 않는다(재미·분위기 우선).
- **갈래(분기) 없음.** 이야기는 한 줄로 가고(8~11장, 7~10분), **사탕 결과만 매번 달라진다.** 결말은 하나(검정 유령 사탕 행진 → 모두 변신 → 인사).
- **장 구성(2026-10-28 최종 지시)**: 1장 마녀가 초대장을 보내 아이들(다현이 + 토끼·곰·여우)이 사탕 가게에 모인다(마을 사탕 떨어짐·문 두드리기 삭제) → 2장 마녀가 솥을 끓인다(불 지피기, 뽀글뽀글) → 3장 재료 선반 소개, 마녀 "같이 만들까?" 다현이 "내가 할래요!" → 4·5·6장 자유 넣기·색 맞히기·변신 → (나눠 주기 장면 삭제, 친구들은 처음부터 가게 안에서 함께 본다) → 7장 모든 색 → 유령 사탕 → 8장 "오~우~" 행진 → 9장 마녀가 남은 사탕을 다 꺼내 **모두 먹고 각자 다른 변신(8가지 변신이 한 컷에)** → "해피 핼러윈!" 인사 톡. **9장.**
- **재료 선반 11개(최종, 더 추가 없음)**: 빨강 = 아기 용 빨간 콧물·빨간 소방차·무당벌레 / 노랑 = 핼러윈 호박 등·병아리 방귀·고무 오리 / 파랑 = 괴물 파란 응가·파란 생선·파란 파도 / 초록 = 초록 개구리·초록 공룡. 모두 3~4세가 깔깔 웃을 것. 재료마다 넣을 때 효과음 하나씩. 결과와 같은 재료 금지. 코코비 동요 재료는 결과적으로 생선 1개만 겹친다(차용 허용 범위).
  - **생물(무당벌레·파란 생선·개구리·공룡)은 눈을 그린다**(CLAUDE.md §7-7 등록). 솥에 넣을 때 다치는 느낌 없이 '퐁 뛰어들어 수영'하듯 귀엽게.
  - **핼러윈 호박 등은 눈·입 얼굴 구멍**을 오린다(실제 물건이라 의인화 아님, §7-7 예외 등록). 구멍일 뿐 표정 변화·말하기·깜빡임 없음. 속 촛불 빛은 빛 층(멀수록 흐려지는 그라데이션 허용 §7-1). 솥에 넣을 때 빛이 솥 안으로 퐁.
  - 소방차는 「나의 빨간 자동차」와 겹치지 않게 사다리·물대포가 있는 네모난 트럭. 얼굴 없음.
- **아이가 재료를 자유롭게 여러 개 톡해 솥에 넣고, 들어간 색 종류로 사탕이 정해진다.** 틀린 답 없음. 색 섞기는 실제 색 원리(빨+노=주황, 노+파=초록, 빨+파=보라, 빨+초=갈색).
- **먹은 아이의 몸이 변신한다**(과일 밭 배경 변신은 삭제). 결과표(§4-2): 딸기·오리·물고기·개구리·호박·박쥐·초콜릿 7가지 + **검정 유령 사탕**. 변신은 몇 초 뒤 '뿅' 원래대로. 친구들은 유령 사탕(7~8장)과 마지막 모두 변신(9장)에서만 변신. 변신 장면 배경은 핼러윈 거리·지붕·달밤 하늘 2~3장 재사용.
- 유령 사탕: 모든 색을 넣어 검정 사탕 → 다현이 입술이 까매지고 "유령 사탕이다~" "오~~우~~" 두 팔 들고 행진, 마녀·호박이·친구들도 따라 먹고 행진(무섭지 않게, 웃기게). 거절 결말 없음, "으웩!… 어? 맛있다!" 즐거운 먹기.
- **모든 배경은 핼러윈 밤 느낌**(보름달·박쥐 실루엣·호박 등·종이 거미줄·보라·주황·남색 하늘·별), 으스스하지 않게.
- **솥 물 색 변화**: 재료를 넣을 때마다 솥 물 색이 바뀐다. 첫 색은 단색 판, 둘째 색부터는 섞인 색이 아니라 **색 띠가 회오리치며 도는** 모습(띠마다 단색 조각, 1조각 1색, 코드 회전). 다 넣고 젓기 → '펑!' 연기 → 결과 사탕 등장(§4-3).
- **사탕 8종 디자인**을 따로 둔다: 모양·색지·포장이 다 다르고 변신 대상이 실루엣으로 보임(오리 모양 막대사탕 등). 광택 금지, 반짝임은 작은 크림 하이라이트 조각만. 사탕 등장 컷은 공용 틀 하나에 사탕만 바꿔 끼운다(§4-4). 재료와 결과가 겹쳐도 된다(오리·물고기·개구리·호박 사탕 그대로).
- **4·5·6장(넣기 → 펑 무슨 색 → 변신)은 회전 블록으로 2~3회전 반복**(사용자 2026-10-28). 회전마다 마녀 "이번엔 다른 색으로 해 볼까?", 2·3회전은 짧게(안내 줄이고 변신 동작 짧게, 색 질문은 그대로). 먹고 변신하는 사람은 매 회전 다현이(친구가 먹는 안은 판단 23). 자동 재생·읽어 주기는 회전마다 다른 결과(중복 없이). 시간 계산(§5-1)으로 **2회전 고정 + 3회전은 '한 번 더?' 솥 톡 선택**을 추천.
- **다현이 변신 순간마다 컷신**(사용자 2026-10-28): 변신 7가지 + 유령 = `cut_tf_*` 8장, 공용 틀(뿅 반짝 테두리·핼러윈 밤 배경 층) 공유. 한 번 볼 때 보이는 컷 수가 §5-2 상한(3~5)을 넘는 것은 사용자 결정(§9).
- 아이 이름 **다현이**(「유니콘을 찾아서」 다현이 얼굴 기준 + 꼬마 마법사 옷, 판단 0). 더러움은 귀엽고 만화식(종이 방울·말랑 똬리·파리·냄새 선). 자동 재생·읽어 주기는 결과 조합 중 **무작위**. 마녀는 다정·엉뚱. 원작 없음, 다른 작품 닮지 않기. 폴더 이름 `witch_candy` 유지.

## 1. 재미와 분위기 (교훈 대신)
- **한 줄**: 핼러윈 밤, 사탕 마녀의 초대장을 받은 다현이와 친구들이 사탕 가게에 모인다. 다현이가 우스운 재료를 골라 솥에 넣고, 섞인 색대로 생긴 사탕을 먹으면 몸이 딸기·오리·물고기·개구리·호박·박쥐·초콜릿으로 잠깐 변신한다. 모든 색을 다 넣은 검정 유령 사탕으로 모두 까만 입술로 "오~우~" 행진하고, 마지막엔 남은 사탕을 다 먹어 모두가 각자 다른 모습으로 변신한다.
- **재미의 핵심**: ① "으엑, 콧물? 응가?" — 우스운 재료를 **아이가 직접 골라 넣는** 자유, 재료마다 다른 소리(삐뽀삐뽀·뿡·꽥·개굴·크앙·철썩) ② 솥 물이 **빨강·노랑·파랑·초록 띠로 회오리치다 펑 → 주황·보라·갈색**으로 변하는 색 섞기 ③ "○○ 사탕이다!" 순간 **다현이 몸이 뿅 변신**해 굴러가고 뒤뚱거리고 헤엄치고 지붕까지 뛴다 ④ **검정 유령 사탕** — 까만 입술로 "오~우~" 행진 ⑤ 마지막에 **여섯이 한꺼번에 여덟 가지로 변신**하는 큰 그림 ⑥ 볼 때마다 다른 변신.
- **분위기**: 핼러윈 밤이지만 **따뜻하고 반짝이는 밤**. 보라·남색 하늘에 큰 보름달, 꿀색 호박 등, 종이 거미줄(거미 없음), 하늘에 작은 박쥐 실루엣 몇 마리(가까이 오지 않음), 알록달록 깃발. 유령·해골·거미는 그리지 않는다. "유령 사탕"은 까만 입술 + 두 팔 들고 "오~우~" 하는 흉내일 뿐 유령 그림은 없다. 박쥐 변신은 등에 작은 보라 날개가 돋는 귀여운 모습.
- **더러움의 수위**: 콧물은 빨간 종이 물방울, 응가는 파란 말랑 똬리(소프트아이스크림 모양), 방귀는 노란 종이 구름. 냄새 선 2~3줄과 작은 파리 한 마리(얼굴 없음)까지. 질감·광택·얼룩 없음. 입에 넣는 것은 완성된 사탕이지 재료가 아니다.
- **다시 보고 싶게**: 끝 화면 뒷표지에 사탕 여덟 개(딸기·오리·물고기·개구리·호박·박쥐·초콜릿·검정)를 작게 늘어놓고 다현이가 6장에서 **직접 변신한 것만 색**이 칠해진다(9장 모두 변신은 세지 않음). "다음엔 다른 색을 섞어 볼까요?" 한 줄. 일곱 변신을 다 보면 검정 유령 사탕 스티커(판단 8).

## 2. 방향
- 창작 동화. 노래·마법 요정·키스 없음. 마법은 '솥 물 회오리 + 펑 연기 + 몸 변신 뿅'으로만, 원작 동화의 마법 반짝 효과음은 허용.
- **이야기 흐름에 영향을 주는 선택은 없다.** 재료 고르기는 사탕의 **색·이름·변신**만 바꾸고, 장면 순서·결말은 늘 같다(CLAUDE.md §2 '줄거리와 상관없는 배움 문제' 안).
- 색 섞기는 **실제 색 원리**대로만: 빨+노=주황, 노+파=초록, 빨+파=보라, 빨+초=갈색, 초+노·초+파=초록(초록 쪽), 모든 색=검정(7장 전용).
- 4장 재료 넣기는 **두 색까지**만 받는다(세 번째 색을 누르면 그 재료가 흔들리며 선반으로 돌아가고 마녀 "세 가지는 맨 마지막에!" — 판단 4). 같은 색 재료는 몇 개든 넣을 수 있다.
- 배움 조작: **세기**(4장 재료가 들어갈 때마다 하나~다섯, 7장 네 재료), **색 고르기**(5장 두 색을 섞었을 때만 "무슨 색이 될까요?" 주황·초록·보라·갈색 중 정답 하나 choose). 재미 조작은 **2장 불 지피기 톡 하나**(장작 톡 → 불꽃 활활 → 솥 뽀글뽀글). 4장 국자 톡은 '다 넣었어요' 신호. 마지막 인사 톡 한 번. 연타 없음(7장 네 재료는 한 번 누르면 나머지 자동 — 친구들이 하나씩 넣는다, 판단 5).
- 모든 안내는 `T.ask(안내, 조작)`. 자유 넣기는 새 조작 `fill`이 필요하다(§12).
- 분량: **9장(4·5·6장은 회전 블록 2~3회전), 2회전 약 9분·3회전 약 10분 40초**(§5-1 시간표). 대사 약 58줄(공통) + 결과별 42줄, 조작 5~6개, 컷 한 번 볼 때 6~8번.

### 3-1. 크기 비율 (§4-1)
- 기준: **다현이 머리 폭 = 1**, 다현이 키 ≈ 2.5. 마녀 키 = 다현이 키 × **1.6**(머리 폭 1). 호박이 앉은 키 1.2(두 발로 서면 1.8). 친구 셋 = 다현이와 같은 키.
- 솥 높이 = 다현이 키 × 0.6, 솥 입 지름 = 다현이 키 × 0.7. **재료 한 개 = 머리 폭 × 0.5**(열한 개 모두 같은 상자 크기 — 소방차·공룡·오리는 '장난감 크기', 무당벌레·개구리는 '큰 장난감 크기'로 통일). 사탕 한 알 = 머리 폭 × 0.35. 사탕 병 높이 = 머리 폭 × 1.3. 국자 길이 = 다현이 키 × 0.5. 초대장 = 머리 폭 × 0.8(호박 모양 카드). 장작 더미 폭 = 솥 입 지름과 같음, 불꽃 높이 = 머리 폭 × 0.6.
- **변신 자세의 크기 일관성**: 변신해도 **머리 폭 1 그대로**. 딸기 공(웅크림)은 머리가 보이는 공, 납작 초콜릿은 머리 폭은 그대로이고 몸만 세로로 눌린다, 박쥐 날개·물고기 꼬리·개구리 다리는 몸 밖으로 덧붙는 조각이라 상자가 커진다 → 코드 HT는 반드시 **머리카락 폭**으로 잰다(상자 높이로 맞추면 변신마다 크기가 널뛴다).
- 9장 모두 변신 컷은 통그림이지만 여섯 인물의 머리 폭이 §3-1 비율(다현이·친구 1, 마녀 1, 호박이 얼굴 폭 0.8)을 지키도록 프롬프트에 적는다.
- 테스트: 5→6→6끝(다현이 서기 → 변신 → 뿅 원래대로)을 변신 7가지마다 사진으로 머리 폭 비교. 7→8장(먹기 → 유령 걸음), 9장 컷 앞뒤도.

### 4-1-1. 선반 배치 (한 화면 11개 + 국자, 누르는 상자 짧은 변 ≥ 90px)

### 10-5. 재사용 계획 (결과가 8가지여도 그림이 늘지 않게)
1. **색만 바뀌는 것은 조각 교체**: 솥 물 판·회오리 띠(색 조각, 회전은 코드), 결과 사탕(8종 1장씩을 코드로 복제해 병·손·색종이·컷 틀·9장 더미), 보기 사탕 4. 사탕 등장 컷은 틀 1장에 사탕만 교체.
2. **변신 장면은 새 배경 1장(지붕·달밤)뿐**, 나머지는 거리·가게 앞·부엌 재사용. 변신은 다현이 자세 교체 + 코드 동작(회전·기울임·포물선·궤도·tint)으로 낸다.
3. **9장 모두 변신은 큰 컷 1장**으로 — 마녀·호박이·친구 셋의 변신 자세 그림을 만들지 않는다.
4. **호박 등 그림 1장**이 거리 장식·노랑 재료·검정 사탕 조명·행진 조명을 다 맡는다. 박쥐 실루엣 1장을 복제해 하늘·모빌·변신 무리에 쓴다. 거미줄 1장을 복제. 초대장 1장을 넷으로 복제.
5. 변신 컷은 **틀 1장 + 인물 큰 그림 8장**을 코드로 합성해 틀을 공유한다(§9). 회전·결과가 바뀌어도 컷 파일은 같은 9장.
6. 친구 자세 4(stand·reach·happy·ghost)가 1~9장을 다 덮는다. `ghost` 자세 하나가 8·9장을 덮는다.
7. 재료 선반 11개는 3·4·7장에 같은 그림. 7장 탁자 위 네 재료는 그중 넷을 코드로 옮긴다. 세로 모드 4단 배치는 칸 조각을 코드로 다시 쌓는다.
8. 8장 행진은 새 배경 없이 부엌 → 가게 앞 → 거리 → 가게 앞을 이어 쓴다. 9장 솥은 부엌 솥 그림을 문 앞에 둔다.

## 12. 새 조작 `fill` 제안 (엔진 추가 필요, 판단 3)
현재 조작 중 `free(targets, ms)`는 시간 제한 자유 누르기이고, `choose`는 정답 하나다. 4장 '틀린 답 없이 여러 개 넣고 끝내기'는 다음이 필요하다.

```
T.fill(items, { done, maxKinds, prompt, onDrop, onReject })
  items: [{ el, key: 'r'|'y'|'b'|'g', onDrop? }, ...]   // 11개, 모두 정답
  done:  국자 el (톡하면 끝)
  maxKinds: 받는 색 종류 수 (4장 2, 7장은 tap으로 대신)
  → Promise<{ kinds: Set, count }>
```
- 동작: 모든 재료 칸과 국자를 `arm`. 재료를 누르면 `onDrop(item, i)`(동화가 복제해 솥으로 날리고 소리·세기), 들어간 색 집합이 `maxKinds`를 넘기면 `onReject(item)`(흔들림 + 마녀 한마디) 하고 받지 않는다. 같은 재료를 다시 누르면 하나 더 나온다. 국자를 누르면 끝. **집합이 비어 있으면 국자를 눌러도 끝나지 않고** 안내 한 줄.
- 손가락 힌트: 5초 무입력 → 재료 칸 하나(순환), 재료를 한 번이라도 넣은 뒤 20초 무입력 → 국자. 12초 재안내는 기존 helper 규칙.
- `T.ask(안내, () => T.fill(...))`로 안내 중에도 눌린다. 칸 짧은 변 ≥ 90px, 세로 모드에서 열한 칸과 국자가 모두 보이게(§4-1-1).
- **자동 재생**(`autoDrive.fill`): §13 정책대로 조합을 고르고 재료 1~3개를 눌러 넣은 뒤 국자. 검증 모드는 `?mix=ry` 같은 주소 인자로 조합 고정(r·y·b·g 단색 4 + 두 색 6).
- 7장 네 재료는 기존 `tap` 한 번 → 나머지는 친구들이 자동(판단 5).
- **'한 번 더?' 선택 톡**(6² 끝): 기존 `tap`에 `timeout` 옵션이 없다. `T.tap(target, { prompt, timeout: 6000 })` → 시간 안에 누르면 `true`, 지나면 `false`(손가락 힌트는 2초 뒤 한 번만, 12초 재안내 없음). 자동 재생·읽어 주기·검증은 `false`(2회전 고정, `?rounds=3`으로 바꿀 수 있게). 판단 24.
- 결과 키(색 집합 → §4-2 결과 8가지 중 하나)는 동화 코드가 들고 5·6장 대사·그림·끝 화면·스티커에 넘긴다.

22. **같은 결과가 또 나올 때**: (가) 허용하되 마녀가 "아까랑 같네? 다음엔 다른 색도 해 봐!" 한마디(**추천** — 아이의 선택을 막지 않는다) (나) 같은 조합의 둘째 색을 누르면 살짝 흔들며 받지 않고 다른 색을 권함(아이가 왜 안 되는지 모를 수 있음).
23. **회전마다 먹는 사람**: 매 회전 다현이(**추천**, 그림 폭증 방지). 대안: 2회전은 토끼가 먹음 — 토끼 변신 자세 7 + 컷 7이 더 필요해 비권장.
24. **회전 수**: 2회전 고정 + 3회전은 '한 번 더?' 솥 톡 선택(§5-1, 시간 제한 `tap` 옵션 엔진 추가). 대안: 2회전 고정만(엔진 변경 없음, 10분 안 확실).
25. **7장 유령 사탕 등장 컷(`cut_candy_frame`)을 둘지**: 두면 한 번 볼 때 컷 7~8번, 빼면 6~7번. 변신 컷(`cut_tf_ghost`)이 8장 첫머리에 바로 오므로 빼도 된다. 추천: 뺀다(그림 −1, 컷 부담 −1).
26. **2장 불 지피기 톡의 '불' 표현**: 종이 불꽃 2조각, 연기 없음, 둥근 끝. 3~4세에게 불이 걱정되면 장작 대신 **솥 밑 마법 돌(빛나는 돌)을 톡해 솥이 데워지는** 연출로 바꿀 수 있다(그림은 같은 수). 추천: 종이 불꽃(핼러윈 모닥불 느낌).

## 16. 확정 사항 (2026-10-28 사용자)
- 갈래 없음·한 줄 이야기·결말 하나(유령 사탕 행진 → 모두 변신 → 인사). 교훈 없음. 마녀는 다정·엉뚱, 무서운 장면 금지. 원작 없음, 다른 작품 닮지 않기. 폴더 `witch_candy`. 아이 이름 **다현이**(유니콘 얼굴 기준 + 꼬마 마법사 옷).
- **장 구성 9장**: 1 초대장·모임(마을 사탕 떨어짐·문 두드리기 삭제) / 2 솥 끓이기(불 지피기) / 3 재료 소개·"같이 만들까?" "내가 할래요!" / 4·5·6 자유 넣기·색 맞히기·변신 / (나눠 주기 삭제, 친구들은 처음부터 가게 안) / 7 모든 색 → 유령 사탕(친구들 가게 안 구경) / 8 행진 / 9 남은 사탕 다 먹고 **모두 각자 변신(8가지 한 컷 `cut_all_transform`)** → 인사 톡.
- 제목 「사탕 마녀의 핼러윈」 확정(동요와 비슷함을 알고 사용자 결정, KIPRIS 확인 필요), 노래·후렴 금지. 동요의 네 절 반복·재료 목록 통째 옮기기·맞이하는 도입·거절 결말·으스스한 마녀는 쓰지 않음. **동요 재료 일부 차용 허용**(결과적으로 파란 생선 1개).
- **재료 11개 최종**: 빨강 = 아기 용 콧물·소방차·무당벌레 / 노랑 = 핼러윈 호박 등·병아리 방귀·고무 오리 / 파랑 = 괴물 응가·파란 생선·파란 파도 / 초록 = 개구리·공룡. 재료마다 효과음 하나. **생물(무당벌레·생선·개구리·공룡)은 눈을 그린다**(§7-7 등록), 솥에 넣을 때 '퐁 뛰어들어 수영'. **호박 등은 눈·입 얼굴 구멍**(§7-7 예외 등록, 표정 변화·말하기 없음, 구멍 빛 그라데이션 허용, 넣을 때 빛이 솥 안으로). 소방차는 사다리·물대포로 「나의 빨간 자동차」와 구분.
- 아이가 재료를 자유롭게 여러 개 넣고 색 종류로 사탕이 정해진다(실제 색 원리). **먹은 아이 몸이 변신**(과일 밭 배경 변신·키위·포도·귤·바나나·블루베리·공룡 변신은 삭제): 딸기(빨강)·오리(노랑)·물고기(파랑)·개구리(초록 및 초록 든 두 색, 노+파)·호박(빨+노, 빛 상자)·박쥐(빨+파)·초콜릿(빨+초, 수염·주르륵 납작). 몇 초 뒤 뿅 원래대로. 친구들은 유령 사탕과 9장 모두 변신에서만 변신. 변신 배경은 핼러윈 거리·지붕·달밤 하늘 2~3장 재사용.
- 모든 색 → **검정 유령 사탕**: 까만 입술, 두 팔 들고 "오~우~", 모두 따라 먹고 행진(무섭지 않게). "으웩!… 어? 맛있다!" 즐거운 먹기, 더러움은 만화식.
- **모든 배경은 핼러윈 밤**(보름달·박쥐 실루엣·호박 등·거미줄·보라/주황/남색 하늘·별), 으스스하지 않게.
- 자동 재생·읽어 주기는 결과 무작위.
- **솥 물 색 변화**(단색 판 → 색 띠 회오리 → 펑 연기 → 결과 사탕)와 **사탕 8종 디자인**(모양·포장 다르게, 광택 없이 하이라이트 조각만, 등장 컷 공용 틀), 재료와 결과가 겹쳐도 됨(오리·물고기·개구리·호박).
- **4·5·6장 회전 블록 2~3회전**(마녀 "이번엔 다른 색으로 해 볼까?", 2·3회전 짧게, 자동 재생·읽어 주기는 회전마다 다른 결과). **다현이 변신마다 컷**(`cut_tf_*` 8장 + 공용 틀, 유니콘 다현이 얼굴 기준) — 한 번 볼 때 컷 수가 §5-2 상한을 넘는 예외.
- 나머지(장면 세부, 선반 배치, 색지·층·카메라, 조작 6개, 컷 파일 13장, 그림 약 124장, 녹음 약 112줄, 2회전 고정 + 3회전 선택, 목소리 제안, 변신 동작·사탕 디자인·9장 변신 배정 세부)는 이 문서의 제안이며 사용자 확정을 기다린다.
