## 2. 판단: 만화·판타지 폭력 질문
앱이 보여 주는 갈등은 전부 원작의 약한 위협입니다. 제출 전에 사용자가 아래 동화의 장면 사진을 한 번 훑고 정하세요.
| 동화 | 위협 장면 | 순화 처리(기획서에 기록된 것을 확인 필요) |
|---|---|---|
| 늑대와 일곱 마리 아기 염소, 아기 돼지 삼형제, 빨간 모자 | 늑대 | 잡아먹는 장면 순화 여부 |
| 헨젤과 그레텔 | 마녀 | |
| 백설공주 | 마녀·독사과 | |
| 인어공주, 별주부전, 팥죽할멈과 호랑이 | 위험·호랑이 | |
- **추천(정직하고 현실적):** '없음'. 근거는 어떤 동화에도 피·상처·죽음을 보여 주지 않도록 순화했다는 기획서 기록. 단, 위 표에서 장면을 직접 확인하지 않았습니다(이번 작업은 앱 코드·그림을 열어 보지 않음).
- **보수적 답:** '만화·판타지 폭력: 드묾/약함(Infrequent or Mild)'. 4+ 대신 9+ 가 되고, **Kids '5세 이하' 구간과 어긋날 수 있습니다**(Kids 카테고리는 앱이 해당 연령에 적합해야 하며 등급이 높으면 거절될 수 있음). 이 경우 Kids 를 포기하고 일반 교육 앱으로 내는 선택지가 생깁니다.
