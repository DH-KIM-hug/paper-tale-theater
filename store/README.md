## 스크린샷 규격
- iPad 13인치: **2752×2064 가로**. 아이패드 세로(2064×2752)는 만들지 않음(아래 이유).
- iPhone 6.9인치: **1320×2868 세로**.
- 이름 규칙 `<기기>_<번호>_<장면>.png`, 번호 순서가 업로드 순서입니다: 01 홈, 02 시작(표지), 03·04 놀이(누르는 순간), 05 읽어 주기(잠자리 재생기), 06 잠자리 탭, 07 스티커북, 08 내 무대.
- 업로드 대상 크기가 Apple 화면에서 다르게 요구되면 알려 주세요(2026-11 기준 값).

## 사용자가 직접 정할 것
1. 앱 이름 확정(후보 「톡톡 동화극장」). 영어 이름은 후보 3개 중 택1, 또는 앱 화면의 영어 표기 'Toki Toki Tale'(홈 머리글)과도 맞출지.
2. 가격 지역·판매 국가, 한국 원화 가격 확인(USD 4.99 / 0.99 가격 점).
3. 출시 국가·출시 방식(수동/자동), 출시일.
4. 저작권 표기 `© 2026 DH-KIM-hug` 를 법적 이름·상호로 바꿀지, 마케팅 URL 을 비울지(추천: 비움).
5. 연령 등급 폭력 질문 답과 Kids 카테고리 신청 여부.

## 스크린샷에서 지킨 규칙
- 실제 아이 사진 없음. 아이 캐릭터 창작 동화(구름 공장·나의 빨간 자동차·유니콘)는 어떤 화면에도 안 나옴: 홈에서 '창작 동화' 줄을 숨기고, 홈 배너는 첫 장(빨간 암탉)에서 찍었으며, 읽어 주기 목록에서는 이 세 편을 숨김.
- 사탕 마녀(허용)는 읽어 주기 탭 목록에 제목 썸네일로 일부 보일 수 있으나 아이 이름은 안 나옴. 이름 노출 우려가 있으면 `06_night` 를 빼세요.
- 스티커북·내 무대에는 팥죽할멈·호랑이·황소·개구리·토끼·거북·너구리·밤 스티커만 심어서 아이 캐릭터 스티커가 없음.
- 홈 하단 '이번 주 무료'·'공주' 줄은 날짜에 따라 바뀌므로 한 주 뒤 다시 찍으면 목록이 달라짐.
